MinoAndroid CD 파이프라인

GitHub Actions + Fastlane 기반 Play Store 배포 자동화 · release/* 브랜치에서 단계적 배포

파이프라인 3단계

  • • ① cd-qa.yml — push release/** 자동
  • • ② cd-internal.yml — 수동 dispatch
  • • ③ cd-promote.yml — 수동 dispatch
  • • 게이트는 사람 판단(QA·내부테스트)

배포 모델

  • • Play 앱은 team.mino 단일 앱
  • • 내부테스트 빌드를 그대로 production 승급
  • • 재빌드 X → 검증 = 출시 바이너리
  • • qaRelease(team.mino.qa)는 Play 미게시

versionCode / versionName

  • • versionCode = github.run_number 주입
  • • ① versionName = release 브랜치명 파생
  • • ②③ versionName = dispatch 입력값
  • • ③ version_code 비우면 internal 최신 승급
