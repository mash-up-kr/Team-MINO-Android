# [Android] 꾹(GGUK) MVP 개발 기술 사양서 (PRD)

# 1. 서비스 개요 및 개발 방향

본 문서는 외부 링크 수집 및 약속 장소 공유 서비스 '꾹(GGUK)'의 Android 클라이언트 개발 지침서입니다.

개발자가 화면별 구현 로직을 직관적으로 파악할 수 있도록 Figma 디자인 보드([000]~[007])의 화면 흐름(User Flow)을 기준으로 UI/UX 인터랙션, 클라이언트 동작 규칙, 런타임 권한 제어 명세를 작성했습니다.

### 핵심 개발 지침

- **화면 플로우 중심 개발**: 앱 진입부터 외부 공유, 온보딩, 카드 스와이프, 지도 탐색, 마이페이지 권한 설정까지 유저 동선에 맞춘 인터랙션을 우선 구현합니다.
- **상황별 권한 요청 (Contextual Permissions)**:
    - 알림 권한: 앱 스플래시 화면 진입 후 **2초 지연** 뒤 요청.
    - 위치 권한: 방 상세에서 **지도 뷰(Map View)가 실제 노출되는 시점**에 요청.
    - 권한 재요청: 마이페이지 내 토글 및 OS 앱 설정 화면 연동.
- **비회원 디바이스 세션**: 소셜 로그인 없이 디바이스 고유 식별자 기반으로 세션을 유지합니다.
- **독립적 카드 소비 경험**: 홈 탭의 카드 덱 인터랙션은 클라이언트 로컬 UI 상태로 관리하여 다른 멤버의 화면에 영향을 주지 않도록 격리합니다.

### [1] 데이터 및 도메인 용어

- **방 (Room)**
    - 장소들을 모아서 저장하고 관리할 수 있는 가상의 공간.
    - 사용자는 여러 개의 방을 생성할 수 있으며, 방마다 고유한 **대표 색상**이 지정됩니다.
    - [1] 개인방 (Personal Room)
        - 프로필 작성 완료 시 **기본으로 자동 생성되는 사용자 전용 저장 공간**.
        - **초대 불가**: 다른 멤버를 초대할 수 없으며, 오직 혼자서만 장소를 모으고 관리할 수 있습니다.
        - **삭제/제거 금지 (Delete Prevention)**:
            - 기본으로 제공되는 최상위 개인 공간이므로 **삭제, 나가기, 제거 기능이 절대 제공되지 않습니다.**
            - 앱 내에서 개인방은 어떠한 경우에도 삭제할 수 없습니다.
    - [2] 공동방 (Group Room)
        - 사용자가 필요에 따라 **별도로 새로 생성하는 공간**.
        - **멤버 초대 가능**: 초대 링크 생성 및 멤버 초대를 통해 다른 사용자들과 장소를 공동으로 추가·관리할 수 있습니다.
        - **방장 권한 및 위임**: 방장이 방 나가기를 시도할 경우, 남은 멤버가 있다면 반드시 다른 멤버에게 방장 권한을 위임해야 합니다.
    - [3] 장소 및 마커 표출 규칙
        - **단일 방 장소**: 해당 방의 대표 색상 커스텀 마커 적용.
        - **중복 장소 (여러 방에 속함)**: **최초로 저장된 방의 대표 색상** 마커 적용 (방 선택 모달에서 다른 방으로 전환 시 해당 방의 색상으로 변경).
        - **지도 표출 규칙**: 메인 지도에서는 모든 방의 장소가 표시되며, **방 상세** 진입 시에는 **해당 방에 저장된 장소만** 지도 위에 표시됩니다.
- **장소 (Place / Pin)**
    - 사용자가 추가한 실제 지명 및 위경도 좌표를 가진 위치 데이터.
    - 지도 위에는 커스텀 핀 마커로 표시됩니다.
    - **중복 규칙 및 마커 색상 정책**
        - **동일한 방 내:** 같은 장소가 중복 저장될 수 없음.
        - **다른 방 간 중복 저장 시:** 한 장소가 여러 방에 동시에 저장된 경우(중복 장소), **최초로 저장된 방의 대표 색상 마커**를 유지함.
        *(예: 방 A(노랑)에 최초 저장 후 방 B(파랑)에 추가 저장 시, 기본적으로 노랑 마커 표시)*
        - **방 선택 모달 선택 시:** 하단 방 선택 모달에서 특정 방(예: 방 B)을 클릭하여 전환하면 해당 방의 대표 색상(예: 파랑) 마커로 변경됨.
- **방장 (Room Owner)**
    - 방을 최초로 생성했거나 방장 권한을 위임받은 사용자.
    - 방 이름, 대표 색상 등 **방의 전체 설정을 변경할 수 있는 권한**을 가집니다.
    - **방 나가기 제한**: 방에 다른 멤버가 남아있는 상태에서 방장이 나가기를 시도할 경우, 반드시 **다른 멤버에게 방장 권한을 위임해야만** 나가기가 가능합니다.

### [2] UI / UX 및 화면 구조 용어

- **카드 덱 (Card Deck)**
    - 장소 정보를 한 장씩 보여주는 카드 형태의 탐색 UI Component.
    - **기본 구성**: 1개 덱당 **최대 10개의 장소 카드**로 구성됨.
    - **스와이프 방향별 동작**:
        - **우측 스와이프 (Right Swipe)**: 현재 장소를 넘김 (카드 덱에서 제거 및 다음 장소 노출).
        - **좌측 스와이프 (Left Swipe)**: 바로 이전에 넘겼던 장소 카드를 다시 불러와 복구 (Undo).
    - **스와이프 애니메이션**: 좌우 스와이프 시 적용되는 애니메이션은 아직 논의 중으로 미정.
    - **동적 새로고침 Floating Button**: 카드 덱 내 잔여 장소가 **2개 이하 시점**에 화면에 노출되며, 클릭 시 같은 방의 새 10개 장소 카드로 덱을 다시 채움.
    - **자동 방 전환 (Room Transition)**: 새로고침 버튼을 누르지 않고 10개 카드를 모두 넘겨 덱이 소진되면, **다음 방의 카드 덱으로 자동 전환**됨.
- **3단 바텀시트 (3-Step BottomSheet)**
    - **[004] 방 상세** 및 **[003] 저장 탭** 하단에서 높이가 3단계로 조절되는 레이어 UI.
    - **`Peek` (최하단)**: 지도 영역을 가장 넓게 보여주며, 하단에 간이 정보/컨트롤바만 표시. (영역 20%)
    - **`Half` (중간)**: 선택한 장소의 요약 카드 정보 및 상세 정보 표출. (영역 40%)
    - **`Full` (최상단)**: 화면 전체를 덮으며 내 방에 저장된 장소 목록 전체(List View)를 리스트 형태로 표출. (영역 100%)
- **커스텀 핀 마커 (Custom Pin Marker)**
    - 지도 상에 장소 위치를 나타내는 아이콘. 형태(Asset)는 디자이너가 지정한 고정 커스텀 이미지 형태를 가지며, **속한 방의 대표 색상에 따라 다이나믹하게 색상이 변경**되어 렌더링됨.
- **동적 GPS 버튼 (Floating GPS Button)**
    - 현재 위치로 카메라는 이동시키는 버튼.
    - 바텀시트가 `Peek` ↔ `Half`로 움직일 때 **바텀시트의 높이(Offset)를 실시간 추적하여 우측 하단 상하 위치가 연동**되며, 바텀시트가 **`Full` 모드가 되면 화면에서 완전히 숨김(Gone)** 처리됨.
- **지연 권한 요청 (Lazy Permission Request)**
    - 앱 시작 시 즉시 모든 권한을 요구하지 않고, 스플래시 진입 2초 뒤(알림 권한) 또는 지도 화면이 실제 사용자의 눈에 보이는 시점(위치 권한) 등 **해당 기능이 필요한 맥락(Context)에 맞춰 팝업을 띄우는 UX 정책**.

# 2. 목표 / 비목표

### 목표 (MVP 범위)

- **[SYS-001] 신규 공동방 생성**: 방 이름, 설명, 8종 테마 컬러 선택을 통한 온보딩/저장 탭 공통 모듈화 방 생성 플로우.
- **[SYS-002] 외부 공유 수신**: 인스타그램 등 외부 앱에서 공유된 링크 수신 후 비동기 분석 요청 및 방 선택 바텀시트 표출.
- **[SYS-003] 장소 복제 & 방 목록 선택**: 탐색 중인 Context를 유지한 채 타깃 방을 선택해 해당 장소를 복제/공유하는 모달 팝업.
- **[SYS-004] 지도 & 동적 GPS**: 위치 권한/디폴트 좌표 기반 지도 초기화, 테마/중복 핀 마커 판별 및 바텀시트 드래그 높이에 연동되는 동적 GPS UX.
- **[SYS-005] 바텀 네비게이션**: 4개 메인 탭(홈/저장/알림/마이페이지) 간 상태 보존 및 몰입 뷰 화면별 노출 제어.
- **[SYS-006] 방 초대 링크 생성**: 공동방 초대 딥링크/코드 생성 및 OS 공유 시트 연동 공유.
- **[SYS-007] 방장 나가기 & 권한 위임**: N인 방 탈퇴 시 Radio Group 기반 타 멤버 권한 위임 다이얼로그 표출 및 1인 방 즉시 삭제/탈퇴 처리.
- **[SYS-008] 외부 지도 & 장소보기 연동**: 장소 상세 화면에서 카카오맵 앱으로 해당 장소 검색 연동 및 미설치 시 외부 웹 브라우저로 이동.
- **[SCR-001] 스플래시 & 지연 알림 권한**: 스플래시 진입 2초 후 OS 알림 권한 팝업 지연 노출 및 온보딩 자동 이동.
- **[SCR-002] 앱 온보딩**: 필수 프로필 작성/기본 개인방 자동 생성 및 선택적 공동방 생성, 친구 초대, 간이 튜토리얼 순차 이행.
- **[SCR-003] 홈 탭 카드 덱 탐색**: 장소 카드 스와이프 탐색, 카테고리/수동 방 변경, 10개 소진 시 다음 방 자동 전환 및 새로고침.
- **[SCR-004] 저장 탭 방 목록 관리**: 최상단 개인방 고정 및 공동방 목록 지도 마커 프리뷰 렌더링, 조건부 생성 유도 배너 표출.
- **[SCR-005] 방 상세 지도 탐색**: 3단 바텀시트 기반 지도/장소 탐색, 갤러리/리스트 뷰 토글 및 방 편집/초대/위임 나가기 관리.
- **[SCR-006] 장소 상세 & 코멘트**: 장소 대표 정보, 코멘트 타임라인 조회/작성/삭제, 복제 공유 및 외부 장소보기 연동.
- **[SCR-007] 알림 탭**: 시간순 알림 목록 조회, 읽음 처리 및 알림 유형별 타깃 방/장소 Direct Navigation.
- **[SCR-008] 마이페이지 & 환경설정**: 프로필 관리, 라이트/다크 테마 설정, OS 앱 설정 화면 연동 권한 관리 및 서비스 약관 제공.

### 비목표 (MVP 제외 범위)

- **앱 내 URL 직접 입력 UI**: 외부 공유 시트 수신 기능으로 일원화.
- **소셜 로그인 / OAuth 2.0**: 회원가입 절차 없이 디바이스 기반 세션 사용.
- **방 직접 폭파(삭제) 버튼**: 명시적 삭제 버튼 없이 `방 나가기 + 방장 위임` 구조 적용.
- **방별 프로필 분리**: 단일 공통 프로필 사용.

# 3. 화면 플로우별 기능 명세 및 UI/UX 규칙

## ⚙️ [공통 / 독립 시스템 명세] (최우선 개발 대상)

### [SYS-001] [독립 명세] 신규 공동방 생성 (Create Group Room)

- **역할:** 온보딩, 저장 탭 내 생성 버튼, 유도 배너 등 앱 내/외부 다양한 진입점에서 호출되는 **단일화된 공동방 생성 컴포넌트/플로우**.
- **사용처:** [SCR-002] 온보딩, [SCR-004] 저장 탭

#### 🔄 서브 플로우 명세

- **Flow A. 방 정보 입력 및 테마 선택**
    - 공동방 생성 화면/바텀시트 진입 ➔ 방 이름(1~15자), 방 설명(0~50자, 선택) 입력 ➔ 대표 테마 색상(Hex Color Palette 8종 중 1개) 선택
- **Flow B. 생성 완료 및 진입점별 후속 분기**
    - [생성 완료] 클릭 ➔ 서버 공동방 생성 API 호출
    - ➔ **[SCR-002] 온보딩에서 진입 시:** 생성 완료 후 [SCR-002]의 '친구 초대' 스텝으로 다음 이동
    - ➔ **[SCR-004] 저장 탭 등 기타 화면에서 진입 시:** 생성 완료 후 생성된 해당 방의 **[SCR-005] 방 상세** 화면으로 즉시 이동

### [SYS-002] [공통 명세] 외부 공유 수신 (Shared Link Receiver)

- **역할:** 외부 앱에서 '공유하기'를 통해 꾹 앱으로 링크가 전달되었을 때 수신 및 비동기 분석 연동.
- **사용처:** 앱 외부 (OS 공유 시트)

#### 🔄 서브 플로우 명세

- **Flow A. 링크 수신 및 방 선택 바텀시트**
    - 외부 공유 ➔ OS 공유 시트에서 '꾹' 선택 ➔ 공유된 링크 수신 ➔ URL 추출 ➔ 분석 요청 ➔ 내 방 선택 바텀시트 표출 ➔ 방 선택 후 '저장' 클릭 시 저장 완료 후 바텀시트 닫힘 (최초 1회 간이 튜토리얼 팝업 표출)

### [SYS-003] [공통 명세] 장소 복제 & 방 목록 선택 팝업 (Place Replication & Room Selector)

- **역할:** 보고 있는 장소를 내가 속한 다른 방으로 공유(복제)할 때 공통 호출되는 모달 팝업 및 Context 유지 로직.
- **사용처:** [SCR-005] 방 상세, [SCR-006] 장소 상세

#### 🔄 서브 플로우 명세

- **Flow A. 방 선택 및 복제 실행**
    - [다른 방에 공유] 클릭 ➔ 내 방 목록 선택 팝업 노출 (이미 해당 장소가 저장된 방은 Disabled 처리) ➔ Target 방 선택 ➔ 공유 완료 Toast 표출 ➔ **현재 탐색 중인 화면/Context 유지 (타깃 방으로 이동하지 않음)**

### [SYS-004] [공통 명세] 지도 뷰어, 마커 및 동적 GPS 시스템 (Map System & Dynamic GPS)

- **역할:** 지도 기반 화면에서 공통 연동되는 카메라 초기화, 마커 색상 판별, 바텀시트 높이에 연동되는 동적 GPS 버튼 UX.
- **사용처:** [SCR-004] 저장 탭, [SCR-005] 방 상세, [SCR-006] 장소 상세

#### 🔄 서브 플로우 명세 및 UI/UX 규칙

- **지도 초기화:** 위치 권한 허용 시 내 현재 위치, 거절 시 예측된 기본 디폴트 좌표로 중심점 세팅. *(※ 디폴트 좌표는 현재 강남역으로 임시 지정되어 있으며 추후 변경될 수 있음)*
- **화면별 지도 사용 형태:**
    - **[SCR-004] 저장 탭:** 방 목록/카드 내 해당 방 저장 장소들의 마커 분포를 보여주는 프리뷰 뷰포트 지도 연동.
    - **[SCR-005] 방 상세 & [SCR-006] 장소 상세:** 전체 화면 연동 인터랙티브 지도 뷰.
- **마커 색상 정책:** 단일 장소는 **해당 방의 대표 테마 색상 마커**, 중복 저장 장소는 **최초로 저장된 방의 대표 색상 마커**(방 선택 모달에서 전환 시 해당 방 색상으로 변경).
- **동적 GPS 버튼:** 바텀시트 Peek ↔ Half 드래그 높이에 연동하여 Y축 실시간 상하 이동 / Full 모드 승격 시 `GONE` 처리 ([SCR-005] 방 상세 및 [SCR-006] 장소 상세 적용).

### [SYS-005] [공통 명세] 바텀 네비게이션 시스템 (Bottom Navigation System)

- **역할:** 메인 탭 4개(홈, 저장, 알림, 마이페이지)간 스태킹/상태(State) 유지를 담당하는 최상위 시스템 UI.
- **사용처:** [SCR-003] 홈 탭, [SCR-004] 저장 탭, [SCR-007] 알림 탭, [SCR-008] 마이페이지

#### 🔄 서브 플로우 명세 및 UI/UX 규칙

- **State Preservation:** 탭 전환 시 스크롤 및 필터 상태를 유지한다.

### [SYS-006] [공통 명세] 방 초대 링크 생성 및 공유 (Room Invite & Link Sharing)

- **역할:** 온보딩 및 방 상세 화면에서 공동방으로 타인을 초대할 때 공통 호출되는 초대 링크 생성 및 OS Share Sheet 호출 컴포넌트.
- **사용처:** [SCR-002] 온보딩, [SCR-005] 방 상세

#### 🔄 서브 플로우 명세

- **Flow A. 초대 링크 생성 및 공유 시트 호출**
    - [초대 링크 공유] 클릭 ➔ 해당 방의 딥링크/초대 코드 생성 ➔ 성공 시 OS 공유 시트 연동 (링크 복사 / 카카오톡 / 문자 등)

### [SYS-007] [공통 명세] 방장 나가기 및 권한 위임 (Owner Delegation & Room Exit)

- **역할:** 방장이 방 나가기를 시도할 때 멤버 수에 따라 권한 위임 다이얼로그를 표출하고 탈퇴 처리하는 공통 정책 컴포넌트.
- **사용처:** [SCR-005] 방 상세

#### 🔄 서브 플로우 명세

- **Flow A. 방장 나가기 시 위임 조건 분기**
    - 방장이 [방 나가기] 클릭 ➔
    - ➔ **1인 공동방:** 별도 위임 절차 없이 즉시 방 삭제 및 탈퇴 처리.
    - ➔ **N인 공동방:** 타 멤버 목록 Radio Group 다이얼로그 노출 ➔ 1인 선택 필수 ➔ 권한 위임 API 성공 후 방 탈퇴 처리.

### [SYS-008] [공통 명세] 외부 지도 및 장소보기 앱 연동 (External Place View App Launcher)

- **역할:** 장소 상세 화면에서 장소보기 CTA 클릭 시 외부 카카오맵/네이버지도 앱 또는 웹 브라우저에서 해당 장소를 검색해 보여주는 독립 시스템.
- **사용처:** [SCR-006] 장소 상세

#### 🔄 서브 플로우 명세

- **Flow A. 설치 여부 검증 및 장소보기 실행**
    - [장소보기] 클릭 ➔ 카카오맵 앱 설치 여부 확인
    - ➔ **앱 설치됨:** 카카오맵 앱에서 해당 장소 검색 결과로 연결
    - ➔ **앱 미설치:** 외부 웹 브라우저에서 해당 장소 검색 결과로 Fallback 이동

## 📱 [화면 플로우별 명세]

### [SCR-001] 스플래시 & 지연 알림 권한 (Splash & Notification Permission)

- **서브 플로우:**
    - 스플래시 진입 ➔ 2초 후 OS 알림 권한 팝업 지연 노출 ➔ 유저 허용/거부 여부와 상관없이 **[SCR-002] 온보딩**으로 이동

### [SCR-002] 앱 온보딩 (Onboarding Flow)

#### 🔄 서브 플로우 명세

- **Flow A. 필수 - 프로필 작성 & 기본 개인방 자동 생성 (Required)**
    - 프로필 이미지 등록 & 닉네임 입력 ➔ [다음] 클릭 ➔ 프로필 생성 및 기본 개인방 자동 생성 완료 ➔ **Flow B**로 이동 *(※ 건너뛰기 불가)*
- **Flow B. 선택 - 첫 공동방 생성 (Optional)**
    - 첫 공동방 생성 안내 화면 ➔ [생성하기] 클릭 시 **[SYS-001] 신규 공동방 생성** 호출 ➔ 생성 완료 후 **Flow C**로 이동
    - ➔ [건너뛰기] 클릭 시: 공동방을 생성하지 않고 Flow C를 건너뛰어 즉시 **Flow D**로 이동
- **Flow C. 조건부 선택 - 친구 초대 (Conditional Optional)**
    - *(※ Flow B에서 공동방을 생성한 유저에게만 노출)*
    - 생성된 공동방 초대 화면 ➔ [초대 링크 공유] 클릭 시 **[SYS-006] 초대 링크 공유** 호출 후 **Flow D**로 이동 / [건너뛰기] 클릭 시 **Flow D**로 직행
- **Flow D. 선택 - 간이 튜토리얼 (Optional)**
    - 가이드 화면 ➔ [완료] 또는 [건너뛰기] 클릭 시 **[SCR-003] 홈 탭** 진입 *(※ [SYS-005] 바텀 네비게이션 노출 시작)*
    - *(※ [건너뛰기] 기능 상세는 아직 확정되지 않았으나, 제공 예정이므로 UI는 유지)*

### [SCR-003] 홈 탭 - 장소 카드 덱 탐색 (Home - Place Card Deck)

- **시스템 연동:** **[SYS-005] 바텀 네비게이션** 첫 번째 탭.

#### 🔄 서브 플로우 명세

- **Flow A. 메인 - 카드 덱 스와이프 탐색:** 우측 스와이프(카드 넘어감), 좌측 스와이프(Undo 복구).
- **Flow B. 카테고리 변경:** Horizontal Scroll 카테고리 칩 선택 ➔ 덱 재로드 & Undo Stack 초기화.
- **Flow C. 덱 새로고침:** 카드 잔여량 3개 이하 시 [새로고침] FAB 노출 ➔ 클릭 시 10개 재로드.
- **Flow D. 카드 소진 & 자동 방 전환:** 10번째 카드 소진 시 다음 방의 동일 카테고리 덱(10개) 자동 로드 ➔ 상단 2~3초 안내 툴팁 노출.
- **Flow E. 수동 방 변경:** 우측 상단 [방 변경] 클릭 ➔ 방 선택 ➔ 선택한 방의 카드 덱 재로드.

### [SCR-004] 저장 탭 - 방 목록 탐색 & 관리 (Storage Tab - Room List & Management)

- **시스템 연동:** **[SYS-004] 지도 시스템**, **[SYS-005] 바텀 네비게이션** 적용. *(※ [SYS-004] 연동 반영)*

#### 🔄 서브 플로우 명세

- **Flow A. 메인 - 방 목록 탐색:** 최상단 고정된 개인방 + 하단 공동방 목록 렌더링 (**각 방 카드 내 [SYS-004] 지도 마커 프리뷰 노출**) ➔ 방 선택 시 **[SCR-005] 방 상세** 이동.
- **Flow B. 조건부 - 공동방 생성 유도 배너:**
    - [개인방만 존재 시]: 상단 유도 배너 노출 ➔ 클릭 시 **[SYS-001] 신규 공동방 생성** 호출
    - [공동방 1개 이상 존재 시]: 유도 배너 숨김(Gone)
- **Flow C. 생성 - 신규 공동방 생성:**
    - 바텀시트 [+] 버튼 클릭 ➔ **[SYS-001] 신규 공동방 생성** 호출 ➔ 생성 완료 후 **[SCR-005] 방 상세** 화면으로 직행.

### 2.1. 사용자 경험 및 탐색 Flow 최적화 (목표 항목 업데이트)

- **시각화된 위치 기반 탐색 강화:**
  저장 탭`[SCR-004]`의 방 목록 프리뷰부터 방 상세`[SCR-005]`, 장소 상세`[SCR-006]`에 이르기까지 **[SYS-004] 지도 시스템**을 일관되게 연동하여 테마 색상별 마커, 중복 핀 판별, 바텀시트 연동 동적 GPS UX를 제공하고 직관적인 공간 인지 경험을 완성합니다.

### [SCR-005] 방 상세 - 지도 탐색 & 방 목록 관리 (Room Detail & Management)

- **시스템 연동:** **[SYS-003] 장소 복제**, **[SYS-004] 지도/GPS/마커**, **[SYS-006] 초대 공유**, **[SYS-007] 방장 위임** 적용. *(※ [SYS-008] 외부 장소보기 제거)*
- **화면 특성:** 몰입감을 위해 **[SYS-005] 바텀 네비게이션 비노출(GONE)**.

#### 🔄 서브 플로우 명세

- **Flow A. 메인 탐색:** **[SYS-004] 지도/GPS** + 3단 바텀시트(Peek/Half/Full)로 저장 장소 탐색. 장소 클릭 시 **[SCR-006] 장소 상세**로 이동.
- **Flow B. 필터 & 뷰 토글:** Full 모드 진입 시 카테고리 칩 + 정렬 Dropdown + **갤러리/리스트 뷰 토글** 적용.
- **Flow C. 장소 액션:** 장소 카드 [...] 클릭 ➔ [다른 방에 공유] 선택 시 **[SYS-003] 장소 복제 팝업** 호출 / [장소 삭제] 선택 시 해당 방에서 제거. *(※ 장소보기 없음)*
- **Flow D. 방 설정 & 초대/나가기:**
    - [친구 초대]: **[SYS-006] 방 초대 링크 공유** 호출.
    - [방 편집] (방장 전용): 방 이름, 대표 컬러 수정.
    - [방 나가기]: 클릭 시 **[SYS-007] 방장 나가기 및 권한 위임** 호출 (일반 멤버는 즉시 나가기 / 개인방은 메뉴 비노출).

### [SCR-006] 장소 상세 & 코멘트 (Place Detail & Comments)

- **시스템 연동:** **[SYS-003] 장소 복제**, **[SYS-004] 지도/GPS/마커**, **[SYS-008] 장소보기** 적용.

#### 🔄 서브 플로우 명세

- **Flow A. 장소 상세 조회:** 대표 이미지, 카테고리, 주소, 등록자, 코멘트 타임라인 조회.
- **Flow B. 다른 방에 공유:** [다른 방에 공유] 클릭 ➔ **[SYS-003] 장소 복제 팝업** 호출 ➔ 공유 완료 후에도 **현재 장소 상세 화면 유지**.
- **Flow C. 외부 장소보기 연동:** [장소보기] 클릭 ➔ **[SYS-008] 외부 지도 및 장소보기 앱 연동** 호출.
- **Flow D. 코멘트 작성/삭제:** 코멘트 입력 및 등록 / 내 작성 코멘트 삭제 기능.

### [SCR-007] 알림 탭 (Notifications Tab)

- **시스템 연동:** **[SYS-005] 바텀 네비게이션** 세 번째 탭.

#### 🔄 서브 플로우 명세

- **Flow A. 목록 조회:** 최신 알림 시간순 렌더링 (안 읽음/읽음 구분).
- **Flow B. 알림 클릭 이동:** 클릭 시 읽음 처리 후 알림 유형별 화면 이동 ([SCR-005] 방 상세, [SCR-006] 장소 상세 등).

### [SCR-008] 마이페이지 & 환경설정 (My Page & Settings)

- **시스템 연동:** **[SYS-005] 바텀 네비게이션** 네 번째 탭.

#### 🔄 서브 플로우 명세

- **Flow A. 프로필 관리:** 닉네임/이미지 수정 ➔ 앱 전체 유저 프로필 즉시 반영.
- **Flow B. 화면 테마:** 라이트 / 다크 / 시스템 동기화 스위치 조작 ➔ Local DataStore 저장 및 반영.
- **Flow C. OS 권한 관리:** 알림/위치 스위치 클릭 ➔ OS 시스템 앱 설정 화면으로 딥링크 이동. *(※ 알림 권한은 추가 UI가 생길 수 있음, 아직 미정)*
- **Flow D. 서비스 정보:** 약관 웹뷰 및 Play Store 리뷰 남기기 딥링크 연결.
