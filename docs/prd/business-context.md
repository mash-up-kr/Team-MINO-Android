# 1. 서비스 개요 및 개발 방향

SNS에서 본 좋은 장소는 "나중에 가봐야지" 하고 링크를 저장해두지만, 정작 약속을 잡을 때는 "저번에 말한 거기가 어디였지?"로 끝난다. 링크는 각자의 DM·저장함에 흩어져 있고, 지도에 찍히지 않으니 어디에 모여 있는지도 알 수 없다.

**꾹(GGUK)** 은 외부 앱에서 공유한 장소 링크를 **방(Room)** 에 모아 지도 위에 함께 쌓고, 그렇게 쌓인 장소를 카드로 다시 꺼내보게 하는 장소 수집·공유 서비스다. 저장은 SNS 공유 시트 한 번으로 끝나고, 꺼내보는 일은 홈 탭의 카드 덱이 대신한다.

본 문서는 꾹의 Android 클라이언트가 무엇을 만드는지에 대한 단일 출처이며, Figma `◆ver.2` 보드([000]~[011])의 화면과 User Flow를 기준으로 작성했다.

## 핵심 원칙

- **저장은 앱 밖에서, 탐색은 앱 안에서**: 장소 추가의 유일한 정식 입구는 외부 앱의 OS 공유 시트다. 앱은 저장된 장소를 지도·카드·리스트로 다시 꺼내 보이는 데 집중한다.
- **상황별 권한 요청 (Contextual Permissions)**: 앱 시작 시 권한을 몰아 묻지 않는다. 위치 권한은 지도가 실제로 그려지는 시점에, 알림 권한은 마이페이지에서 사용자가 스위치를 켜는 시점에 요청한다.
- **비회원 디바이스 세션**: 소셜 로그인 없이 디바이스 고유 식별자 기반으로 세션을 유지한다.
- **방마다 다른 얼굴**: 방은 대표 색상과 캐릭터를 가지며, 마커·뱃지·툴팁까지 그 색과 캐릭터로 일관되게 표현한다. 사용자가 "지금 어느 방에 있는지"를 글자가 아니라 색과 캐릭터로 알 수 있게 한다.
- **독립적 카드 소비 경험**: 홈 탭의 카드 덱 인터랙션은 클라이언트 로컬 UI 상태로 관리하며, 다른 멤버의 화면에 영향을 주지 않는다.

## 데이터 및 도메인 용어

- **방 (Room)**
    - 장소들을 모아서 저장하고 관리할 수 있는 가상의 공간.
    - 사용자는 여러 개의 방을 생성할 수 있으며, 방마다 고유한 **대표 색상**과 **대표 캐릭터**가 지정된다.
    - **대표 색상**: 지정된 **12종 팔레트**(red / red orange / orange / lime / green / cyan / violet / pink / blue / brown / light blue / purple) 중 1개를 선택한다. 마커·뱃지·툴팁 색상의 기준이 된다.
        - **선택은 필수가 아니며, 고르지 않으면 기본값인 회색이 적용된다.**
    - [1] 개인방 (Personal Room)
        - 프로필 작성 완료 시 **기본으로 자동 생성되는 사용자 전용 저장 공간**. 방 리스트 최상단에 `내 장소`로 고정된다.
        - **초대 불가**: 다른 멤버를 초대할 수 없으며, 오직 혼자서만 장소를 모으고 관리한다.
        - **삭제/나가기 금지**: 기본으로 제공되는 최상위 개인 공간이므로 삭제·나가기·제거 기능을 어떤 경우에도 제공하지 않는다.
    - [2] 공동방 (Group Room)
        - 사용자가 필요에 따라 **별도로 새로 생성하는 공간**. 방 이름·방 설명·대표 색상을 입력해 만든다.
        - **멤버 초대 가능**: 초대 링크를 생성해 다른 사용자를 초대하고, 장소를 공동으로 추가·관리한다.
        - **방장 권한 및 위임**: 방장이 나가기를 시도할 때 남은 멤버가 있다면 반드시 다른 멤버에게 방장 권한을 위임해야 한다.
- **장소 (Place / Pin)**
    - 사용자가 추가한 실제 지명·주소·위경도 좌표를 가진 위치 데이터. 지도 위에는 커스텀 핀 마커로 표시된다.
    - **구성 요소**: 장소명, 주소, 카테고리, 대표 이미지(복수), 등록자, 원문 링크(공유받은 외부 URL), 코멘트 목록, 저장 경과일.
    - **중복 규칙 및 마커 색상 정책**
        - **동일한 방 내**: 같은 장소가 중복 저장될 수 없다.
        - **다른 방 간 중복 저장 시**: 한 장소가 여러 방에 동시에 저장된 경우(중복 장소), 지도에는 **가장 최근에 저장한 방의 대표 색상 마커**를 기본으로 표시한다.
        - **방 전환 시**: 방 선택을 통해 다른 방(예: 파란 방)으로 전환하면 해당 방의 대표 색상 마커로 바뀐다.
- **방장 (Room Owner)**
    - 방을 최초로 생성했거나 방장 권한을 위임받은 사용자.
    - 방 이름, 방 설명, 대표 색상 등 **방의 전체 설정을 변경할 수 있는 권한**을 가진다.
    - **방 나가기 제한**: 방에 다른 멤버가 남아있는 상태에서 방장이 나가기를 시도하면 반드시 다른 멤버에게 방장 권한을 위임해야만 나갈 수 있다.
- **코멘트 (Comment)**
    - 장소에 남기는 텍스트 메모. 같은 방 멤버들에게 공유되며 `친구들의 코멘트`로 노출된다.
    - **입력 제한**: 1회 최대 200자.
    - **삭제 권한**: `TBD:` 자신이 작성한 코멘트만 삭제할 수 있는 것으로 본다. 삭제 동선이 ver.2 디자인에 아직 반영되어 있지 않다.
    - 방을 나가더라도 그 방에 남긴 장소와 코멘트는 방에 그대로 남는다.

## UI / UX 및 화면 구조 용어

- **카드 덱 (Card Deck)**
    - 장소 정보를 한 장씩 보여주는 카드 형태의 탐색 UI. [SCR-003] 홈 탭에서 사용한다.
    - **기본 구성**: 1개 덱당 **최대 10개의 장소 카드**로 구성된다.
    - **스와이프 인식 영역**: 스와이프 제스처는 **화면 우측 영역에서만** 인식한다. 좌측 영역은 스와이프 대상이 아니다.
    - **스와이프 방향별 동작** (우측 영역 내에서)
        - **좌 → 우 드래그**: 현재 장소를 넘긴다(덱에서 제거하고 다음 카드 노출).
        - **우 → 좌 드래그**: 바로 이전에 넘겼던 카드를 되돌린다(Undo).
    - **동적 새로고침 Floating Button**: 덱의 10장 중 **8장 이상을 소진한 시점**(잔여 2개 이하)에 노출되며, 클릭 시 같은 방의 새 10개 카드로 덱을 다시 채운다.
    - **자동 방 전환 (Room Transition)**: 새로고침 버튼을 누르지 않고 10개를 모두 넘겨 덱이 소진되면 다음 방의 덱으로 자동 전환된다.
- **카드 정렬 기준 (Card Sorting)**
    - 홈 탭 카드 덱에 어떤 장소를 담을지 결정하는 3종 기준. 모든 기준은 **후보 집합 내의 순위**로 정렬한다.
    - **꾹 Pick**: 클릭 수, 코멘트 수, 중복 저장 수를 종합한 상위 노출. 아무 반응이 없는 장소는 가장 오래된 것부터 랜덤으로 채운다.
    - **최신순**: 현재일 기준 **최근 14일 이내**에 저장된 장소.
    - **가까운순**: 내 현재 위치 기준 **반경 3km 이내**의 장소.
- **3단 바텀시트 (3-Step BottomSheet)**
    - 지도 화면 위에서 높이가 3단계(`Peek`/`Half`/`Full`)로 조절되는 레이어 UI. [SCR-004] 방 리스트 탭, [SCR-005] 방 상세, [SCR-006] 장소 상세, [SYS-003] 다른 방에 공유에서 사용한다.
    - **높이는 화면 비율이 아니라 화면·상태별 고정 dp 값이다.** 담기는 콘텐츠(헤더·칩·카드 개수)에 따라 화면마다 값이 다르다.
        - **[SCR-004] 방 리스트**
            - `Peek`: 90dp(고정값, 바텀 네비게이션 높이 제외) — 헤더(방 리스트 + 방 생성 아이콘 버튼 영역)만 표시.
            - `Half` (공동방 0개, 개인방만): 244dp(고정값) — 헤더 + 칩(전체·최근 저장 순·코멘트 순) + 개인방 카드.
            - `Half` (공동방 1개): 348dp(고정값) — 위 구성 + 공동방 카드 1개.
            - `Half` (공동방 N개 이상): 380dp(고정값) — 위 구성 + 공동방 카드(세로 스크롤, 스크롤 어포던스를 위해 3번째 카드는 잘리게 표시).
            - `Full`: 전체 화면으로 확장, 방 카드 목록 전체를 리스트로 표출.
        - **[SCR-005] 방 상세**: `Half` 높이는 [SCR-004]의 `공동방 1개 Half`(348dp)와 동일하다.
        - **[SCR-006] 장소 상세**: 높이 369dp(고정값)를 유지한다.
    - 시트는 **바텀 네비게이션 위로 드래그**해 승격한다.
- **커스텀 핀 마커 (Custom Pin Marker)**
    - 지도 상에 장소 위치를 나타내는 아이콘. 형태는 고정 커스텀 에셋이며, **속한 방의 대표 색상에 따라 동적으로 색이 바뀐다.**
- **현재 위치 버튼 (My Location Button)**
    - 지도를 옮겨 본 뒤 카메라를 내 현재 위치로 되돌리는 버튼. [SYS-004]가 제공하며, 지도를 쓰는 화면에서 공통으로 노출된다.
    - **배치**: 지도 우측 하단. 3단 바텀시트 높이에 연동해 위아래로 움직이고, `Full`에서는 숨긴다.
- **방 캐릭터 & 방 뱃지 (Room Character & Badge)**
    - 방마다 부여되는 캐릭터 일러스트와, 홈 탭 상단에 현재 방 이름을 표시하는 뱃지(칩).
    - **역할**: 홈 탭에서 캐릭터 또는 뱃지를 클릭하면 방 변경 바텀시트가 열린다. 방을 바꾸면 캐릭터와 뱃지가 해당 방의 것으로 교체된다.
- **방 전환 툴팁 (Room Transition Tooltip)**
    - 방이 바뀐 직후 상단에 뜨는 안내 툴팁. 노출 후 투명도가 낮아지며 부드럽게 사라진다. (유지 시간 5초)
- **공동방 생성 유도 (Nudge & Ghost Card)**
    - 공동방이 하나도 없는 사용자에게 공동방 생성을 권하는 두 가지 장치.
    - **Nudge**: [SCR-004] 방 리스트 탭 진입 시 자동으로 올라오는 생성 유도 바텀시트.
    - **Ghost Card**: 방 리스트 하단에 상시 노출되는 `공동방 만들기` 카드.
- **지연 권한 요청 (Lazy Permission Request)**
    - 앱 시작 시 모든 권한을 몰아 묻지 않고, 해당 기능이 필요한 맥락에서만 OS 권한 팝업을 띄우는 정책. 위치는 지도 노출 시점, 알림은 마이페이지 스위치 조작 시점에 요청한다.

# 2. 목표 / 비목표

## 목표 (MVP 범위)

- **[SYS-001] 공동방 생성 및 편집**: 방 이름·방 설명·12종 대표 색상을 입력해 공동방을 만들고, 방장이 같은 폼으로 방 정보를 수정할 수 있다. 온보딩·방 리스트 탭·홈 탭 방 변경 시트·방 상세에서 공통으로 호출된다.
- **[SYS-002] 외부 공유 수신**: 인스타그램 등 외부 앱의 공유 시트에서 꾹을 선택해 링크를 넘기면, 링크가 분석되어 원하는 방에 장소로 저장된다.
- **[SYS-003] 장소 복제 & 방 선택**: 보고 있던 화면을 벗어나지 않고, 이미 저장된 장소를 내가 속한 다른 방에 복제할 수 있다.
- **[SYS-004] 지도 & 마커**: 위치 권한 여부에 따라 지도를 초기화하고, 방 대표 색상과 중복 저장 여부를 반영한 커스텀 마커로 장소를 표시한다. 지도를 옮긴 뒤에도 버튼 한 번으로 현재 위치로 되돌아올 수 있다.
- **[SYS-005] 바텀 네비게이션**: 홈·저장·알림·마이페이지 4개 탭을 오가며 각 탭의 상태가 보존되고, 몰입 화면에서는 감춰진다.
- **[SYS-006] 방 초대 링크 생성 & 공유**: 공동방의 초대 링크를 만들어 클립보드 복사 또는 OS 공유 시트로 친구에게 보낼 수 있다.
- **[SYS-007] 방 나가기 & 방장 권한 위임**: 멤버는 확인 후 바로 나가고, 방장은 남은 멤버에게 권한을 위임한 뒤에만 나갈 수 있다.
- **[SYS-008] 외부 장소보기 & 원문보기 연동**: 장소 상세에서 외부 지도 앱으로 장소를 찾아보거나, 저장의 출처가 된 원문 링크를 열 수 있다.
- **[SYS-009] 공동방 생성 유도**: 공동방이 없는 사용자에게 방 리스트 탭 진입 시 Nudge 바텀시트와 Ghost Card로 첫 공동방 생성을 유도한다.
- **[SYS-010] 초대 링크 수신 & 방 참여**: 친구가 보낸 초대 링크를 눌러 앱으로 진입하고 해당 공동방의 멤버가 된다.
- **[SYS-011] 프로필 설정**: 닉네임과 제공 아바타로 프로필을 만들고, 이후 마이페이지에서 같은 화면으로 수정한다. 프로필은 앱 전체에서 하나만 쓴다.
- **[SCR-001] 스플래시**: 앱 실행 시 브랜드 화면을 3초간 노출하고 다음 화면으로 자동 진입한다.
- **[SCR-002] 앱 온보딩**: 프로필 설정 → 첫 공동방 생성 → 친구 초대 → 공유 방법 튜토리얼을 순서대로 거쳐 앱 사용을 시작한다.
- **[SCR-003] 홈 탭 카드 덱 탐색**: 3종 정렬 기준으로 뽑힌 장소 카드를 스와이프로 넘겨보고, 방을 바꿔가며 저장해둔 장소를 다시 꺼내본다.
- **[SCR-004] 방 리스트 탭**: 지도 위 3단 바텀시트로 내 방 전체를 훑고, 방을 골라 상세로 들어가거나 새 공동방을 만든다.
- **[SCR-005] 방 상세**: 한 방에 저장된 장소를 지도·카드형·리스트형으로 탐색하고, 방 편집·친구 초대·나가기를 관리한다.
- **[SCR-006] 장소 상세 & 코멘트**: 장소의 대표 정보와 이미지를 보고, 친구들의 코멘트를 읽고 남기며, 다른 방에 공유하거나 외부 앱으로 열어본다.
- **[SCR-007] 알림 탭**: 저장·지역·상황·초대 참여 5종 알림을 시간순으로 확인하고, 알림에서 대상 화면으로 바로 이동한다.
- **[SCR-008] 마이페이지 & 환경설정**: 프로필을 수정하고 다크모드·알림·위치 설정을 관리하며 약관과 앱 리뷰에 접근한다.

## 비목표 (MVP 제외 범위)

- **앱 내 URL 직접 입력 UI**: 장소 추가는 [SYS-002] 외부 공유 시트 수신으로 일원화한다.
- **소셜 로그인 / OAuth 2.0**: 회원가입 절차 없이 디바이스 기반 세션을 사용한다.
- **방 직접 삭제(폭파) 버튼**: 명시적 삭제 버튼 대신 `방 나가기 + 방장 위임`([SYS-007]) 구조로 대체한다.
- **방별 프로필 분리**: [SYS-011]의 단일 공통 프로필을 모든 방에서 함께 사용한다.
- **프로필 이미지 직접 업로드**: 제공되는 아바타 세트 중 선택하는 방식으로 대체한다.
- **앱 내 길찾기·내비게이션**: [SYS-008]로 외부 지도 앱에 넘긴다.

# 3. 화면 플로우별 기능 명세 및 UI/UX 규칙

## ⚙️ 공통 / 독립 시스템 명세

*(최우선 개발 대상)*

### [SYS-001] [공통 명세] 공동방 생성 및 편집 (Create & Edit Group Room)

- **역할:** 방 이름·설명·대표 색상을 다루는 단일 폼. 생성과 편집이 같은 화면을 공유하므로 진입점과 무관하게 하나로 유지한다.
- **사용처:** [SCR-002] 온보딩, [SCR-003] 홈 탭(방 변경 시트), [SCR-004] 방 리스트 탭, [SCR-005] 방 상세(편집)

#### 🔄 서브 플로우 명세

- **Flow A. 방 정보 입력**
    - 생성/편집 화면 진입 ➔ 방 이름 입력(`방 이름을 입력해 주세요.`) ➔ 방 설명 입력(`어떤 장소들을 모으는 방인가요?`) ➔ 대표 색상 12종 중 1개 선택 ➔ 필수 항목이 모두 채워지면 하단 CTA 활성화
    - **필수 항목은 방 이름 하나다.** 방 설명과 대표 색상은 선택 입력이며, 방 이름만 채워지면 CTA가 활성화된다.
    - **대표 색상을 고르지 않으면 회색이 기본값으로 적용된다.**
    - **글자 수 상한은 방 이름 15자, 방 설명 30자다.** 상한을 넘는 입력은 받지 않는다.
- **Flow B. 입력 오류**
    - 유효하지 않은 값 입력 ➔ 해당 입력 필드에 오류 상태 표시 ➔ CTA 비활성 유지
- **Flow C. 생성 완료 및 진입점별 후속 분기**
    - [완료] 클릭 ➔ 공동방 생성 ➔
    - ➔ **[SCR-002] 온보딩에서 진입 시:** 온보딩의 '친구 초대' 스텝으로 이동
    - ➔ **[SCR-003] 홈 탭 방 변경 시트에서 진입 시:** 생성 완료 후 홈 탭으로 돌아와 생성된 방의 덱으로 전환
    - ➔ **[SCR-004] 방 리스트 탭에서 진입 시:** 생성된 방의 [SCR-005] 방 상세로 이동
- **Flow D. 방 편집 (방장 전용)**
    - [SCR-005] 방 상세 더보기 ➔ [편집] 클릭 ➔ Flow A와 동일한 폼에 기존 값이 채워진 상태로 진입 ➔ 값 수정 ➔ [편집 완료] 클릭 ➔ 방 상세로 복귀하며 완료 스낵바 표출

### [SYS-002] [공통 명세] 외부 공유 수신 (Shared Link Receiver)

- **역할:** 외부 앱의 공유 시트로 꾹에 전달된 링크를 받아 장소로 변환하고 저장할 방을 고르게 한다. 앱의 유일한 장소 추가 경로다.
- **사용처:** 앱 외부(OS 공유 시트), [SCR-002] 온보딩 튜토리얼

#### 🔄 서브 플로우 명세

- **Flow A. 링크 수신 및 방 선택**
    - 외부 앱에서 [공유] ➔ OS 공유 시트에서 '꾹' 선택 ➔ 링크 수신 및 URL 추출 ➔ 링크 분석 요청 ➔ 내 방 선택 바텀시트 표출 ➔ 방 선택 후 [저장] 클릭 ➔ 저장 완료 피드백 표출 후 시트 닫힘
- **Flow B. 예외 처리**
    - ➔ **이미 같은 방에 저장된 장소일 때:** 중복 저장 안내 후 저장하지 않음
    - ➔ **링크 분석에 실패했을 때:** 오류 안내 후 저장하지 않음

### [SYS-003] [공통 명세] 장소 복제 & 방 선택 (Place Replication & Room Selector)

- **역할:** 보고 있는 장소를 내가 속한 다른 방으로 복제할 때 공통 호출되는 시트. 탐색 중이던 화면 Context를 유지한다.
- **사용처:** [SCR-005] 방 상세, [SCR-006] 장소 상세

#### 🔄 서브 플로우 명세

- **Flow A. 방 선택 및 복제 실행**
    - [다른 방에 공유] 클릭 ➔ 지도 위 3단 바텀시트로 내 방 목록 표출(`Peek`/`Full`) ➔ 대상 방 선택 ➔ 복제 실행 ➔ 공유 완료 피드백(토스트/스낵바) 표출 ➔ **현재 화면 그대로 유지(대상 방으로 이동하지 않음)**
    - 이미 해당 장소가 저장되어 있는 방은 선택할 수 없도록 비활성 처리한다.

### [SYS-004] [공통 명세] 지도 뷰어 및 마커 시스템 (Map & Marker System)

- **역할:** 지도 기반 화면이 공통으로 쓰는 카메라 초기화와 마커 색상 판별 규칙.
- **사용처:** [SCR-004] 방 리스트 탭, [SCR-005] 방 상세, [SCR-006] 장소 상세, [SYS-003] 장소 복제

#### 🔄 서브 플로우 명세

- **Flow A. 지도 초기화 및 위치 권한**
    - 지도가 실제로 화면에 그려지는 시점 ➔ OS 위치 권한 팝업 표출 ➔
    - ➔ **허용:** 내 현재 위치를 중심점으로 세팅
    - ➔ **거부:** 기본 디폴트 좌표를 중심점으로 세팅 *(※ 현재 강남역으로 임시 지정, 추후 변경될 수 있음)*
- **Flow B. 마커 색상 판별**
    - **단일 방에만 저장된 장소:** 해당 방의 대표 색상 마커
    - **여러 방에 중복 저장된 장소:** 가장 최근에 저장한 방의 대표 색상 마커를 기본 표시 ➔ 방을 전환하면 그 방의 대표 색상으로 변경
    - **중복 장소 마커 클릭 시:** 방 선택 모달과 [SCR-006] 장소 상세 `Half` 바텀시트를 **함께** 노출한다. 모달에서 방을 바꿀 때마다 아래의 장소 상세도 그 방 기준으로 갱신된다.
        - `TBD:` 두 레이어가 겹친 상태의 배치·전환 등 구체 명세는 아직 확정되지 않았다.
- **Flow C. 화면별 지도 사용 형태**
    - **[SCR-004] 방 리스트 탭:** 내 모든 방의 장소 마커를 한 지도에 표시
    - **[SCR-005] 방 상세:** 해당 방에 저장된 장소만 표시
    - **[SCR-006] 장소 상세:** 선택한 장소를 중심으로 표시
- **Flow D. 현재 위치로 이동**
    - 지도 위 [현재 위치] 버튼 클릭 ➔
    - ➔ **위치 권한이 있을 때:** 카메라를 내 현재 위치로 이동
    - ➔ **위치 권한이 없을 때:** Flow A의 권한 요청을 다시 태우고, 허용되면 현재 위치로 이동
    - **버튼은 지도 우측 하단에 두고, 3단 바텀시트 높이에 연동해 위아래로 움직인다.** 시트가 `Full`로 승격되면 숨긴다.

### [SYS-005] [공통 명세] 바텀 네비게이션 시스템 (Bottom Navigation System)

- **역할:** 메인 탭 4개(홈·저장·알림·마이페이지) 간 이동과 탭별 상태 유지를 담당하는 최상위 시스템 UI.
- **사용처:** [SCR-003] 홈 탭, [SCR-004] 방 리스트 탭, [SCR-007] 알림 탭, [SCR-008] 마이페이지

#### 🔄 서브 플로우 명세

- **Flow A. 탭 전환 및 상태 보존:** 탭 전환 시 각 탭의 스크롤·필터·시트 높이 상태를 유지한다.
- **Flow B. 비노출 조건:** [SCR-005] 방 상세, [SCR-006] 장소 상세 등 몰입 화면과 3단 바텀시트가 `Full`로 승격된 상태에서는 감춘다.

### [SYS-006] [공통 명세] 방 초대 링크 생성 및 공유 (Room Invite & Link Sharing)

- **역할:** 공동방에 타인을 초대할 때 공통 호출되는 초대 링크 생성 및 공유 진입점.
- **사용처:** [SCR-002] 온보딩, [SCR-005] 방 상세

#### 🔄 서브 플로우 명세

- **Flow A. 초대 링크 생성 및 공유**
    - [친구 초대] 클릭 ➔ 해당 방의 초대 링크 생성 ➔
    - ➔ **[초대 링크 복사] 선택:** `클립 보드에 복사되었어요.` 토스트 표출 후 1.5초 뒤 다음 화면으로 자동 이동
    - ➔ **[공유하기] 선택:** OS 공유 시트 연동(카카오톡·문자 등)

### [SYS-007] [공통 명세] 방 나가기 및 방장 권한 위임 (Room Exit & Owner Delegation)

- **역할:** 방 나가기 시 역할과 멤버 수에 따라 확인·위임 절차를 분기하는 공통 정책.
- **사용처:** [SCR-005] 방 상세

#### 🔄 서브 플로우 명세

- **Flow A. 일반 멤버 나가기**
    - [방 나가기] 클릭 ➔ 확인 모달 표출(`나가면 이 방을 더 이상 볼 수 없어요. 방의 장소와 댓글은 그대로 남아요.`) ➔ [나가기] 클릭 ➔ 탈퇴 처리 후 [SCR-004] 방 리스트 탭으로 이동
- **Flow B. 방장 나가기**
    - 방장이 [방 나가기] 클릭 ➔ 확인 모달 표출 ➔ [나가기] 클릭 ➔
    - ➔ **1인 공동방:** 위임 절차 없이 즉시 방 삭제 및 탈퇴 처리
    - ➔ **N인 공동방:** 위임 모달 표출(`방장은 나가기 전에 다른 멤버에게 방장을 넘겨야 해요` / `선택한 멤버가 앞으로 이 방을 관리해요.`) ➔ 멤버 목록에서 1인 선택(필수) ➔ [다음] 클릭 ➔ 권한 위임 후 탈퇴 처리
- **Flow C. 개인방:** 나가기 메뉴 자체를 노출하지 않는다.

### [SYS-008] [공통 명세] 외부 장소보기 및 원문보기 연동 (External Link Launcher)

- **역할:** 장소 상세에서 앱 밖의 정보로 나가는 두 가지 경로를 담당한다.
- **사용처:** [SCR-006] 장소 상세

#### 🔄 서브 플로우 명세

- **Flow A. 장소보기**
    - [장소보기] 클릭 ➔ 외부 지도 앱 설치 여부 확인 ➔
    - ➔ **설치됨:** 외부 지도 앱에서 해당 장소 검색 결과로 이동
    - ➔ **미설치:** 외부 웹 브라우저에서 해당 장소 검색 결과로 Fallback 이동
- **Flow B. 원문보기**
    - [원문보기] 클릭 ➔ 이 장소가 저장될 때 사용된 원본 링크(SNS 게시물 등)를 외부 앱 또는 브라우저로 연다.

### [SYS-009] [공통 명세] 공동방 생성 유도 (Create Group Room Nudge)

- **역할:** 공동방이 하나도 없는 사용자를 첫 공동방 생성으로 밀어주는 유도 장치. 개인방만으로는 서비스의 공유 가치를 경험할 수 없기 때문에 별도 시스템으로 분리한다.
- **사용처:** [SCR-003] 홈 탭, [SCR-004] 방 리스트 탭

#### 🔄 서브 플로우 명세

- **Flow A. Nudge 바텀시트 (방 리스트 탭 진입 시)**
    - 공동방 0개 상태로 [SCR-004] 방 리스트 탭 진입 ➔ 생성 유도 바텀시트 자동 표출(`공동방을 생성해보세요!` / `"저번에 말한 거기가 어디였지?" 더 이상 묻지 마세요.`) ➔
    - ➔ **[공동방 만들기] 클릭:** [SYS-001] 호출
    - ➔ **[나중에 만들래요] 클릭:** 시트 닫힘, 방 리스트 유지
- **Flow B. Ghost Card (방 리스트 하단)**
    - 공동방 0개 상태에서 방 리스트 하단에 `공동방 만들기` Ghost Card 상시 노출 ➔ 클릭 시 [SYS-001] 호출
- **Flow C. 홈 탭 빈 상태 CTA**
    - 볼 수 있는 장소가 하나도 없을 때 홈 탭에 빈 상태 안내 표출 ➔ CTA 클릭 시 [SYS-001] 호출
- **Flow D. 해제 조건:** 공동방이 1개 이상 존재하면 Flow A~C를 모두 노출하지 않는다.

### [SYS-010] [공통 명세] 초대 링크 수신 및 방 참여 (Invite Link Receiver)

- **역할:** [SYS-006]으로 만들어진 초대 링크를 받은 쪽의 경로. 링크 클릭에서 방 멤버가 되기까지를 담당한다.
- **사용처:** 앱 외부(딥링크), [SCR-005] 방 상세

#### 🔄 서브 플로우 명세

- **Flow A. 초대 링크 진입**
    - 친구가 보낸 초대 링크 클릭 ➔ 꾹 앱으로 진입 ➔
    - ➔ **앱 미설치:** 스토어로 이동 후 설치·최초 실행 시 초대 대상 방으로 연결

### [SYS-011] [공통 명세] 프로필 설정 (Profile Setup)

#### 🔄 서브 플로우 명세

- **Flow A. 프로필 입력**

### [SCR-003] 홈 탭 - 장소 카드 덱 탐색 (Home - Place Card Deck)

- **시스템 연동:** [SYS-001] 공동방 생성, [SYS-005] 바텀 네비게이션, [SYS-009] 공동방 생성 유도.

#### 🔄 서브 플로우 명세

- **Flow A. 메인 - 카드 덱 스와이프 탐색**

    - 카드는 장소명·주소·대표 이미지·카테고리 태그·등록자를 담으며, 카드의 [...]에서 장소 액션에 접근한다.
- **Flow B. 정렬 기준 변경**

- **Flow D. 카드 소진 & 자동 방 전환**
    - 새로고침 없이 10장을 모두 소진 ➔ 다음 방의 덱 자동 로드 ➔ 방 전환 툴팁 노출 후 자연스럽게 사라짐
- **Flow E. 수동 방 변경**

    - ➔ **[방 만들기] 선택:** [SYS-001] 호출
- **Flow F. 빈 상태**
    - 볼 수 있는 장소가 없을 때 안내 표출(`꾹 눌러둔 장소, 다시 꺼내볼까요?`) ➔ CTA 클릭 시 [SYS-009] Flow C로 연결

### [SCR-004] 방 리스트 탭 (Room List Tab)

- **시스템 연동:** [SYS-001] 공동방 생성, [SYS-004] 지도/마커, [SYS-005] 바텀 네비게이션, [SYS-009] 공동방 생성 유도.

#### 🔄 서브 플로우 명세

- **Flow A. 메인 - 지도 & 3단 바텀시트 탐색**

- **Flow C. 신규 공동방 생성**
    - 시트 우상단 [+] 클릭 ➔ [SYS-001] 호출 ➔ 생성 완료 후 [SCR-005] 방 상세로 직행
- **Flow D. 공동방 0개 상태**

- **방 정체성의 일관된 표현:**

## 확정된 항목

- **Q**: [SYS-001] 공동방 생성 폼의 필수 입력 범위와 글자 수 상한은 어디까지인가?
  → **A**: 필수는 **방 이름 하나**. 방 설명·대표 색상은 선택 입력이며, 색상을 고르지 않으면 **회색**이 기본값이다. 글자 수 상한은 **방 이름 15자 / 방 설명 30자**. *(디자인 노드 `2336-58718`에서 `*` 필수 표기가 모두 hidden 상태임을 확인)*
- **Q**: 동적 GPS 버튼(현재 위치 이동)을 MVP에서 제외할 것인가?
  → **A**: **제외하지 않고 MVP에 포함**한다. 지도 우측 하단에 두고 3단 바텀시트 높이에 연동해 움직이며, `Full`에서는 숨긴다. 비목표에서 [SYS-004] 목표로 옮겼다.
- **Q**: [SCR-007] MVP 알림 유형을 저장 중복·저장 오류 2종으로 한정할 것인가?
  → **A**: **한정하지 않고 5종 모두 MVP에 포함**한다. 저장(중복·오류), 지역 기반, 상황 기반 ①(코멘트 리마인드), 상황 기반 ②(`N명이나 이 장소를 저장했어요!`), 초대 참여.
- **Q**: [SYS-004] 여러 방에 중복 저장된 장소의 마커를 눌렀을 때 방 선택 창을 먼저 띄울 것인가?
  → **A**: 방 선택 모달과 [SCR-006] 장소 상세 `Half` 시트를 **함께** 노출하고, 모달에서 방을 바꿀 때마다 장소 상세도 그 방 기준으로 갱신한다. *(디자인 노드 `1765-84118`)*
- **Q**: [SCR-008] OS 수준에서 이미 거부되어 권한 팝업이 다시 뜨지 않는 경우를 어떻게 처리할 것인가?
  → **A**: 스위치 클릭 시 **OS 앱 설정 화면으로 이동**시켜 사용자가 직접 권한을 켜게 한다.
- **Q**: [SCR-003] 방 전환 툴팁 유지 시간이 3초인가 5초인가?
  → **A**: **5초**.
