# 1. 서비스 개요 및 개발 방향

SNS에서 본 좋은 장소는 "나중에 가봐야지" 하고 링크를 저장해두지만, 정작 약속을 잡을 때는 "저번에 말한 거기가 어디였지?"로 끝난다. 링크는 각자의 DM·저장함에 흩어져 있고, 지도에 찍히지 않으니 어디에 모여 있는지도 알 수 없다.

**꾹(GGUK)** 은 외부 앱에서 공유한 장소 링크를 **방(Room)** 에 모아 지도 위에 함께 쌓고, 그렇게 쌓인 장소를 카드로 다시 꺼내보게 하는 장소 수집·공유 서비스다. 저장은 SNS 공유 시트 한 번으로 끝나고, 꺼내보는 일은 홈 탭의 카드 덱이 대신한다.

본 문서는 꾹의 Android 클라이언트가 무엇을 만드는지에 대한 단일 출처이며, Figma `◆ver.2` 보드([000]~[011])의 화면·User Flow와 `디자인 정책` 보드([000]~[013])의 화면별 상세 주석을 기준으로 작성했다.

## 핵심 원칙

- **저장은 앱 밖에서, 탐색은 앱 안에서**: 장소 추가의 유일한 정식 입구는 외부 앱의 OS 공유 시트다. 앱은 저장된 장소를 지도·카드·리스트로 다시 꺼내 보이는 데 집중한다.
- **상황별 권한 요청 (Contextual Permissions)**: 앱 시작 시 권한을 몰아 묻지 않는다. 위치 권한은 그 위치가 실제로 필요해지는 맥락에서만(지도가 그려지는 저장 탭 최초 진입, 홈 탭의 `가까운순` 전환, 마이페이지 위치 설정 스위치), 알림 권한은 마이페이지에서 사용자가 스위치를 켜는 시점에 요청한다. 자세한 목록은 「지연 권한 요청」을 따른다.
- **비회원 익명 세션**: 회원가입·소셜 로그인 없이 이용자를 구분하고 세션을 유지한다. 구분의 근거는 앱이 만든 기기 식별자가 아니라 **인증 제공자가 발급한 익명 계정 식별자**이며, 서버는 앱이 보낸 값을 그대로 믿지 않고 서명된 증명을 검증해 요청자를 특정한다. 세션은 기기가 아니라 앱 설치에 묶인다 — 앱을 지웠다 다시 설치하면 이전 세션과 그 데이터로 돌아갈 수 없고, 복구 수단도 제공하지 않는다. 약관·개인정보 처리방침도 이 전제 위에 작성한다.
- **방마다 다른 얼굴**: 방은 대표 색상과 캐릭터를 가지며, 마커·뱃지·툴팁·썸네일까지 그 색과 캐릭터로 일관되게 표현한다. 사용자가 "지금 어느 방에 있는지"를 글자가 아니라 색과 캐릭터로 알 수 있게 한다.
- **독립적 카드 소비 경험**: 홈 탭의 카드 덱 인터랙션은 클라이언트 로컬 UI 상태로 관리하며, 다른 멤버의 화면에 영향을 주지 않는다.
- **저장은 되도록 여러 방에 한 번에**: 방 선택은 단일 선택이 아니라 체크박스 복수 선택이다. 외부 공유 수신과 다른 방 공유가 같은 조작 문법을 공유한다.

## 데이터 및 도메인 용어

- **방 (Room)**
    - 장소들을 모아서 저장하고 관리할 수 있는 가상의 공간.
    - 사용자는 여러 개의 방을 생성할 수 있으며, 방마다 고유한 **대표 색상**과 **대표 캐릭터**가 지정된다.
    - **대표 색상**: 지정된 **12종 팔레트**(red / red orange / orange / lime / green / cyan / violet / pink / blue / brown / light blue / purple) 중 1개를 선택한다. 마커·뱃지·툴팁·썸네일 색상의 기준이 된다.
        - **선택은 필수가 아니며, 고르지 않으면 기본값인 회색이 적용된다.** 컬러칩은 복수 선택할 수 없다.
    - [1] 개인방 (Personal Room)
        - 프로필 작성 완료 시 **기본으로 자동 생성되는 사용자 전용 저장 공간**. 방 리스트 최상단에 `내 장소`로 고정된다.
        - **초대 불가**: 다른 멤버를 초대할 수 없으며, 오직 혼자서만 장소를 모으고 관리한다.
        - **삭제/나가기 금지**: 기본으로 제공되는 최상위 개인 공간이므로 삭제·나가기·제거 기능을 어떤 경우에도 제공하지 않는다.
    - [2] 공동방 (Group Room)
        - 사용자가 필요에 따라 **별도로 새로 생성하는 공간**. 방 이름·방 설명·대표 색상을 입력해 만든다.
        - **멤버 초대 가능**: 초대 링크를 생성해 다른 사용자를 초대하고, 장소를 공동으로 추가·관리한다.
        - **방장 권한 및 위임**: 방장이 나가기를 시도할 때 남은 멤버가 있다면 반드시 다른 멤버에게 방장 권한을 위임해야 한다.
- **방 썸네일 (Room Thumbnail)**
    - 방 카드에 노출되는 대표 이미지. 방에 담긴 장소 수에 따라 두 가지 형태를 가진다.
    - **장소 0개**: 방 생성 시 고른 **대표 색상 + 캐릭터 조합**이 그대로 유지된다.
    - **장소 N개**: 방에 저장된 장소들의 이미지가 **콜라주**로 표시되며, 최대 4장까지(1·2·3·4장) 배치된다.
- **방 멤버 아바타 (Room Member Avatars)**
    - 방 카드·방 상세 헤더에 겹쳐 노출되는 멤버 프로필. 인원에 따라 두 가지 형태를 가진다.
    - **4명 이하**: 멤버 아바타를 있는 대로 모두 겹쳐 표시하고, 카운터는 붙이지 않는다.
    - **5명 이상**: **아바타 3개 + 카운터 칩**으로 표시한다.
        - 카운터는 **아바타로 보이지 않는 나머지 인원 수**다. (멤버 7명 → 아바타 3개 + `4`)
        - 나머지 인원이 99명을 넘으면 `99+`로 표기한다.
    - **정렬 기준**: 가장 최근에 장소를 저장한 사람이 **아바타 중 가장 오른쪽**에 오도록 우→좌로 정렬한다. 카운터 칩은 그 아바타의 오른쪽에 붙인다.
- **장소 (Place / Pin)**
    - 사용자가 추가한 실제 지명·주소·위경도 좌표를 가진 위치 데이터. 지도 위에는 커스텀 핀 마커로 표시된다.
    - **구성 요소**: 장소명, 주소, 카테고리, 대표 이미지(복수), 등록자, 원문 링크(공유받은 외부 URL), 코멘트 목록, 저장 경과일.
        - **저장 경과일은 화면에 표시하지 않는다.** `꾹 Pick` 순위를 매기는 판정값으로만 쓰이며([SCR-003] Flow B), 이 값을 노출하는 화면은 없다.
    - **저장 가능 범위**: 현재 **한국 내 장소만** 지원한다. 게시물 **본문에 주소나 장소명이 포함**되어야 하며, **사진 속 장소 인식은 지원하지 않는다.**
    - **중복 규칙 및 마커 색상 정책**
        - **동일한 방 내**: 같은 장소가 중복 저장될 수 없다. 중복 시도는 [SCR-007] 알림함에 중복 저장 알림으로 남는다. 방을 고르는 시점에 미리 막아 보여줄지는 시트마다 다르다 — 「홈 방 시트」는 체크·비활성으로 확정, 「방 선택 시트」는 미정이다.
        - **다른 방 간 중복 저장 시**: 한 장소가 여러 방에 동시에 저장된 경우(중복 장소), 지도에는 **가장 최근에 저장한 방의 대표 색상 마커**를 기본으로 표시한다.
        - **방 전환 시**: 방 선택을 통해 다른 방(예: 파란 방)으로 전환하면 해당 방의 대표 색상 마커로 바뀐다.
- **방장 (Room Owner)**
    - 방을 최초로 생성했거나 방장 권한을 위임받은 사용자.
    - 방 이름, 방 설명, 대표 색상 등 **방의 전체 설정을 변경할 수 있는 권한**을 가진다.
    - **방 나가기 제한**: 방에 다른 멤버가 남아있는 상태에서 방장이 나가기를 시도하면 반드시 다른 멤버에게 방장 권한을 위임해야만 나갈 수 있다.
- **코멘트 (Comment)**
    - 장소에 남기는 텍스트 메모. 같은 방 멤버들에게 공유되며 `친구들의 코멘트`로 노출된다.
    - **입력 제한**: 1회 최대 200자. 국문·영문·숫자·특수문자·공백을 모두 포함해 작성할 수 있다.
    - **작성자 표기**: [SYS-011]에서 설정한 프로필 이미지와 닉네임이 함께 표시된다.
    - **삭제 권한**: **자신이 작성한 코멘트만** 삭제할 수 있다. 방장에게도 남의 코멘트를 지우는 권한은 없다. 삭제 동선은 [SCR-006] Flow F를 따른다.
    - 방을 나가더라도 그 방에 남긴 장소와 코멘트는 방에 그대로 남는다.

## UI / UX 및 화면 구조 용어

- **카드 덱 (Card Deck)**
    - 장소 정보를 한 장씩 보여주는 카드 형태의 탐색 UI. [SCR-003] 홈 탭에서 사용한다.
    - **기본 구성**: 1개 덱당 **최대 10개의 장소 카드**로 구성된다. 방의 장소가 10개 미만이면 있는 만큼만 채운다(4개면 4장, 3개면 3장). **저장 장소가 0개인 방은 건너뛴다.**
    - **스와이프 인식 영역**: 스와이프 제스처는 **화면 우측 영역에서만** 인식한다. 좌측 영역은 스와이프 대상이 아니다.
    - **스와이프 방향별 동작** (우측 영역 내에서)
        - **좌 → 우 드래그**: 현재 장소를 넘긴다(덱에서 제거하고 다음 카드 노출).
        - **우 → 좌 드래그**: 바로 이전에 넘겼던 카드를 되돌린다(Undo).
    - **카드 액션 메뉴**: 카드의 [...] 버튼에서 `다른 방 저장`과 `장소 가리기` 두 가지에 접근한다.
    - **동적 새로고침 Floating Button**: 덱의 10장 중 **8장 이상을 소진한 시점**(잔여 2개 이하)에 노출되며, 클릭 시 방금 본 카드를 제외한 같은 방의 새 10개 카드로 덱을 다시 채운다.
    - **자동 방 전환 (Room Transition)**: 새로고침 버튼을 누르지 않고 덱을 모두 소진하면 **현재 정렬 기준 안에서** 다음 방의 덱으로 자동 전환된다. 저장 장소가 0개인 방은 건너뛴다.
    - **자동 정렬 전환 (Sort Transition)**: 현재 정렬 기준에서 더 볼 방이 없으면 정렬 기준을 `꾹 Pick` → `최신순` → `가까운순` 순서로 자동 전환해 같은 방식으로 덱을 이어 노출한다. **`가까운순`까지 모두 소진했을 때에만** 완료 안내 화면으로 전환된다. 상세 규칙은 [SCR-003] Flow E를 따른다.
    - **시작 방**: 앱 최초 실행 시에는 개인방(`내 장소`)의 덱으로 시작하고, 이후에는 **마지막으로 보던 방**의 덱으로 시작한다.
- **홈 카드 덱 정렬 기준 (Home Deck Sorting)**
    - 홈 탭 카드 덱에 어떤 장소를 담을지 결정하는 3종 기준. 모든 기준은 **후보 집합 내의 순위**로 정렬하며, 기본값은 `꾹 Pick`이다.
    - **꾹 Pick**: **장소 저장일 기준 경과일이 오래된 상위 30%** 장소를 노출한다. 순위 판정값인 경과일은 사용자가 홈 카드 덱에서 그 카드를 넘겨 확인하면 0일로 초기화된다([SCR-003] Flow B).
    - **최신순**: 현재일 기준 **최근 14일 이내**에 저장된 장소.
    - **가까운순**: 내 현재 위치 기준 **반경 3km 이내**의 장소. 위치 권한이 필요하다([SYS-004] Flow A).
- **목록 정렬 기준 (List Sorting)**
    - [SCR-004] 방 리스트 탭과 [SCR-005] 방 상세의 지도 위 정렬 드롭다운. **5종**이며 기본값은 `전체`다.
    - `전체` 전체 노출 / `꾹 Pick` 장소 저장일 기준 경과일이 오래된 상위 30% / `최신순` 저장 시각 기준 / `거리순` 내 기준 반경 3km 이내 / `코멘트순` 코멘트 수 상위 30%
    - `꾹 Pick`의 판정 기준은 「홈 카드 덱 정렬 기준」과 동일하다. 단 [SCR-003] Flow B의 경과일 초기화는 **홈 카드 덱에서만** 일어나며, 이 목록 정렬에는 적용하지 않는다.
- **카테고리 필터 (Category Filter)**
    - 지도 위 장소 유형 칩. **`전체` / `카페` / `음식점` 3종 고정**이며 기본값은 `전체`다. 선택한 카테고리의 장소만 지도·목록에 표시한다.
- **장소분류 라벨 (Place Category Label)**
    - 장소 하나가 지금 왜 눈에 띄는지를 한 마디로 붙여주는 표시. **4종 고정**이며, 판정값은 모두 **그룹 내의 순위**로 매긴다.
        - `친구들이 많이 본 곳`: 클릭수 상위
        - `이야기 많은 곳`: 코멘트수 상위
        - `여럿이 저장한 곳`: 중복 저장 데이터 상위(여러 방에 저장된 장소)
        - `가볼 만한 곳`: **위 세 라벨 어디에도 걸리지 않은 장소 중 가장 오래된 게시물**을 랜덤으로 고른다. 라벨이 없는 장소를 위한 기본값 자리다.
    - **「카테고리 필터」와 다른 축이다.** 카테고리 필터는 장소의 종류(`카페`·`음식점`)를 고르는 필터이고, 이 라벨은 장소에 붙는 성격 표시로 필터 대상이 아니다.
    - **「홈 카드 덱 정렬 기준」과도 다른 축이다.** 덱에 어떤 장소를 담을지는 정렬 기준 3종이 정하고, 라벨은 담긴 장소마다 붙는 표시다.
    - [SCR-003] 홈 카드 덱에서 부여되며, [SCR-006] 장소 상세는 **홈에서 부여된 값을 그대로 표시한다.** 장소 상세가 따로 판정하지 않는다.
- **3단 바텀시트 (3-Step BottomSheet)**
    - 지도 화면 위에서 높이가 3단계(`Peek`/`Half`/`Full`)로 조절되는 레이어 UI. [SCR-004] 방 리스트 탭, [SCR-005] 방 상세, [SCR-006] 장소 상세에서 사용한다.
    - **높이는 화면 비율이 아니라 화면·상태별 고정 dp 값이다.** 담기는 콘텐츠(헤더·칩·카드 개수)에 따라 화면마다 값이 다르다.
        - **[SCR-004] 방 리스트**
            - `Peek`: 88dp(고정값, 바텀 네비게이션 높이 제외) — 헤더(방 리스트 + 방 생성 아이콘 버튼 영역)만 표시.
            - `Half` (공동방 0개, 개인방만): 256dp(고정값) — 헤더 + 칩 + 개인방 카드.
            - `Half` (공동방 1개): 360dp(고정값) — 위 구성 + 공동방 카드 1개.
            - `Half` (공동방 N개 이상): 380dp(고정값) — 위 구성 + 공동방 카드(세로 스크롤, 스크롤 어포던스를 위해 3번째 카드는 잘리게 표시).
            - `Full`: 전체 화면으로 확장, 방 카드 목록 전체를 리스트로 표출.
            - **진입 기본값은 `Half`다** — 바텀 네비게이션 `저장` 탭으로 들어오면 `Peek`이 아니라 `Half`로 열려, 지도와 방 목록을 함께 보여준 상태에서 탐색을 시작한다.
        - **[SCR-005] 방 상세**: `Peek` 88dp, `Half` 256dp(고정값)이며 진입 시 기본값은 `Half`다.
        - **[SCR-006] 장소 상세**: `Half` 높이 369dp(고정값)를 유지한다.
    - 시트는 **바텀 네비게이션 위로 드래그**해 승격한다.
- **방 선택 시트 (Room Picker Sheet)**
    - 장소를 담을 방을 고르는 **리스트형** 시트. [SYS-002] 외부 공유 수신과 [SYS-003] 다른 방에 공유가 같은 카드 목록·선택 규칙을 공유하되, **높이 단계와 CTA 문구는 서로 다르다.** [SCR-003] 홈 탭은 이 시트를 쓰지 않는다(「홈 방 시트」 참고).
    - **방 카드 구성**: 썸네일 · 방 이름 · 방 설명 · 저장된 장소 수 + 체크박스. **[SCR-004] 방 리스트 탭의 방 카드와 달리 멤버 아바타는 넣지 않는다.**
    - **복수 선택**: 방 카드마다 체크박스가 있어 여러 방을 한 번에 고를 수 있다. 하나라도 선택해야 CTA가 활성화된다.
    - **CTA 문구**: [SYS-002]는 `저장하기`(새 장소를 담는 행위), [SYS-003]은 `공유하기`(이미 있는 장소를 넘기는 행위). 동작이 다르므로 문구도 나눈다.
    - **이미 저장된 방**: `TBD:` [SYS-002]가 링크 분석을 저장 이후로 미루면서(→ [SYS-002] Flow A) 시트를 그리는 시점에는 중복 여부를 알 수 없게 됐다. 이 시트에서 중복 방을 어떻게 다룰지는 §5 미확정 항목으로 남긴다. **[SCR-003] 홈 방 시트는 이 미정과 무관하게 체크·비활성으로 확정**이다.
    - **높이(하단 Action Area 포함, 고정값)**
        - **[SYS-002] 외부 공유 — 2단**: `Peek` 436dp(카드 2개 온전 + 1개 잘림) / `Full`(방 4개) 612dp / `Full`(방 5개 이상) 644dp
            - `Full`(방 5개 이상)에서는 스크롤 어포던스를 위해 5번째 카드가 잘리게 보인다.
            - **방 개수가 적어도 단계 구성은 같다.** 방 3개 이하를 단일 단계로 고정하지 않는다.
        - **[SYS-003] 다른 방에 공유 — 단일 고정**: `Full` **676dp 하나만 사용한다.** `Peek` 단계도, 방 개수에 따른 높이 변화도 없다.
            - 방이 4개를 넘으면 시트 높이는 그대로 두고 **카드 목록만 세로 스크롤**한다.
- **홈 방 시트 (Home Room Sheet)**
    - [SCR-003] 홈 탭 전용 **그리드형** 시트. 방을 70dp 정사각 커버 + 이름으로 3열 배치하며, 첫 칸은 항상 `방 만들기`다. 높이는 **400dp(고정값)**.
    - 「방 선택 시트」와 **다른 시트다.** 체크박스 리스트가 아니고, 카드에 방 설명·장소 수·멤버 아바타가 없다.
    - **두 가지 용도로 쓴다.**
        - **방 변경**: 방을 누르면 즉시 그 방으로 적용된다([SCR-003] Flow F).
        - **다른 방 저장**: 카드 메뉴에서 호출되어 장소를 담을 방을 고른다([SCR-003] Flow C).
    - **이미 저장된 방**: `다른 방 저장`으로 열렸을 때, 그 장소가 이미 있는 방 카드는 **체크(✓) 표시와 함께 비활성**되어 다시 고를 수 없다.
- **커스텀 핀 마커 (Custom Pin Marker)**
    - 지도 상에 장소 위치를 나타내는 아이콘. 형태는 고정 커스텀 에셋이며, **속한 방의 대표 색상에 따라 동적으로 색이 바뀐다.**
    - **4가지 형태**: `기본 핀` / `선택 핀`(장소를 선택했을 때) / `클러스터 1~99`(`50+` 식 표기) / `클러스터 100+`.
- **현재 위치 버튼 (My Location Button)**
    - 지도를 옮겨 본 뒤 카메라를 내 현재 위치로 되돌리는 버튼. [SYS-004]가 제공하며, 지도를 쓰는 화면에서 공통으로 노출된다.
    - **배치**: 지도 우측 하단. 3단 바텀시트 높이에 연동해 위아래로 움직이고, `Full`에서는 숨긴다.
- **방 캐릭터 & 방 뱃지 (Room Character & Badge)**
    - 방마다 부여되는 캐릭터 일러스트와, 홈 탭 상단에 현재 방 이름을 표시하는 뱃지(칩).
    - **표기 규칙**: 공동방은 `{방 이름}방이에요`, 개인방은 `내 장소`로 표기한다. 캐릭터는 뱃지와 같은 높이에 둔다.
    - **역할**: 홈 탭에서 캐릭터 또는 뱃지를 클릭하면 방 변경 바텀시트가 열린다. 방을 바꾸면 캐릭터와 뱃지가 해당 방의 것으로 교체된다.
- **방 전환 툴팁 (Room Transition Tooltip)**
    - 방이 바뀐 직후 상단에 뜨는 안내 툴팁. 노출 후 투명도가 낮아지며 부드럽게 사라진다. (유지 시간 5초)
- **공동방 생성 유도 (Nudge & Ghost Card)**
    - 공동방이 하나도 없는 사용자에게 공동방 생성을 권하는 두 가지 장치.
    - **Nudge**: [SCR-004] 방 리스트 탭(바텀 네비게이션 `저장` 탭) 진입 시 자동으로 올라오는 생성 유도 바텀시트.
    - **Ghost Card**: 방 리스트 하단에 상시 노출되는 `공동방 만들기` 카드.
- **지연 권한 요청 (Lazy Permission Request)**
    - 앱 시작 시 모든 권한을 몰아 묻지 않고, 해당 기능이 필요한 맥락에서만 OS 권한 팝업을 띄우는 정책. 알림은 마이페이지 스위치 조작 시점에 요청한다.
    - **위치 권한을 묻는 맥락은 세 곳이다** — 지도가 실제로 그려지는 시점(저장 탭 최초 진입), [SCR-003] 홈 탭에서 `가까운순`으로 자동 전환하려는 시점, [SCR-008] 마이페이지의 `위치 설정` 스위치 조작 시점. 어디서 허용되든 이후에는 다시 묻지 않는다.

# 2. 목표 / 비목표

## 목표 (MVP 범위)

- **[SYS-001] 공동방 생성 및 편집**: 방 이름·방 설명·12종 대표 색상을 입력해 공동방을 만들고, 방장이 같은 폼으로 방 정보를 수정할 수 있다. 온보딩·방 리스트 탭·홈 방 시트·방 상세·방 선택 시트에서 공통으로 호출된다.
- **[SYS-002] 외부 공유 수신**: 인스타그램 등 외부 앱의 공유 시트에서 꾹을 선택해 링크를 넘기면, 고른 방들에 장소로 저장되고 곧바로 쓰던 앱으로 돌아온다. 링크 분석은 저장을 누른 뒤 뒤에서 돌며 결과는 알림으로 받는다.
- **[SYS-003] 장소 복제 & 방 선택**: 보고 있던 화면을 벗어나지 않고, 이미 저장된 장소를 내가 속한 다른 방들에 한 번에 복제할 수 있다.
- **[SYS-004] 지도 & 마커**: 위치 권한 여부에 따라 지도를 초기화하고, 방 대표 색상·중복 저장 여부·밀집도를 반영한 커스텀 마커로 장소를 표시한다. 지도를 옮긴 뒤에도 버튼 한 번으로 현재 위치로 되돌아올 수 있다.
- **[SYS-005] 바텀 네비게이션**: 홈·저장·알림·마이페이지 4개 탭을 오가며 각 탭의 상태가 보존되고, 몰입 화면에서는 감춰진다.
- **[SYS-006] 방 초대 링크 생성 & 공유**: 공동방의 초대 링크를 만들어 클립보드 복사 또는 OS 공유 시트로 친구에게 보낼 수 있다.
- **[SYS-007] 방 나가기 & 방장 권한 위임**: 멤버는 확인 후 바로 나가고, 방장은 남은 멤버에게 권한을 위임한 뒤에만 나갈 수 있다.
- **[SYS-008] 외부 장소보기 & 원문보기 연동**: 장소 상세에서 외부 지도 앱으로 장소를 찾아보거나, 저장의 출처가 된 원문 링크를 열 수 있다.
- **[SYS-009] 공동방 생성 유도**: 공동방이 없는 사용자에게 방 리스트 탭 진입 시 Nudge 바텀시트와 Ghost Card로 첫 공동방 생성을 유도한다.
- **[SYS-010] 초대 링크 수신 & 방 참여**: 친구가 보낸 초대 링크를 눌러 앱으로 진입하고 해당 공동방의 멤버가 된다.
- **[SYS-011] 프로필 설정**: 닉네임과 제공 아바타로 프로필을 만들고, 이후 마이페이지에서 같은 화면으로 수정한다. 프로필은 앱 전체에서 하나만 쓴다.
- **[SCR-001] 스플래시**: 앱 실행 시 브랜드 화면을 3초간 노출하는 동안 비회원 익명 세션을 확보하고 다음 화면으로 자동 진입한다.
- **[SCR-002] 앱 온보딩**: 프로필 설정 → 첫 공동방 생성 → 친구 초대 → 공유 방법 튜토리얼을 순서대로 거쳐 앱 사용을 시작한다.
- **[SCR-003] 홈 탭 카드 덱 탐색**: 3종 정렬 기준으로 뽑힌 장소 카드를 스와이프로 넘겨보고, 방을 바꿔가며 저장해둔 장소를 다시 꺼내본다.
- **[SCR-004] 방 리스트 탭**: 지도 위 3단 바텀시트로 내 방 전체를 훑고, 방을 골라 상세로 들어가거나 새 공동방을 만든다.
- **[SCR-005] 방 상세**: 한 방에 저장된 장소를 지도·카드형·리스트형으로 탐색하고, 장소를 지우거나 방 편집·친구 초대·나가기를 관리한다.
- **[SCR-006] 장소 상세 & 코멘트**: 장소의 대표 정보와 이미지를 보고, 친구들의 코멘트를 읽고 남기고 내 코멘트를 지우며, 다른 방에 공유하거나 외부 앱으로 열어본다.
- **[SCR-007] 알림 탭**: 저장·지역·상황·방 참여 6종 알림을 시간순으로 확인하고, 알림에서 대상 화면으로 바로 이동한다. 저장에 실패한 이유도 여기서 안내한다.
- **[SCR-008] 마이페이지 & 환경설정**: 프로필을 수정하고 알림·위치 설정을 관리하며 약관·개인정보 처리방침과 앱 리뷰에 접근한다.

## 비목표 (MVP 제외 범위)

- **앱 내 URL 직접 입력 UI**: 장소 추가는 [SYS-002] 외부 공유 시트 수신으로 일원화한다.
- **소셜 로그인 / OAuth 2.0**: 회원가입 절차 없이 익명 세션을 사용한다. 익명 세션을 실제 계정으로 승격해 재설치·기기 변경 후에도 데이터를 이어가는 것 역시 MVP 범위 밖이다.
- **방 직접 삭제(폭파) 버튼**: 명시적 삭제 버튼 대신 `방 나가기 + 방장 위임`([SYS-007]) 구조로 대체한다.
- **방별 프로필 분리**: [SYS-011]의 단일 공통 프로필을 모든 방에서 함께 사용한다.
- **프로필 이미지 직접 업로드**: 제공되는 아바타 세트 중 선택하는 방식으로 대체한다.
- **앱 내 길찾기·내비게이션**: [SYS-008]로 외부 지도 앱에 넘긴다.
- **해외 장소 저장**: 현재 한국 내 장소만 지원하며, 범위 밖 링크는 [SCR-007]의 저장 오류 안내로 사유를 알린다.
- **이미지 기반 장소 인식**: 사진 속 장소는 분석하지 않는다. 본문에 포함된 주소·장소명만 추출한다.
- **저장 값 기반 동적 카테고리 생성**: 카테고리 필터는 `전체`/`카페`/`음식점` 3종 고정으로 한정한다.
- **다크 모드 / 테마 선택**: 앱은 라이트 테마 하나로만 동작한다. OS 다크 모드를 따라가지도, 마이페이지에서 테마를 고르게 하지도 않는다.
- **방 커버 이미지 직접 지정**: 방 썸네일은 대표 색상+캐릭터 또는 저장 장소 이미지 콜라주로 자동 구성한다. *(디자인에 `방 커버 변경 예정` 메모가 있으나 MVP 범위 밖)*

# 3. 화면 플로우별 기능 명세 및 UI/UX 규칙

## ⚙️ 공통 / 독립 시스템 명세

*(최우선 개발 대상)*

### [SYS-001] [공통 명세] 공동방 생성 및 편집 (Create & Edit Group Room)

- **역할:** 방 이름·설명·대표 색상을 다루는 단일 폼. 생성과 편집이 같은 화면을 공유하므로 진입점과 무관하게 하나로 유지한다.
- **사용처:** [SCR-002] 온보딩, [SCR-003] 홈 탭(방 변경 시트), [SCR-004] 방 리스트 탭, [SCR-005] 방 상세(편집), [SYS-003] 다른 방에 공유 시트

#### 🔄 서브 플로우 명세

- **Flow A. 방 정보 입력**
    - 생성/편집 화면 진입 ➔ 방 이름 입력(`방 이름을 입력해 주세요.`) ➔ 방 설명 입력(`어떤 장소들을 모으는 방인가요?`) ➔ 대표 색상 12종 중 1개 선택 ➔ 필수 항목이 모두 채워지면 하단 CTA(`방 생성하기`) 활성화
    - **필수 항목은 방 이름 하나다.** 방 설명과 대표 색상은 선택 입력이며, 방 이름만 채워지면 CTA가 활성화된다.
    - **방 이름은 한글·영문·숫자만 받으며 공백 포함 15자 이내다.** 방 설명은 공백 포함 30자 이내이며, 입력하는 동안 좌측 하단 카운터에 실시간으로 글자 수가 반영된다.
    - **대표 색상을 고르지 않으면 회색이 기본값으로 적용된다.** 컬러칩은 복수 선택할 수 없다.
    - 상단 썸네일 프리뷰에 방 이름·설명·색상 입력이 실시간으로 반영된다.
- **Flow B. 입력 오류**
    - 유효하지 않은 값 입력 ➔ 해당 입력 필드에 오류 상태 표시 ➔ CTA 비활성 유지
    - 방 이름이 오류 상태이면 설명·색상을 채워도 CTA는 계속 비활성이다.
- **Flow C. 생성 완료 및 진입점별 후속 분기**
    - [완료] 클릭 ➔ 공동방 생성 ➔
    - ➔ **[SCR-002] 온보딩에서 진입 시:** 온보딩의 '친구 초대' 스텝으로 이동
    - ➔ **[SCR-003] 홈 탭 방 변경 시트에서 진입 시:** 생성 완료 후 홈 탭으로 돌아와 생성된 방의 덱으로 전환
    - ➔ **[SCR-004] 방 리스트 탭에서 진입 시:** 생성된 방의 [SCR-005] 방 상세로 이동
    - ➔ **[SYS-003] 방 선택 시트에서 진입 시:** 시트로 복귀하며, 새로 만든 방이 개인방 바로 아래(두 번째)에 표시된다
- **Flow D. 방 편집 (방장 전용)**
    - [SCR-005] 방 상세 더보기 ➔ [편집] 클릭 ➔ Flow A와 동일한 폼에 기존 값이 채워진 상태로 진입 ➔ 값 수정 ➔ [편집 완료] 클릭 ➔ 방 상세로 복귀하며 완료 스낵바 표출
- **Flow E. 이탈 경로**
    - **[뒤로가기]:** 온보딩 최초 진입 시에는 [SYS-011] 프로필 설정으로, 그 밖에는 호출한 화면([SCR-004] 방 리스트 / [SYS-003] 다른 방에 공유)으로 되돌아간다.
    - **[건너뛰기]:** 앱 최초 접속(온보딩) 시에만 노출되며, 클릭 시 [SCR-002]의 공유 방법 튜토리얼로 이동한다.

### [SYS-002] [공통 명세] 외부 공유 수신 (Shared Link Receiver)

- **역할:** 외부 앱의 공유 시트로 꾹에 전달된 링크를 받아 장소로 변환하고 저장할 방들을 고르게 한다. 앱의 유일한 장소 추가 경로다.
- **사용처:** 앱 외부(OS 공유 시트), [SCR-002] 온보딩 튜토리얼
    - [SCR-003] 홈 탭 카드의 `다른 방 저장`은 **이 명세가 아니다.** 링크 수신 없이 이미 저장된 장소를 복제하는 경로이며 시트도 다르다([SCR-003] Flow C).

#### 🔄 서브 플로우 명세

- **Flow A. 링크 수신 및 방 선택**
    - 외부 앱에서 [공유] ➔ OS 공유 시트에서 '꾹' 선택 ➔ 링크 수신 및 URL 추출 ➔ **곧바로** 방 선택 시트 표출(`게시물 저장` / `장소를 저장할 방을 선택해주세요.`) ➔ 개인방 + 공동방 전체 목록에서 체크박스로 **복수 선택** ➔ [저장하기] 클릭 ➔ **이 시점에 링크 분석 요청** ➔ 저장 완료 토스트 표출 후 시트가 닫히며 **직전에 쓰던 외부 앱으로 돌아간다**
    - **링크 분석은 시트를 그리기 전이 아니라 [저장하기] 이후에 돈다.** 공유 시트에서 꾹을 고른 직후 대기 화면을 만들지 않기 위해서다. 분석 결과와 실패는 Flow B가 [SCR-007] 알림함으로 알린다.
    - **URL 추출 규칙**: 공유된 텍스트에 URL이 **여러 개면 첫 번째 것만** 쓴다. **URL이 하나도 없으면** 저장을 시작하지 않고 Flow B의 오류 알림으로 넘긴다.
    - 저장 완료 토스트는 `저장이 완료됐습니다.`이며, 체크 아이콘과 함께 **화면 하단에서 40dp 띄운 위치**에 표출한다.
    - 시트 높이·카드 구성·CTA 문구는 「방 선택 시트」 정의를 따른다.
    - `TBD:` 이미 저장되어 있는 방을 시트에서 어떻게 다룰지는 아직 미정이다(§5 참고). 분석이 [저장하기] 이후로 밀리면서 시트를 그리는 시점에는 중복 여부를 판정할 수 없다.
    - 방을 하나도 고르지 않으면 [저장하기]는 비활성 상태다.
- **Flow B. 예외 처리**
    - **방마다 저장은 따로 성립한다.** 여러 방을 골랐을 때 한 방의 실패가 다른 방의 저장을 되돌리지 않으며, 알림도 방 단위로 남는다.
    - ➔ **이미 같은 방에 저장된 장소일 때:** 그 방에는 저장하지 않고, [SCR-007] 알림함에 `이미 저장해둔 곳이에요` 중복 저장 알림을 남긴다
    - ➔ **링크 분석에 실패했을 때:** 저장하지 않고, [SCR-007] 알림함에 `장소를 저장하지 못했어요.` 오류 알림을 남긴다. 실패 사유의 상세 안내는 [SCR-007] Flow D가 담당한다
    - ➔ **공유된 텍스트에 URL이 없을 때:** 같은 오류 알림으로 처리한다

### [SYS-003] [공통 명세] 장소 복제 & 방 선택 (Place Replication & Room Selector)

- **역할:** 보고 있는 장소를 내가 속한 다른 방들로 복제할 때 공통 호출되는 시트. 탐색 중이던 화면 Context를 유지한다.
- **사용처:** [SCR-005] 방 상세, [SCR-006] 장소 상세

#### 🔄 서브 플로우 명세

- **Flow A. 방 선택 및 복제 실행**
    - [다른 방에 공유] 클릭 ➔ 방 선택 시트 표출(`Full` 단일 고정, 단계 전환 없음) ➔ 상단에 대상 장소 카드(첫 번째 썸네일·장소명·주소) 노출 ➔ 개인방 + 공동방 전체 목록에서 체크박스로 **복수 선택** ➔ [공유하기] 클릭 ➔ 복제 실행 ➔ `공유가 완료되었습니다.` 토스트 표출 ➔ **현재 화면 그대로 유지(대상 방으로 이동하지 않음)**
    - 토스트는 체크 이모티콘과 함께 **화면 하단에서 40dp 띄운 위치**에 표출한다. [SYS-002]도 같은 배치를 쓴다.
    - `TBD:` 이미 해당 장소가 저장되어 있는 방을 어떻게 다룰지는 [SYS-002]와 함께 미정이다(§5 참고).
    - 방을 하나도 고르지 않으면 [공유하기]는 비활성 상태다.
- **Flow B. 시트에서 새 방 만들기**
    - 시트의 [새 방 만들기] 클릭 ➔ [SYS-001] 호출 ➔ 생성 완료 후 시트로 복귀 ➔ 새로 만든 방이 개인방 바로 아래에 추가되어 바로 선택할 수 있다

### [SYS-004] [공통 명세] 지도 뷰어 및 마커 시스템 (Map & Marker System)

- **역할:** 지도 기반 화면이 공통으로 쓰는 카메라 초기화와 마커 색상·밀집도 판별 규칙.
- **사용처:** [SCR-003] 홈 탭(위치 권한 요청만), [SCR-004] 방 리스트 탭, [SCR-005] 방 상세, [SCR-006] 장소 상세

#### 🔄 서브 플로우 명세

- **Flow A. 지도 초기화 및 위치 권한**
    - 지도가 실제로 화면에 그려지는 시점(저장 탭 최초 진입) ➔ OS 위치 권한 팝업 표출 ➔
    - ➔ **허용:** 내 현재 위치를 중심점으로 세팅
    - ➔ **거부:** 기본 디폴트 좌표를 중심점으로 세팅 *(※ 현재 강남역으로 임시 지정, 추후 변경될 수 있음)*
    - **지도 없이 위치 권한을 묻는 경로**: [SCR-003] 홈 탭에서 `가까운순`으로 자동 전환하려는 시점([SCR-003] Flow E)에도 같은 OS 팝업을 띄운다. 이 경로는 지도를 그리지 않으므로 중심점 세팅 없이 권한 결과만 사용하며, 거부 시 처리는 [SCR-003] Flow E가 정한다.
- **Flow B. 마커 색상 판별**
    - **단일 방에만 저장된 장소:** 해당 방의 대표 색상 마커
    - **여러 방에 중복 저장된 장소:** 가장 최근에 저장한 방의 대표 색상 마커를 기본 표시 ➔ 방을 전환하면 그 방의 대표 색상으로 변경
    - **중복 장소 마커 클릭 시:** 방 선택 모달과 [SCR-006] 장소 상세 `Half` 바텀시트를 **함께** 노출한다. 모달에서 방을 바꿀 때마다 아래의 장소 상세도 그 방 기준으로 갱신된다.
        - `TBD:` 두 레이어가 겹친 상태의 배치·전환 등 구체 명세는 아직 확정되지 않았다.
- **Flow C. 마커 선택 및 클러스터링**
    - **마커 클릭:** 기본 핀이 선택 핀 형태로 바뀌고, 하단 시트가 [SCR-006] 장소 상세 `Half`로 전환된다.
    - **지도 축소 시:** 핀이 겹치는 구간을 클러스터로 묶는다. **1~99개는 `50+` 식 숫자 표기 클러스터**, **100개 이상은 `100+` 클러스터** 아이콘으로 표시한다.
- **Flow D. 화면별 지도 사용 형태**
    - **[SCR-004] 방 리스트 탭:** 내 모든 방의 장소 마커를 한 지도에 표시하며, 각 마커는 소속 방의 대표 색상을 따른다
    - **[SCR-005] 방 상세:** 해당 방에 저장된 장소만 표시
    - **[SCR-006] 장소 상세:** 선택한 장소를 중심으로 표시
- **Flow E. 현재 위치로 이동**
    - 지도 위 [현재 위치] 버튼 클릭 ➔
    - ➔ **위치 권한이 있을 때:** 카메라를 내 현재 위치로 이동
    - ➔ **위치 권한이 없을 때:** Flow A의 권한 요청을 다시 태우고, 허용되면 현재 위치로 이동. 계속 거부하면 기본 위치(강남역)를 유지한다
    - **버튼은 지도 우측 하단에 두고, 3단 바텀시트 높이에 연동해 위아래로 움직인다.** 시트가 `Full`로 승격되면 숨긴다.

### [SYS-005] [공통 명세] 바텀 네비게이션 시스템 (Bottom Navigation System)

- **역할:** 메인 탭 4개(홈·저장·알림·마이페이지) 간 이동과 탭별 상태 유지를 담당하는 최상위 시스템 UI.
- **사용처:** [SCR-003] 홈 탭, [SCR-004] 방 리스트 탭, [SCR-007] 알림 탭, [SCR-008] 마이페이지

#### 🔄 서브 플로우 명세

- **Flow A. 탭 전환 및 상태 보존:** 탭 전환 시 각 탭의 스크롤·필터·시트 높이 상태를 유지한다.
- **Flow B. 비노출 조건:** [SCR-005] 방 상세, [SCR-006] 장소 상세 등 몰입 화면과 3단 바텀시트가 `Full`로 승격된 상태에서는 감춘다.

### [SYS-006] [공통 명세] 방 초대 링크 생성 및 공유 (Room Invite & Link Sharing)

- **역할:** 공동방에 타인을 초대할 때 공통 호출되는 초대 링크 생성 및 공유 진입점. 초대 링크를 만들어 **OS 공유 시트로 보내거나 클립보드에 복사**하는 두 갈래는 공통이지만, **진입점에 따라 화면 형태·문구·후속 동작이 다르다.**
- **사용처:** [SCR-002] 온보딩(전체 화면), [SCR-005] 방 상세(바텀시트)

#### 🔄 서브 플로우 명세

- **Flow A. 온보딩 진입 — 전체 화면**
    - 온보딩 친구 초대 스텝 진입 ➔ 안내(`친구들을 초대해볼까요?` / `"여기 어때?"는 이제 그만 친구가 들어오면 저장한 장소가 한눈에 모여요. 다음 약속 장소, 여기서 같이 골라요.`) 노출 ➔ 해당 방의 초대 링크 생성 ➔
    - ➔ **[친구 초대하기]:** OS 공유 시트 연동(카카오톡·문자 등)
    - ➔ **[초대 링크 복사]:** `클립 보드에 복사되었어요.` 토스트 표출 후 **1.5초 뒤 다음 온보딩 스텝으로 자동 이동**
    - 아직 방에 아무도 없는 시점이므로 **참여자 목록을 노출하지 않는다.**
    - **이탈 경로** — **[건너뛰기]:** [SCR-002]의 공유 방법 튜토리얼로 이동 / **[뒤로가기]:** [SYS-001] 공동방 생성 화면으로 복귀
- **Flow B. 방 상세 진입 — 바텀시트**
    - [SCR-005] 방 상세의 [친구 +] 클릭 ➔ 높이 424dp(고정값) 바텀시트 표출 ➔
    - **헤더**: 방 커버 아이콘과 방 이름을 표시하고, 우측에 [X] 버튼을 둔다.
    - **참여자 목록**: 현재 방에 참여 중인 멤버의 프로필 이미지와 이름을 표시한다. 참여자가 많으면 **목록 영역만 세로 스크롤**한다.
    - ➔ **[초대하기]:** OS 기본 공유 시트 노출
    - ➔ **[링크 복사하기]:** 초대 링크를 클립보드에 복사하고 `초대 링크를 복사했어요` 토스트 표출. **자동 이동 없이 시트를 유지**해 연속 공유가 가능하다
    - ➔ **[X]:** 시트를 닫고 진입 직전 화면([SCR-005] 방 상세)으로 돌아간다
    - 헤더의 방 커버 아이콘은 「방 썸네일」을 따르며, 별도 지정은 비목표다.

### [SYS-007] [공통 명세] 방 나가기 및 방장 권한 위임 (Room Exit & Owner Delegation)

- **역할:** 방 나가기 시 역할과 멤버 수에 따라 확인·위임 절차를 분기하는 공통 정책.
- **사용처:** [SCR-005] 방 상세

#### 🔄 서브 플로우 명세

- **Flow A. 일반 멤버 나가기**
    - [방 나가기] 클릭 ➔ 확인 모달 표출(`이 방에서 나갈까요?` / `나가면 이 방을 더 이상 볼 수 없어요 방의 장소와 댓글은 그대로 남아요`) ➔ [나가기] 클릭 ➔ 탈퇴 처리 후 [SCR-004] 방 리스트 탭으로 이동
- **Flow B. 방장 나가기**
    - 방장이 [방 나가기] 클릭 ➔ 확인 모달 표출(`방장을 넘기고 나갈까요?` / `방장은 나가기 전에 다른 멤버에게 방장을 넘겨야 해요`) ➔ [나가기] 클릭 ➔
    - ➔ **1인 공동방:** 위임 절차 없이 즉시 방 삭제 및 탈퇴 처리
    - ➔ **N인 공동방:** 위임 모달 표출(`새 방장을 선택해 주세요` / `선택한 멤버가 앞으로 이 방을 관리해요.`) ➔ 멤버 목록에서 1인 선택(필수) ➔ [다음] 클릭 ➔ 권한 위임 후 탈퇴 처리
    - 위임 모달의 멤버 목록은 세로 스크롤 영역(288dp)을 가진다.
- **Flow C. 개인방:** 나가기 메뉴 자체를 노출하지 않는다.

### [SYS-008] [공통 명세] 외부 장소보기 및 원문보기 연동 (External Link Launcher)

- **역할:** 장소 상세에서 앱 밖의 정보로 나가는 두 가지 경로를 담당한다.
- **사용처:** [SCR-006] 장소 상세

#### 🔄 서브 플로우 명세

- **Flow A. 장소보기**
    - [장소보기] 클릭 ➔ 외부 지도 앱 설치 여부 확인 ➔
    - ➔ **설치됨:** 외부 지도 앱에서 해당 장소 검색 결과로 이동
    - ➔ **미설치:** 외부 웹 브라우저에서 해당 장소 검색 결과로 Fallback 이동
- **Flow B. 원문보기**
    - [원문보기] 클릭 ➔ 이 장소가 저장될 때 사용된 원본 링크(인스타그램 게시물 등)를 외부 앱 또는 브라우저로 연다.

### [SYS-009] [공통 명세] 공동방 생성 유도 (Create Group Room Nudge)

- **역할:** 공동방이 하나도 없는 사용자를 첫 공동방 생성으로 밀어주는 유도 장치. 개인방만으로는 서비스의 공유 가치를 경험할 수 없기 때문에 별도 시스템으로 분리한다.
- **사용처:** [SCR-003] 홈 탭, [SCR-004] 방 리스트 탭

#### 🔄 서브 플로우 명세

- **Flow A. Nudge 바텀시트 (방 리스트 탭 진입 시)**
    - 공동방 0개 상태로 바텀 네비게이션 `저장` 탭 클릭 ➔ 생성 유도 바텀시트 자동 표출(`공동방을 생성해보세요!` / `"저번에 말한 거기가 어디였지?" 더 이상 묻지 마세요.`) ➔
    - ➔ **[공동방 만들기] 클릭:** [SYS-001] 호출
    - ➔ **[나중에 만들래요] 클릭:** 시트 닫힘, 방 리스트 유지
- **Flow B. Ghost Card (방 리스트 하단)**
    - 공동방 0개 상태에서 방 리스트 하단에 `공동방 만들기` Ghost Card 상시 노출 ➔ 클릭 시 [SYS-001] 호출
- **Flow C. 홈 탭 빈 상태 CTA**
    - 볼 수 있는 장소가 하나도 없을 때 홈 탭에 빈 상태 안내 표출 ➔ CTA 클릭 시 [SYS-001] 호출
- **Flow D. 해제 조건:** 공동방이 1개 이상 존재하면 Flow A~C를 모두 노출하지 않는다.

### [SYS-010] [공통 명세] 초대 링크 수신 및 방 참여 (Invite Link Receiver)

- **역할:** [SYS-006]으로 만들어진 초대 링크를 받은 쪽의 경로. 링크 클릭에서 방 멤버가 되기까지를 담당한다.
- **사용처:** 앱 외부(딥링크), [SCR-005] 방 상세

#### 🔄 서브 플로우 명세

- **Flow A. 초대 링크 진입**
    - 친구가 보낸 초대 링크 클릭 ➔ 꾹 앱으로 진입 ➔
    - ➔ **앱 미설치:** 스토어로 이동 후 설치·최초 실행 시 초대 대상 방으로 연결
    - ➔ **프로필 미생성 사용자:** [SCR-002] 온보딩의 프로필 설정을 먼저 완료한 뒤 방에 참여
    - ➔ **기존 사용자:** 초대 대상 방에 참여 처리 후 해당 [SCR-005] 방 상세로 이동
- **Flow B. 참여 알림 발송**
    - 참여 처리 완료 ➔ 방의 기존 멤버 전원에게 `{참가자 이름}님이 들어왔어요` 알림, 참가 당사자에게 `방에 참가했어요` 알림을 각각 보낸다 ([SCR-007] Flow B)
- 디자인에 이 플로우는 제목 프레임만 있으나, Flow A의 3분기는 확정 명세로 삼는다.

### [SYS-011] [공통 명세] 프로필 설정 (Profile Setup)

- **역할:** 닉네임과 아바타로 구성된 단일 공통 프로필을 만들고 수정하는 화면. 온보딩과 마이페이지가 같은 화면을 공유한다.
- **사용처:** [SCR-002] 온보딩, [SCR-008] 마이페이지

#### 🔄 서브 플로우 명세

- **Flow A. 프로필 입력**
    - 진입(`친구들에게 어떻게 보일까요?`) ➔ 닉네임 입력 ➔ 제공 아바타 목록에서 1개 선택(`프로필 이미지를 꾸며보세요.`) ➔ 유효한 값이 채워지면 [저장] 활성화
    - **닉네임은 한글·영문 2글자 이상**이어야 하며, 필수 입력이다.
    - 아바타는 하나만 고를 수 있고, 고르는 즉시 상단 프로필 썸네일에 반영된다.
    - **[지우기] 버튼**: 닉네임·아바타 입력을 한 번에 초기화한다.
- **Flow B. 입력 오류:** 유효하지 않은 닉네임 입력 ➔ 오류 상태 표시 및 [저장] 비활성 유지
- **Flow C. 저장 및 후속 분기**
    - [저장] 클릭 ➔ 프로필 저장 ➔
    - ➔ **[SCR-002] 온보딩에서 진입 시:** 개인방(`내 장소`) 자동 생성 후 [SYS-001] 공동방 생성 스텝으로 이동
    - ➔ **[SCR-008] 마이페이지에서 진입 시:** 마이페이지로 복귀하며 앱 전체 프로필 표기에 즉시 반영
- **Flow D. 뒤로가기:** 앱 최초 접속(온보딩) 시에는 비활성이고, [SCR-008] 마이페이지에서 진입했을 때만 활성이다.

## 📱 화면 플로우별 명세

### [SCR-001] 스플래시 (Splash)

#### 🔄 서브 플로우 명세

- **Flow A. 브랜드 노출 및 자동 전환**
    - 앱 실행 ➔ 로고·캐릭터 스플래시 노출 ➔ **3초 뒤 자동으로 다음 화면 이동** ➔
    - ➔ **최초 실행(프로필 없음):** [SYS-011] 프로필 설정으로 시작하는 [SCR-002] 온보딩
    - ➔ **재실행:** 직전 세션의 메인 탭
    - 이 화면은 브랜드 노출과 함께 「비회원 익명 세션」 확보를 맡는다. 첫 서버 요청보다 먼저, 서버 요청과 구분되는 단계로 세션을 확보한다. **재실행은 저장된 세션을 네트워크 없이 복원**하므로 대기가 없고, 세션 확보로 늘어나는 대기는 최초 실행에서만 발생해 3초 노출 안에 흡수된다.
- **Flow B. 세션 확보 실패**
    - 최초 실행인데 네트워크가 없으면 세션을 확보하지 못한다. 이때는 자동 전환하지 않고 실패를 알리며, 앱을 다시 켜지 않아도 같은 화면에서 재시도할 수 있게 한다.
    - 안내 문구는 **연결 문제로 인한 세션 확보 실패**임을 드러낸다. `장소를 불러오지 못했습니다` 류의 데이터 조회 실패 문구로 뭉뚱그리면 사용자가 취할 행동이 어긋난다.
    - `TBD:` 실패 상태에서 사용자를 어디까지 들여보낼지는 미정이다(§5 참고). 재시도 외의 진입을 막을지, 네트워크가 필요 없는 화면만 열지 갈린다.

### [SCR-002] 앱 온보딩 (Onboarding Flow)

- **시스템 연동:** [SYS-001] 공동방 생성, [SYS-002] 외부 공유 수신, [SYS-005] 바텀 네비게이션, [SYS-006] 방 초대 링크, [SYS-011] 프로필 설정.
- **화면 특성:** [SYS-005] 바텀 네비게이션 비노출.

#### 🔄 서브 플로우 명세

- **Flow A. 필수 - 프로필 설정 & 개인방 자동 생성**
    - [SYS-011] 프로필 설정 호출 ➔ [저장] 클릭 ➔ 프로필 생성 및 개인방(`내 장소`) 자동 생성 ➔ **Flow B**로 이동 *(※ 건너뛰기 불가, 뒤로가기 비활성)*
- **Flow B. 선택 - 첫 공동방 생성**
    - [SYS-001] 공동방 생성 폼 노출 ➔
    - ➔ **[방 생성하기] 클릭:** 공동방 생성 ➔ **Flow C**로 이동
    - ➔ **[건너뛰기] 클릭:** Flow C를 건너뛰고 **Flow D**로 직행
- **Flow C. 조건부 선택 - 친구 초대** *(※ Flow B에서 공동방을 만든 사용자에게만 노출)*
    - 초대 안내(`친구들을 초대해볼까요?` / `"여기 어때?"는 이제 그만 친구가 들어오면 저장한 장소가 한눈에 모여요. 다음 약속 장소, 여기서 같이 골라요.`) ➔
    - ➔ **[친구 초대하기] 클릭:** [SYS-006] Flow A 호출 ➔ 링크 복사 토스트 후 1.5초 뒤 **Flow D**로 이동
    - ➔ **[건너뛰기] 클릭:** **Flow D**로 직행
- **Flow D. 선택 - 공유 방법 튜토리얼 (3스텝 + 완료)** *(※ [SYS-002] 외부 공유 수신을 실제 저장 없이 연습시키는 구간)*
    - **Step 1** `SNS 공유 방법` / `아래 공유 버튼을 눌러서 연습해보세요` ➔ 가상 인스타그램 게시글에서 [공유] 버튼 클릭 연습(공유 버튼 위에 툴팁 상시 노출)
    - **Step 2** 공유 대상 목록에서 '꾹' 선택 연습(`공유 대상` 버튼 위에 툴팁 상시 노출)
    - **Step 3** 시스템 공유 시트 노출 ➔ 2초 뒤 자동 전환
    - **완료** 캐릭터 그래픽과 함께 `튜토리얼 완료` / `이제 진짜 SNS 핫플을 공유해보세요` 노출 ➔ 2초 뒤 자동 전환
    - 각 스텝의 [건너뛰기] 또는 완료 ➔ **[SCR-004] 방 리스트 탭**으로 진입 *(※ [SYS-005] 바텀 네비게이션 노출 시작)*

### [SCR-003] 홈 탭 - 장소 카드 덱 탐색 (Home - Place Card Deck)

- **시스템 연동:** [SYS-001] 공동방 생성, [SYS-005] 바텀 네비게이션, [SYS-009] 공동방 생성 유도. *(`다른 방 저장`은 홈 전용 시트를 쓰므로 [SYS-002]·[SYS-003] 어느 쪽도 호출하지 않는다 — Flow C 참고.)*

#### 🔄 서브 플로우 명세

- **Flow A. 메인 - 카드 덱 스와이프 탐색**
    - 홈 진입 ➔ 현재 방의 뱃지·캐릭터와 함께 카드 덱 노출(`꾹 눌러둔 장소, 다시 꺼내볼까요?`) ➔ 화면 우측 영역에서 좌→우 드래그 시 다음 카드 노출 / 우→좌 드래그로 되돌리면 이전 카드 복구 *(좌측 영역은 스와이프 인식 대상이 아니다)*
    - 카드는 **헤더**(등록자 아바타 + 장소분류 라벨 뱃지 + 더보기 `[...]` 버튼), **장소명**, **주소**, **대표 이미지 2칸 그리드**로 구성된다.
        - **저장 경과일은 카드에 표시하지 않는다.** 순위 판정값으로만 쓰인다(Flow B).
        - 등록자는 **아바타 이미지**로만 표시하고 이름 텍스트는 두지 않는다.
    - **시작 방**: 앱 최초 실행 시 개인방(`내 장소`), 이후에는 마지막으로 보던 방.
- **Flow B. 정렬 기준 변경**
    - 상단 정렬 칩(`꾹 Pick` / `최신순` / `가까운순`) 선택 ➔ 해당 기준으로 덱 재로드 및 Undo 이력 초기화
    - 기본값은 `꾹 Pick`이며, 각 기준의 판정 규칙은 「홈 카드 덱 정렬 기준」 정의를 따른다.
    - **경과일 초기화**: 사용자가 카드를 **넘겨 확인한 시점**에 그 장소의 `꾹 Pick` 순위 판정용 경과일이 0일로 초기화되어 후보에서 밀려나고, 경과일이 다시 쌓여 그 방의 오래된 상위 30%에 재진입하면 다시 노출된다.
        - 초기화되는 값은 **`꾹 Pick` 순위 판정값에 한정**한다. 저장 경과일은 어느 화면에도 표시하지 않으므로 사용자에게 보이는 변화는 없으며, `최신순`·`가까운순` 판정에도 영향을 주지 않는다.
        - 되돌리기(우→좌 드래그)로 카드를 복구하면 그 장소의 초기화도 함께 취소된다.
        - 판정 기준인 "확인"은 카드를 넘긴 시점이다. 최상단에 노출만 되고 넘기지 않은 카드, `장소 가리기`로 가린 카드는 확인으로 보지 않는다.
- **Flow C. 카드 액션 메뉴**
    - 카드 [...] 클릭 ➔
    - ➔ **[장소 가리기]:** 해당 장소를 **현재 덱에서만** 제외한다. 덱을 새로 불러오면 다시 후보에 포함된다
    - ➔ **[다른 방 저장]:** 「홈 방 시트」를 호출해 담을 방을 고른다 ➔ 저장 완료 토스트. **이미 그 장소가 있는 방 카드는 체크(✓)된 채 비활성**이라 애초에 고를 수 없다
        - 이 경로는 **[SYS-002]가 아니다.** 링크 수신·분석이 없고 시트도 다르며, 저장 동작 자체는 [SYS-003] 장소 복제와 같다.
- **Flow D. 덱 새로고침**
    - 덱을 대부분 소진 ➔ [장소 더 보기] Floating Button 노출 ➔ 클릭 시 방금 본 카드를 제외한 같은 방의 새 덱 로드 *(노출 임계값과 덱 크기는 「카드 덱」 정의 참고)*
- **Flow E. 카드 소진 & 자동 방·정렬 전환**
    - 새로고침 없이 덱을 모두 소진 ➔ **현재 정렬 기준 안에서** 다음 방의 덱 자동 로드 ➔ 방 전환 툴팁 노출 후 자연스럽게 사라짐
    - 저장 장소가 0개인 방은 건너뛴다.
    - 현재 정렬에서 더 볼 방이 없으면 ➔ **정렬 기준을 다음 단계로 자동 전환**하고 상단 정렬 칩 선택 표시도 새 기준으로 갱신 ➔ 새 정렬의 첫 방부터 같은 방식으로 덱을 이어 노출
        - 전환 순서는 `꾹 Pick` 완료 → `최신순`, `최신순` 완료 → `가까운순`, `가까운순` 완료 → 완료 안내 화면이다. 완료 상태에 도달한 뒤 스스로 `꾹 Pick`으로 되돌아가 순환하지는 않는다.
        - 후보가 0건인 정렬(예: 최근 14일 내 저장 장소가 없는 `최신순`)은 건너뛴다.
        - 자동 정렬 전환 시 Undo 이력은 Flow B와 동일하게 초기화한다.
        - 사용자가 상단 정렬 칩을 직접 고르면 고른 정렬부터 전환 순서를 다시 시작한다.
    - ➔ **`가까운순`으로 전환하려는데 위치 권한이 없을 때:** 그 시점에 위치 권한을 요청한다([SYS-004] Flow A) ➔ **허용**이면 `가까운순` 덱 노출, **거부**면 `가까운순`을 건너뛰고 완료 안내 화면으로 넘어간다
    - **`가까운순`까지 모든 방의 장소를 확인했을 때에만** `꾹 눌러둔 장소를 모두 둘러봤어요` 상태로 전환한다. 이 상태에서는 자동 전환을 더 하지 않으며, 다시 보려면 사용자가 정렬 칩을 고르거나 방을 직접 바꿔야 한다.
    - 볼 수 있는 장소가 애초에 하나도 없는 경우는 이 완료 상태가 아니라 Flow G 빈 상태다.
- **Flow F. 수동 방 변경**
    - 상단 방 뱃지 또는 캐릭터 클릭 ➔ 「홈 방 시트」가 방 변경 용도로 표출 ➔
    - ➔ **방 선택:** 즉시 해당 방으로 적용되어 캐릭터·뱃지가 교체되고, 방 전환 툴팁이 5초 노출 후 페이드아웃되며 덱이 재로드된다
    - ➔ **[방 만들기] 선택:** [SYS-001] 호출
- **Flow G. 빈 상태**
    - 볼 수 있는 장소가 없을 때 안내 표출(`꾹 눌러둔 장소, 다시 꺼내볼까요?` / `"저번에 말한 거기가 어디였지?" 더 이상 묻지 말고, 친구와 함께 장소를 저장해 보세요.`) ➔ [공동방 만들기] CTA 클릭 시 [SYS-009] Flow C로 연결

### [SCR-004] 방 리스트 탭 (Room List Tab)

- **시스템 연동:** [SYS-001] 공동방 생성, [SYS-004] 지도/마커, [SYS-005] 바텀 네비게이션, [SYS-009] 공동방 생성 유도.

#### 🔄 서브 플로우 명세

- **Flow A. 메인 - 지도 & 3단 바텀시트 탐색**
    - 탭 진입 ➔ [SYS-004]로 지도 초기화(위치 권한이 아직 없을 때만 이 시점에 요청 — [SCR-003]이나 [SCR-008]에서 이미 허용됐다면 묻지 않는다) ➔ 내 모든 방의 장소 마커 표시 ➔ 하단 `방 리스트` 시트가 **`Half`로 열림(진입 기본값)** ➔ `Peek`/`Half`/`Full`로 드래그해 탐색 *(단계별 고정 높이는 「3단 바텀시트」 정의 참고)*
    - **진입 기본값은 `Half`다.** 단, [SCR-005] 방 상세에서 [X]로 돌아온 경우는 Flow A의 기본값이 아니라 [SCR-005]의 상태 유지 규칙(방 상세 `Half` → 방 리스트 `Half`, `Full` → `Full`)을 따른다.
    - `Peek`/`Half`: 지도 상단에 목록 정렬 드롭다운(5종)과 카테고리 칩을 두고 마커를 필터링한다. 둘 다 기본값은 `전체`다.
- **Flow B. 방 목록 조회 (`Full`)**
    - 시트를 `Full`로 승격 ➔ 개인방(`내 장소`)이 최상단 고정된 방 카드 목록 노출(방 썸네일·이름·설명·장소 개수·멤버 아바타) ➔ 정렬 칩으로 목록 정렬
    - 방 카드 선택 ➔ [SCR-005] 방 상세로 이동
    - 방 썸네일과 멤버 아바타의 표시 규칙은 「방 썸네일」·「방 멤버 아바타」 정의를 따른다.
    - [나가기(X)] 클릭 ➔ `Half` 상태로 복귀
- **Flow C. 신규 공동방 생성**
    - 시트 우상단 [+] 클릭 ➔ [SYS-001] 호출 ➔ 생성 완료 후 [SCR-005] 방 상세로 직행
- **Flow D. 공동방 0개 상태**
    - 진입 시 [SYS-009] Nudge 바텀시트 표출 및 Ghost Card 노출

### [SCR-005] 방 상세 (Room Detail & Management)

- **시스템 연동:** [SYS-001] 방 편집, [SYS-003] 장소 복제, [SYS-004] 지도/마커, [SYS-006] 초대 링크, [SYS-007] 방 나가기·위임, [SYS-010] 초대 수신.
- **화면 특성:** 몰입감을 위해 [SYS-005] 바텀 네비게이션 비노출.

#### 🔄 서브 플로우 명세

- **Flow A. 메인 탐색**
    - 진입 ➔ 해당 방의 장소만 표시된 지도 + 3단 바텀시트(**진입 기본값은 `Half`**) ➔ 상단에 방 제목·설명·장소 수 인디케이터·멤버 아바타 노출 ➔ 장소 선택 시 [SCR-006] 장소 상세로 이동
    - **더보기 [⋮] 위치**: `Peek` 상태에서만 상단에 표기하고, 그 밖의 상태에서는 하단에 표기한다.
    - **[X] 나가기**: 현재 시트 상태를 유지한 채 [SCR-004] 방 리스트로 돌아간다. (방 상세 `Half` → 방 리스트 `Half`, 방 상세 `Full` → 방 리스트 `Full`)
- **Flow B. 필터 & 뷰 전환**
    - 목록 정렬 드롭다운(5종) 클릭 시 정렬 선택 ➔ 카테고리 칩으로 필터 ➔ 뷰 토글로 **리스트형 ↔ 카드형** 전환 (좌측 아이콘=리스트형, 우측 아이콘=카드형)
- **Flow C. 장소 액션**
    - 장소 카드 [...] 클릭 ➔
    - ➔ **[다른 방에 공유]:** [SYS-003] 호출 ➔ 완료 후 방 상세 유지하며 피드백 토스트 표출
    - ➔ **[장소 삭제]:** 확인 모달 표출(`이 장소를 삭제할까요?` / `장소에 등록된 사진과 댓글이 모두 삭제되며, 다시 되돌릴 수 없어요.`) ➔ 확인 시 해당 방에서만 장소 제거
- **Flow D. 멤버 & 방 관리**
    - **[친구 +] 클릭:** [SYS-006] Flow B 호출 (참여자 목록이 함께 뜨는 바텀시트)
    - **더보기 [⋮] ➔ [편집]** *(방장 전용)*: [SYS-001] Flow D 호출 ➔ 완료 시 스낵바 표출
    - **더보기 [⋮] ➔ [나가기]:** [SYS-007] 호출 (개인방은 메뉴 비노출)

### [SCR-006] 장소 상세 & 코멘트 (Place Detail & Comments)

- **시스템 연동:** [SYS-003] 장소 복제, [SYS-004] 지도/마커, [SYS-008] 장소보기·원문보기.
- **화면 특성:** 지도 위 `Half`/`Full` 바텀시트로 표시되며 [SYS-005] 바텀 네비게이션 비노출.

#### 🔄 서브 플로우 명세

- **Flow A. 장소 상세 조회**
    - 장소 선택 ➔ 마커가 선택 핀으로 전환되며 `Half` 요약 카드 노출 ➔ 위로 드래그 시 `Full` 전환 ➔ 헤더, 액션 버튼 행, 대표 이미지 가로 스크롤, 코멘트 타임라인 조회
    - **헤더 구성**: 등록자 아바타 + 장소분류 라벨 + 우측 [X] 나가기가 한 줄, 그 아래 장소명과 주소가 각각 한 줄이다.
    - **저장 경과일은 표시하지 않는다.** 저장 경과일을 노출하는 화면은 [SCR-003] 홈 카드를 포함해 **어디에도 없다**(「장소」 구성 요소 참고).
    - **장소명·주소가 길 때**: 줄을 늘리지 않고 한 줄을 유지한 채 넘치는 글자를 `...`으로 생략한다.
    - **액션 버튼 행**: [장소보기]·[원문보기]·[다른방에 공유] 3개가 한 줄에 놓이며, 화면 폭을 넘겨 **가로 스크롤**된다.
    - **[X] 나가기**: [SCR-005] 방 상세 `Half`로 복귀한다.
- **Flow B. `Full` 스크롤 헤더**
    - `Full` 상태에서 아래로 스크롤 ➔ 확장형 헤더가 **축소형 헤더**로 변형되어 상단에 고정 ➔ 최상단으로 다시 스크롤하면 확장형으로 복귀
    - **확장형**: Flow A의 헤더 구성 그대로. **축소형**: 장소명과 [X] 나가기만 남긴다.
- **Flow C. 다른 방에 공유:** [다른방에 공유] 클릭 ➔ [SYS-003] 호출 ➔ 완료 후에도 현재 장소 상세 유지
- **Flow D. 외부 연동:** [장소보기] 또는 [원문보기] 클릭 ➔ [SYS-008] 호출
- **Flow E. 코멘트 작성**
    - `친구들의 코멘트` 영역에서 입력(최대 200자, 국문·영문·숫자·특수문자·공백 허용) ➔ 입력창에 `N/200` 글자 수 카운터 표시 ➔ 하단 [등록] 클릭 ➔ 타임라인 최신에 반영
    - 코멘트에는 작성자의 프로필 이미지와 닉네임이 함께 표시된다.
    - 코멘트가 없으면 빈 상태 안내(`아직 코멘트가 없어요!`) 표출
    - **긴 코멘트는 높이 제한 없이 전문을 노출한다.** 자르거나 [더보기]로 접지 않는다. 시안의 140dp는 샘플 내용의 높이일 뿐이다.
- **Flow F. 코멘트 삭제**
    - **내가 쓴 코멘트에만** 우측 [⋮]가 노출된다 ➔ 클릭 시 `댓글 삭제` 한 항목의 메뉴 표출 ➔ 클릭 즉시 삭제되어 타임라인에서 사라진다
    - **확인 모달을 두지 않으며 되돌리기 수단도 없다.**
    - 남이 쓴 코멘트에는 [⋮]가 없어 삭제 진입점 자체가 없다. **방장도 남의 코멘트는 지울 수 없다.**

### [SCR-007] 알림 탭 (Notifications Tab)

- **시스템 연동:** [SYS-002] 외부 공유 수신(중복·오류 알림), [SYS-005] 바텀 네비게이션 세 번째 탭, [SYS-010] 초대 수신(참여 알림).

#### 🔄 서브 플로우 명세

- **Flow A. 목록 조회 및 시간 표기**
    - 알림을 최신순으로 렌더링한다. 각 알림의 시간은 경과에 따라 다르게 표기한다.
        - 1시간 미만: `방금` / 24시간 미만: `N시간 전` / 7일 미만: `N일 전` / 그 이상: `N월 N일`
    - **읽음/안 읽음 상태는 구분해 표시하지 않는다.** 목록은 모든 알림을 같은 형태로 렌더링한다.
    - 알림 권한을 허용하지 않은 사용자에게도 **별도의 권한 유도 UI를 두지 않는다.** 알림 권한을 켜는 경로는 [SCR-008] 마이페이지의 `알림 설정` 스위치 하나다.
- **Flow B. 알림 유형과 이동 (MVP 6종)**

    | 유형 | 노출 조건 | 표시 문구 | 클릭 시 이동 |
    |---|---|---|---|
    | 중복 저장 | 동일한 방에 동일한 장소를 저장 | `이미 저장해둔 곳이에요` + 장소 이름 | [SCR-006] 장소 상세 |
    | 저장 오류 | 조건에 맞지 않는 게시물이거나 알 수 없는 오류 | `장소를 저장하지 못했어요.` + `잠시 후 다시 시도해주세요` | Flow D 안내 화면 |
    | 위치 기반 리마인드 | 위치 권한 허용 사용자, 현재 위치 반경 3km 내 저장 장소 | `근처에 저장한 장소가 있어요` + 장소 이름 | [SCR-006] 장소 상세 |
    | 코멘트 기반 리마인드 | 내가 속한 모든 방의 장소 중 코멘트가 가장 많은 장소 | `코멘트가 제일 많이 달린 장소에요` + 장소 이름 | [SCR-006] 장소 상세 |
    | 공동방 참가 ① | 속한 방에 새 멤버가 추가됨 (기존 멤버 전원 수신) | `{참가자 이름}님이 들어왔어요` + 공동방 이름 | [SCR-005] 방 상세 |
    | 공동방 참가 ② | 방에 새로 참가한 본인만 수신 | `방에 참가했어요` + 공동방 이름 | [SCR-005] 방 상세 |

    - **위치 기반 예외**: 반경 3km 내 대상 장소가 여러 개면 **앱 밖 푸시로** 대표 알림 1건(`근처에 저장한 곳 N개가 있어요` + `반경 3km`)을 보내고, 알림함 목록에는 개별 알림으로만 표시한다.
        - **대표 알림은 목록에 행으로 만들지 않는다.** "대표 알림을 탭하면 알림함 화면으로 이동"은 **앱 밖 푸시를 탭했을 때**의 이동 경로를 뜻한다.
- **Flow C. 빈 상태:** 알림이 하나도 없으면 스팟 일러스트와 함께 `받은 알림이 없어요` 표출
- **Flow D. 저장 오류 안내 화면**
    - 저장 오류 알림 클릭 ➔ 스팟 일러스트와 함께 저장 실패 조건·기술적 한계를 안내한다.
        - `현재 한국 내 장소만 지원됩니다.`
        - `사진 속 장소인식은 아직 지원하지 않습니다`
        - `본문에 주소나 장소명을 포함해주세요`

### [SCR-008] 마이페이지 & 환경설정 (My Page & Settings)

- **시스템 연동:** [SYS-005] 바텀 네비게이션 네 번째 탭, [SYS-011] 프로필 설정.

#### 🔄 서브 플로우 명세

- **Flow A. 프로필 관리:** 프로필 영역의 [연필] 클릭 ➔ [SYS-011] 호출 ➔ [저장] 후 앱 전체에 즉시 반영
- **Flow B. 알림 설정:** `알림 설정` 스위치 클릭 ➔ OS 알림 권한 팝업 표출 ➔ [허용] 시 스위치 ON
- **Flow C. 위치 설정:** `위치 설정` 스위치 클릭 ➔ OS 위치 권한 팝업 표출 ➔ [허용] 시 스위치 ON
- **Flow D. 서비스 정보**
    - `서비스 정보 > 약관 및 동의` 클릭 ➔ 약관 화면으로 이동. **서비스 이용약관**과 **개인정보 처리방침**을 한 화면에서 스크롤로 제공하며, 각각 시행일자를 표기한다.
        - 약관은 **회원가입 없는 익명 세션 기반 이용**을 전제로 작성하고, 처리 항목으로 익명 계정 식별자 / 이용자 입력 정보(닉네임·프로필 이미지·방 이름·저장 장소·댓글·메모) / 자동 생성 정보(접속 일시·이용 기록·오류 기록·앱 버전·OS 정보) / 푸시 알림 토큰 / 기능 사용 시점의 위치정보를 명시한다.
            - `TBD:` 현행 약관·개인정보 처리방침 본문은 **기기 식별자** 전제로 작성되어 있어 개정이 필요하다. 익명 계정 식별자의 발급·보관을 외부 인증 제공자가 맡으므로 처리 위탁·국외 이전 고지가 필요한지도 함께 확인한다.
    - `앱 리뷰 남기기` 클릭 ➔ 스토어의 꾹 페이지로 이동
- **Flow E. 권한 재요청 불가 상태:** 이미 OS 수준에서 거부되어 권한 팝업이 다시 뜨지 않는 경우, Flow B·C의 스위치 클릭은 OS 앱 설정 화면으로 이동시켜 사용자가 직접 권한을 켜게 한다.
    - `TBD:` **알림·위치 두 스위치 모두** 이 유도 UI의 구체적인 형태가 디자인에 없다. [SCR-007]의 권한 유도 배너가 없어지면서 알림에도 대체 경로가 남지 않았으므로, 마이페이지 스위치가 알림·위치 양쪽의 유일한 재요청 진입점이다.

## 🧭 탐색 경험 최적화

- **방 정체성의 일관된 표현:**
  [SCR-003] 홈 탭의 뱃지·캐릭터·전환 툴팁부터 [SCR-004] 방 리스트 탭의 방 썸네일과 [SCR-005] 방 상세의 마커까지, 방의 대표 색상과 캐릭터를 같은 규칙([SYS-004])으로 반복 노출한다. 사용자는 화면 제목을 읽지 않고도 지금 보고 있는 것이 어느 방의 장소인지 알 수 있다.
- **지도 위 3단 바텀시트로 통일된 탐색 문법:**
  [SCR-004] 방 리스트 탭, [SCR-005] 방 상세, [SCR-006] 장소 상세가 모두 `Peek`/`Half`/`Full` 같은 조작 규칙을 공유한다. 화면이 바뀌어도 "위로 끌면 목록, 아래로 내리면 지도"라는 하나의 동작만 익히면 된다.
- **저장 경로의 공통 문법:**
  [SYS-002] 외부 공유 수신과 [SYS-003] 다른 방에 공유가 같은 「방 선택 시트」(체크박스 복수 선택)를 쓴다. 어느 쪽에서 시작하든 "방을 골라 담는다"는 조작이 같고, CTA 문구만 행위에 맞춰 갈린다.
  [SCR-003] 홈 카드의 `다른 방 저장`은 홈의 그리드 시트를 그대로 재사용해 홈 안에서의 문법을 지킨다 — 방 변경과 같은 시트로 방을 고른다.

## 확정된 항목

- **Q**: [SYS-001] 공동방 생성 폼의 필수 입력 범위와 글자 수 상한은 어디까지인가?
  → **A**: 필수는 **방 이름 하나**. 방 설명·대표 색상은 선택 입력이며, 색상을 고르지 않으면 **회색**이 기본값이다. 글자 수 상한은 **방 이름 15자(한글·영문·숫자만, 공백 포함) / 방 설명 30자(공백 포함)**. 컬러칩은 복수 선택 불가. *(디자인 정책 노드 `2314-95264`, `2314-95270`, `2314-95276`)*
- **Q**: 동적 GPS 버튼(현재 위치 이동)을 MVP에서 제외할 것인가?
  → **A**: **제외하지 않고 MVP에 포함**한다. 지도 우측 하단에 두고 3단 바텀시트 높이에 연동해 움직이며, `Full`에서는 숨긴다. 비목표에서 [SYS-004] 목표로 옮겼다.
- **Q**: [SCR-007] MVP 알림 유형을 저장 중복·저장 오류 2종으로 한정할 것인가?
  → **A**: **한정하지 않는다.** 디자인 확정 결과 **6종**이다. 중복 저장, 저장 오류, 위치 기반 리마인드, 코멘트 기반 리마인드, 공동방 참가 ①(기존 멤버 수신), 공동방 참가 ②(참가 당사자 수신). *(디자인 정책 노드 `3037-93062` 외)*
- **Q**: [SCR-007] 알림 5종 각각은 클릭 시 어느 화면으로 이동해야 하는가?
  → **A**: 중복 저장·위치 기반·코멘트 기반은 **[SCR-006] 장소 상세**로, 공동방 참가 ①②는 **[SCR-005] 방 상세**로 이동한다. 위치 기반 대표 알림(복수 건)은 **알림함 화면**으로 이동한다 — 이는 **앱 밖 푸시를 탭한 경우**를 말하며, 알림함 목록 안에는 대표 행을 만들지 않는다. 저장 오류는 저장 실패 사유 안내 화면으로 이동한다. *(디자인 정책 노드 `3037-93062`~`3037-93092`)*
- **Q**: [SCR-007] 알림 탭 목록 명세(최신순 렌더링, 시간 표기, 빈 상태)를 확정할 수 있는가?
  → **A**: **확정.** 최신순 렌더링, 시간 표기는 1시간 미만 `방금` / 24시간 미만 `N시간` / 7일 미만 `N일` / 그 이상 `N월 N일`. 빈 상태는 `받은 알림이 없어요` + 스팟 일러스트. *(디자인 정책 노드 `3037-93098`, `3037-93179`, `3037-90734`)*
  - (4.0.0 정정) 3.1.0까지 함께 적혀 있던 "권한 미허용 사용자에게 상단 유도 배너를 노출하고 닫으면 7일 후 재표시" 규칙은 **철회**한다. 아래 배너 철회 항목 참고.
- **Q**: [SYS-004] 여러 방에 중복 저장된 장소의 마커를 눌렀을 때 방 선택 창을 먼저 띄울 것인가?
  → **A**: 방 선택 모달과 [SCR-006] 장소 상세 `Half` 시트를 **함께** 노출하고, 모달에서 방을 바꿀 때마다 장소 상세도 그 방 기준으로 갱신한다. *(디자인 노드 `1765-84118`)*
- **Q**: [SCR-008] OS 수준에서 이미 거부되어 권한 팝업이 다시 뜨지 않는 경우를 어떻게 처리할 것인가?
  → **A**: 스위치 클릭 시 **OS 앱 설정 화면으로 이동**시켜 사용자가 직접 권한을 켜게 한다.
  - (4.0.0 정정) 3.1.0까지 덧붙어 있던 "알림에 한해서는 [SCR-007] 배너의 `설정 바로가기`가 같은 역할을 한다"는 **성립하지 않는다.** 배너가 철회되어 알림도 마이페이지 스위치가 유일한 재요청 경로다.
- **Q**: [SCR-003] 방 전환 툴팁 유지 시간이 3초인가 5초인가?
  → **A**: **5초**. *(디자인 정책 노드 `3251-202597`)*
- **Q**: [SYS-002]·[SYS-003] 저장 시 방을 하나만 고르는가, 여러 개 고를 수 있는가?
  → **A**: **체크박스 복수 선택**이다. 이미 저장된 방은 체크된 채 비활성으로 표시되고, 하나라도 선택해야 [공유하기]가 활성화된다. [SYS-003] 시트에는 `새 방 만들기` 버튼이 있어 시트를 벗어나지 않고 방을 만들 수 있다. *(디자인 정책 노드 `2400-268908`, `2792-175985`, `2400-268902`)*
  - (4.1.0 정정) 복수 선택과 `새 방 만들기`는 그대로다. 다만 **"이미 저장된 방 = 체크된 채 비활성"은 이 시트에서 철회**해 미확정으로 되돌렸고(아래 미확정 항목), **CTA 문구는 [SYS-002] `저장하기` / [SYS-003] `공유하기`로 갈렸다.**
- **Q**: `◆ver.2` 보드의 `[006]`은 결번인가 미반영인가?
  → **A**: **결번**이다. 디자인 정책 보드의 섹션 헤더에 남아 있는 `[006] 알림` / `[007] 마이페이지`는 구 넘버링이며, 프레임 이름 기준 현행은 `007 알림` / `008 마이페이지`다.

- **Q**: [SCR-003] 덱을 모두 소진했을 때 어느 시점에 완료 안내 화면을 보여주는가?

- **Q**: [SCR-007] 알림 목록에서 읽음/안 읽음 상태를 구분해 표시하는가?
  → **A**: (4.0.0 확정) **구분하지 않는다.** 목록은 모든 알림을 같은 형태로 렌더링한다. *(알림 탭 spec — 이슈 [#160](https://github.com/mash-up-kr/Team-MINO-Android/issues/160))*
- **Q**: [SCR-003] 홈 탭에서 `가까운순`으로 자동 전환하려는데 위치 권한이 없으면 어떻게 하는가?
  → **A**: (4.0.0 확정) 그 시점에 위치 권한을 요청한다. 허용하면 `가까운순` 덱을 노출하고, 거부하면 `가까운순`을 건너뛰어 완료 안내 화면으로 넘어간다. 이번 개정으로 홈 경로가 새로 늘고, 3.1.0의 「지연 권한 요청」 문구에서 빠져 있던 [SCR-008] 마이페이지 스위치까지 함께 적어 위치 권한을 묻는 맥락은 총 세 곳이 된다. *(spec `docs/specs/home-card-deck/spec.md` 3.0.0)*
- **Q**: 코멘트 삭제 권한을 "본인이 쓴 코멘트만"으로 확정할 수 있는가? 삭제 진입점과 확인 절차는 어떻게 되는가? — 3.1.0까지 디자인에 삭제 동선 미반영
  → **A**: (4.1.0 확정) **본인이 쓴 코멘트만** 삭제할 수 있다. 진입점은 내 코멘트 우측의 [⋮]이고, 메뉴에는 `댓글 삭제` 한 항목만 있다. **확인 모달과 되돌리기를 두지 않고 클릭 즉시 삭제한다.** 방장에게도 남의 코멘트를 지우는 권한은 주지 않는다. [SCR-006] Flow F로 분리해 적었다. *(디자인 노드 `2792-142384`, 메뉴 `3541-131686`)*
- **Q**: [SCR-006] 장소 상세 헤더에 저장 경과일 배지(`저장한 지 N일째`)를 남길 것인가?

- **Q**: [SCR-003] 홈 카드는 실제로 무엇을 담는가? 저장 경과일(`저장한 지 N일째`)이 카드에 있는가?
  → **A**: (4.2.0 확정) **저장 경과일은 카드에 없다.** 실제 카드 컴포넌트(`Aos_home_card`)와 구현체 `HomeCard.kt`를 대조해 확인했다. 카드는 **헤더**(등록자 아바타 + 장소분류 라벨 뱃지 + 더보기 `[...]` 버튼) · **장소명** · **주소** · **대표 이미지 2칸 그리드**로만 구성된다. 등록자는 아바타 이미지로만 표시하고 이름 텍스트는 없다.
  - 3.0.0에서 카드 구성에 "저장 경과일"을 넣은 이래 4.1.0까지 이어졌으나 디자인·구현 어디에도 근거가 없었다. 4.1.0이 [SCR-006] 배지를 없애며 "홈 카드뿐"으로 정리한 탓에 **저장 경과일을 표시하는 화면이 하나도 없는 상태**가 문서상으로만 가려져 있었다.
  - 값 자체는 폐기하지 않는다. `꾹 Pick` 순위 판정값으로 계속 쓰이며(Flow B), 「장소」 구성 요소에도 남긴다. **화면에 노출되지 않을 뿐이다.**
- **Q**: [SCR-006]의 장소분류 칩은 어떤 값 체계를 쓰는가? — 주석은 "홈의 장소분류 `카드정렬 값`을 따라간다"로만 적혀 있고, 시안에는 4.0.0이 구버전으로 처리한 `친구들이 많이 본 곳`이 그려져 있다.
  → **A**: (4.1.0 확정) **`가볼 만한 곳` / `이야기 많은 곳` / `여럿이 저장한 곳` / `친구들이 많이 본 곳` 4종 라벨 체계**로 되살린다. 정렬 기준 3종(`꾹 Pick`·`최신순`·`가까운순`)과도, 카테고리 필터 3종(`전체`·`카페`·`음식점`)과도 다른 축이며, §1에 「장소분류 라벨」로 정의했다. 값은 [SCR-003] 홈에서 부여되고 [SCR-006]은 그것을 그대로 표시한다.
- **Q**: 「장소분류 라벨」 4종 각각은 어떤 장소에 붙는가? 어느 라벨도 성립하지 않는 장소는 어떻게 표시하는가?
  → **A**: (4.1.0 확정) 홈 `카드 정렬 값` 주석에 판정 규칙이 이미 정의되어 있었다 — `친구들이 많이 본 곳` 클릭수 / `이야기 많은 곳` 코멘트수 / `여럿이 저장한 곳` 중복 저장 데이터 / `가볼 만한 곳` **위 셋 어디에도 걸리지 않은 장소 중 가장 오래된 게시물(랜덤)**. 모든 값은 그룹 내의 순위로 매긴다. 라벨 없는 장소를 위한 기본값 자리가 `가볼 만한 곳`이므로 라벨이 비는 경우는 없다. *(디자인 노드 `2809-144358`)*
- **Q**: [SCR-006] 140dp를 넘는 긴 코멘트 본문은 잘라서 보여주는가, 전문을 펼칠 수단을 주는가?
  → **A**: (4.1.0 확정) **높이 제한 없이 전문을 노출한다.** 시안의 140dp는 샘플 내용의 높이일 뿐이며 자르기나 [더보기]를 두지 않는다. 입력 상한이 200자이므로 본문 높이도 그 안에서 자연히 제한된다.
- **Q**: [SYS-002]는 링크 분석을 방 선택 시트를 그리기 전에 요청하는가, [저장하기]를 누른 뒤에 요청하는가? — PRD는 전자, 외부 공유 수신 spec(FR-017)은 후자
  → **A**: (4.1.0 확정) **[저장하기] 이후에 요청한다.** 공유 시트에서 꾹을 고른 직후는 외부 앱 위에 얹히는 화면이라 대기 구간을 만들지 않는 편이 낫다. 분석 결과와 실패는 [SCR-007] 알림함으로 돌린다. 이 결정의 대가로 시트를 그리는 시점에 중복 판정이 불가능해졌고, 그래서 아래 "이미 저장된 방" 규칙이 미확정으로 되돌아갔다.

- **Q**: 방 선택 시트의 방 카드는 [SCR-004] 방 리스트 탭의 카드와 같은 것인가? — 방 리스트 카드에는 멤버 아바타가 있고 spec FR-006에는 없다

- **Q**: [SCR-003] 홈 카드의 `다른 방 저장`은 [SYS-002]와 [SYS-003] 중 어느 명세 소관인가? — PRD는 [SYS-002] 시트를 호출한다고 적었으나 spec은 이 경로를 다루지 않았다
  → **A**: (4.1.0 확정) **둘 다 아니다.** 홈에는 방 변경과 같은 **그리드형 전용 시트**(400dp)가 따로 있고 `다른 방 저장`은 그 시트를 재사용한다. §1에 「홈 방 시트」로 분리해 정의했다. 링크 수신·분석이 없으므로 [SYS-002]가 아니고, 시트가 다르므로 [SYS-003]의 방 선택 시트도 아니다 — 저장 동작만 [SYS-003] 장소 복제와 같다. *(디자인 노드 `2809-138960`, 주석 #3·#6)*

  → **A**: (4.1.0 확정) **체크(✓) 표시와 함께 비활성**되어 다시 고를 수 없다. 이 경로는 이미 저장된 장소를 다루므로 시트를 그리는 시점에 중복을 알 수 있다 — [SYS-002]의 미확정과 무관하게 확정이다. *(디자인 노드 `2809-138960` 주석 #6)*
- **Q**: [SYS-002]에서 공유된 텍스트에 URL이 여러 개거나 하나도 없으면 어떻게 하는가?
  → **A**: (4.1.0 확정) 여러 개면 **첫 번째 URL만** 쓰고, 하나도 없으면 저장을 시작하지 않고 [SCR-007] 오류 알림으로 넘긴다. *(외부 공유 수신 spec FR-002·EC-002)*
- **Q**: [SYS-002]에서 여러 방을 골랐는데 일부만 실패하면 전체를 되돌리는가?
  → **A**: (4.1.0 확정) **되돌리지 않는다.** 저장은 방마다 따로 성립하고 알림도 방 단위로 남는다. *(외부 공유 수신 spec TS-019)*
- **Q**: [SCR-008] 마이페이지의 다크모드 설정을 MVP에 둘 것인가?
  → **A**: (4.1.0 철회) **두지 않는다.** 4.0.0까지 있던 [SCR-008] Flow B(`앱 설정 > 다크모드` — 라이트/다크/시스템 기본값 선택)를 삭제하고 비목표로 내렸다. 앱은 라이트 테마 하나로만 동작하며 OS 다크 모드도 따라가지 않는다. 삭제로 Flow C·D·E·F가 B·C·D·E로 당겨졌다.

## 미확정 항목

- **Q**: [SYS-002]·[SYS-003] 방 선택 시트에서 이미 저장된 방을 어떻게 다루는가? — 4.0.0까지는 "체크된 채 비활성"으로 확정돼 있었으나, 4.1.0에서 링크 분석이 [저장하기] 이후로 밀리면서 [SYS-002]는 시트를 그리는 시점에 중복 여부를 알 수 없게 됐다
  - 선택지는 (a) 세 경로 모두 전면 선택 가능 + [SCR-007] 사후 중복 알림, (b) [SYS-002]만 전면 선택 가능하고 [SYS-003]은 비활성 유지, (c) [SYS-002]가 시트 표출과 별개로 중복 조회만 먼저 돌리기.
  - **[SCR-003] 홈 방 시트는 이 미정에 포함되지 않는다** — 체크·비활성으로 확정이다.

- **Q**: [SCR-001]에서 익명 세션 확보에 실패했을 때(최초 실행 + 오프라인) 사용자를 어디까지 들여보내는가?
  - 선택지는 (a) 스플래시에서 차단하고 재시도만 허용, (b) 네트워크가 필요 없는 화면만 열고 데이터 화면 진입 시 재확보, (c) 그대로 진행시키고 화면마다 개별 실패.
  - (a)를 고르면 "세션은 항상 확보되어 있다"를 앱 전체의 전제로 둘 수 있어 화면별 예외가 사라지는 대신, 오프라인 최초 실행 사용자는 앱을 전혀 쓸 수 없다. [SCR-001] Flow B 참고.

- **Q**: 오랫동안 앱을 켜지 않은 이용자의 익명 세션을 서버 측에서 자동으로 무효화하는가?
  - 무효화하면 계정이 무한 누적되지 않는 대신, 뜸했던 사용자가 돌아왔을 때 데이터를 잃고 앱에는 "무효 세션 감지 후 재발급" 경로가 새로 필요해진다.

- **Q**: [SYS-004] 중복 마커 클릭 시 방 선택 모달과 장소 상세 시트가 겹친 상태의 배치·전환 구체 명세는 무엇인가?
- **Q**: [SCR-008] 마이페이지 스위치에서 OS 앱 설정 화면으로 유도하는 UI의 구체적인 형태는 무엇인가? — 디자인 예정
  - (4.0.0에서 범위 확대) 3.1.0까지는 "위치만 미정, 알림은 [SCR-007] 배너가 해결"이었으나 배너가 철회되어 **알림·위치 두 스위치 모두** 이 UI가 필요하다. [SCR-008] Flow E 참고.
