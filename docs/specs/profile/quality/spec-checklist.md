## 발견된 문제

### 1차 검증 (2026-08-16, spec 1.0.0)

**실패: `[TBD]` 마커가 남아 있지 않다** — 2건

- FR-002: "앞뒤 공백을 제외한 값이 **한글·영문으로만 이루어진 2글자 이상**일 때만 유효한 것으로 판정한다. 최대 길이는 `[TBD: 닉네임 최대 글자 수 미지정 - 10자 / 15자(공동방 이름과 동일) / 상한 없음?]`"
  - 디자인 정책 노드 `2314-95625`와 플레이스홀더 모두 하한(2글자 이상)만 말하고 상한을 말하지 않는다. 공동방 이름은 15자 상한이 확정되어 있어 그 값을 그대로 쓸 근거가 없다.
- FR-005: "`지우기`의 활성 조건은 `[TBD: 주석에 조건이 두 줄로 충돌 - 닉네임 유효 시에만 활성 / 닉네임이 유효하고 아바타도 선택했을 때만 활성 / 입력이 하나라도 있으면 활성?]`"
  - 디자인 정책 노드 `2314-95649`에 "'이름 또는 닉네임' 정상 입력, 프로필 이미지 선택 시 활성화"와 "'이름 또는 닉네임' 정상 입력 시 활성화"가 나란히 적혀 있어 서로 다른 조건이 공존한다. 010-1·010-2·010-3 세 프레임만으로는 두 조건을 구분할 수 없다.

**실패: 요구사항이 검증 가능하고 모호하지 않다** — 위 2건의 `[TBD]`가 FR-002·FR-005의 판정을 불가능하게 만든다. 다른 요구사항(FR-001, FR-003·004, FR-006~013)은 문장만으로 통과·실패를 가릴 수 있다.

**1차 검증 중 보완한 것**

- FR-001과 FR-012에 대응하는 테스트 시나리오가 없어 TS-007(두 진입점의 화면 구성 동일), TS-006(저장 실패 시 화면 유지)을 추가하고 테스트 시나리오 번호를 다시 매겼다.
