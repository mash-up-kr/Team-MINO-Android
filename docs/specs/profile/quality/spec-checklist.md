`[TBD]` 마커 **0건**, 실패 항목 **없음**. 전 16항목 통과.

**이번 개정에서 대조한 것**

- 기준 PRD 4.1.0 → 4.2.0 재대조. 프로필에 닿는 변경은 **「비회원 디바이스 세션」 → 「비회원 익명 세션」** 하나이며, 이용자 구분의 근거가 앱이 만든 기기 식별자에서 **인증 제공자가 발급한 익명 계정 식별자**로 바뀌었다. 세션이 기기가 아니라 **앱 설치**에 묶인다는 점도 함께 확정됐다.
- 이 변경은 §4 가정·§2.3 도메인 정의·§3.2 비목표와 어휘(§1 진입/완료 조건, TS-001, FR-007)에만 닿았다. **FR-001~FR-013 · UX-001~UX-006의 판정 내용은 하나도 바뀌지 않았고** 유저 시나리오 3종과 TS-001~TS-017도 그대로다.
- PRD 4.2.0의 홈 카드 변경(저장 경과일을 화면에 표시하지 않음)은 [SCR-003] 범위이며 프로필 스펙과 겹치지 않는다.

**PRD 4.2.0이 새로 연 미확정 3건을 이번 개정에서 닫았다**

- 세션 확보 실패 상태의 화면 도달 → **도달 불가**(스플래시가 차단). 이 스펙은 유효한 세션을 진입 전제로 유지한다
- 재설치로 프로필이 사라졌을 때의 안내 → **알리지 않고** 최초 실행과 동일하게 온보딩 진입
- 서버의 세션 자동 무효화 대응 → **이 스펙 범위 밖**. 익명 세션 스펙이 감지·재발급을 정의한다

앞의 둘은 §4 가정에, 셋째는 §3.2 비목표에 반영하고 §5 「확정된 항목」에 질문·답변을 기록했다.
