## 비고

- 검증 결과: 16개 항목 전원 통과, `[TBD]` 잔여 0건 (FR-001~011 전부 테스트 시나리오로 커버)
- 3.0.0 재검증: 기준 PRD가 2.2.0이 아니라 **5.0.0**임을 확인하고 전면 정합화했다. 1.0.0~2.0.1은 로컬 `develop`이 20커밋 뒤처진 상태에서 읽은 PRD 2.2.0을 근거로 작성돼, 세션 전제("디바이스 세션")·토스트 타이밍·토스트 문구가 모두 실제 PRD와 어긋나 있었다
- 3.0.0에서 뒤집힌 항목: 일시적 오류 토스트 타이밍(앱 실행 기준 10초 → **스피너 노출 후 10초 더, 총 13초**), 세션 전제(기기 식별자 → **인증 제공자 발급 익명 계정 식별자**), 지연·실패 경로의 적용 범위(전체 → **최초 실행 전용**)
- 2.0.1 재검증: MASC 대시보드가 "유저 플로우 1에 Given/When/Then 테스트 시나리오 표가 없다"고 경고했다. 두 플로우의 표를 하나로 합쳐 플로우 2 뒤에만 뒀던 것이 원인이며, 템플릿대로 플로우마다 표를 붙이도록 쪼갰다
- 1차 검증에서 `[TBD]` 3건(스피너 임계 시간·토스트 후 복구·토스트 반복)이 걸려 사용자 확인 후 해소했다. 확정 내역과 3.0.0에서의 정정 이력은 spec.md §5에 남아 있다
- 3.0.1: PRD의 수치 표기가 Figma 시안 기준 px이며 Android 단위계로 쓰인 것이 아님을 확인했다. 3.0.0에서 이를 PRD 표기 오류로 적었던 서술을 걷어내고, `40px`(Figma 375pt 1배율) → `40dp`(Android) 환산 근거로 바로잡았다. 값 자체(40dp)와 요구사항 의미는 그대로다
- 「비회원 익명 세션」 발급 자체는 별도 작업(`feature/176-firebase-anonymous-auth`) 소관이며, 이 스펙은 그 결과만 소비한다(§3.2 참고). Plan 단계에서 해당 작업과의 인터페이스 확인이 필요하다
