- 1차 검증에서 `[TBD]` 3건(스피너 임계 시간·토스트 후 복구·토스트 반복)이 걸려 사용자 확인 후 해소했다. 확정 내역은 spec.md §5에 기록되어 있다

- 디바이스 세션 발급 자체는 별도 작업(`feature/176-firebase-anonymous-auth`) 소관이며, 이 스펙은 그 결과만 소비한다(§3.2 참고). Plan 단계에서 해당 작업과의 인터페이스 확인이 필요하다
