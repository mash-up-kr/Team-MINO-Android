### 2.0.0 개정 검증 노트

`장소 가리기`를 spec의 모든 요구사항에서 제거한 개정이다. **MAJOR인 이유**는 확정 요구사항 항목(FR-006)이 삭제되고 FR-005의 의미가 바뀌었으며 유저 플로우 2가 재정의됐기 때문이다.

| 위치 | 1.0.0 | 2.0.0 |
|---|---|---|
| 유저 플로우 2 | `장소 가리기`·`다른 방 저장` 2항목 조작 | `다른 방 저장` 1항목 기준으로 재작성 |
| FR-005 | 메뉴에 2항목 노출 | **`다른 방 저장` 한 항목만** 노출 |
| FR-006 | `장소 가리기`는 현재 덱에서만 제거 | **삭제 — 결번**(번호 재사용 안 함) |
| TS-008 | 2항목이 열린다 | 1항목만 열린다 |
| TS-009·TS-010 | 가리기 동작·재노출 검증 | **삭제** |
| EC-008 | 마지막 1장을 가려 덱이 빔 | **삭제** |
| §3.2 비목표 | (해당 없음) | **`장소 가리기` 액션 미정의**를 명시 — PRD 8.0.0 §2와 대응 |

**기록은 남겼다.** §2의 FR-006 결번 안내, §5 「확정 항목」의 Q/A, §5 PRD 대조표의 해당 행, 승계 표의 "항목 수는 1개로 축소" 주석은 그대로 둔다. 왜 이 번호가 비었는지가 spec 안에서 추적되어야 하기 때문이다.

**FR 번호는 당기지 않았다.** FR-007~022를 재매핑하면 TS 31건·EC 15건·UX 4건의 「관련 FR」 참조를 전부 다시 써야 하고, 이미 이 번호로 진행 중인 논의와 어긋난다.

### PRD 정합성

이 spec은 PRD보다 **먼저** 쓰였고, 작성 시점의 PRD 6.0.0과 6건이 어긋나 있었다. 두 차례 PRD 개정으로 **전부 해소됐다.**

- 전환 규칙·예고 툴팁·코치마크 문구·위치 권한 거부·전환 순서 재시작 5건 → **PRD 7.0.0** (PR #237)
- 카드 액션 메뉴의 `장소 가리기` 스펙아웃 1건 → **PRD 8.0.0** (PR #244)

기준 PRD 버전을 **8.0.0**으로 맞췄고 §5에 대조표를 남겼다. PRD 8.0.0 원문 3곳(「카드 덱」 카드 액션 메뉴 · [SCR-003] Flow C · §2 비목표)과 대조해 **어긋나는 항목이 0건**임을 확인했다. `/mino-plan`에 그대로 들어갈 수 있다.

> 이 브랜치에 체크아웃된 `docs/prd/business-context.md`는 아직 7.0.0 사본이다. 8.0.0은 `origin/develop`에 있고, 이 브랜치가 develop에 머지될 때 따라온다. 검증은 `origin/develop`의 8.0.0 원문을 기준으로 수행했다.
