### 3차 검증 (2026-08-12) — spec 1.1.0

**전 항목 통과.** 2차 검증에서 유일하게 실패했던 `[TBD]` 마커 2건이 사용자 확정으로 해소되어 spec 본문에서 사라졌다(`grep "\[TBD" spec.md` 0건). `§5 TBD`의 `검토 대기` 구간은 비어 남는 질문이 없다.

| # | 2차 검증의 미해소 질문 | 확정 내용 | 반영 위치 |
|---|---|---|---|
| 1 | 홈 탭 방 변경 시트에서 생성 완료 후 이동처 — Figma(방 상세) vs PRD [SYS-001] Flow C(홈 탭 덱 전환) 충돌 | **Figma를 따라 새로 만든 방의 방 상세로 이동**한다. 방 리스트 탭 [+]·생성 유도 바텀시트와 같은 도착점이다 | FR-011, 유저 플로우 3 5단계, TS-027, §3.2, §5 |
| 2 | 편집 중 미저장 변경을 두고 이탈할 때의 처리 | **폐기 여부를 묻지 않는다.** 확인 모달 없이 즉시 폼을 닫고 고친 값을 버린다 | FR-018, EC-012, TS-028, §5 |

**범위 판정 기록**

- 사용자가 함께 알린 "방 상세 우상단 [x] → 방 리스트로 이동"은 **이 스펙의 범위 밖**으로 한정했다. 이 문서는 생성 완료 후 방 상세까지 데려다 놓는 데서 끝나고, 이후 [x] 동선은 PRD [SCR-005] 방 상세 스펙이 정의한다(§3.2 비목표에 명시).

**후속 조치 (spec 외부)**

- PRD [SYS-001] Flow C의 "홈 탭으로 돌아와 생성된 방의 덱으로 전환"은 위 1번 확정과 어긋난다. **PRD 갱신이 필요**하며, 그 전까지 PRD 2.2.0과 이 spec 1.1.0은 해당 한 줄에서 불일치 상태다.
- `[TBD]` 2건을 전제로 설계를 유보했던 하위 문서들이 갱신 대상이다 — [plan.md](../plan.md) L63, [research.md](../research.md) R-012, [contracts/room-form-launcher.md](../contracts/room-form-launcher.md) L65, [contracts/room-form-ui.md](../contracts/room-form-ui.md) L33, [tasks.md](../tasks.md) T054, [quickstart.md](../quickstart.md) §2·§5.
