- **`[TBD]` (EC-005)**: Nudge 재노출 정책은 room-list의 범위가 아니라 [SYS-009] 공동방 생성 유도 spec 소유로 확정되어, §3.2 비목표에 반영하고 §5에 확정 기록했다.
- **FR-011 테스트 시나리오 누락**: TS-013·EC-006 추가로 해소했다.

### v1.2.0 재검증

- 담당자 확인 결과 Nudge는 **공동방 0개인 동안 재진입 시마다 재노출**되는 것으로 확정(세션당 1회 제한 없음). §3.2의 SYS-009 위임 문구를 제거하고 FR-008·EC-005·§5를 확정 값으로 갱신, TS-014를 추가했다. 재검증 결과 16개 항목 모두 유지 통과.

### v1.2.1 (PATCH)

- §5 TBD 기록의 표현을 명확화 — "Nudge 재노출"이 별도 특수 로직이 아니라, "탭 재진입 시 항상 `Peek` default로 시작"하는 일반 동작(FR-001)과 "공동방 0개면 Nudge 표출"하는 조건(FR-008·FR-010)이 겹쳐서 나오는 결과임을 명시. FR-001/FR-008/FR-010 자체는 변경 없음. 재검증 결과 16개 항목 모두 유지 통과.

### v1.2.2 (PATCH)

- §5에서 "Peek 기본값"이라는 표현이 Figma의 `(Default)` 프레임 명칭과 혼동될 수 있어 정정. 담당자 확인 결과 `(Default)`는 `Half` 상태(공동방 0개, `내 장소`만 표시)를 가리키는 Figma 명칭이며, 진입 시 기본 상태인 `Peek`(FR-001)와는 별개임을 §5에 참고 문구로 명시했다. FR-001 등 요구사항 자체는 변경 없음. 재검증 결과 16개 항목 모두 유지 통과.

### v2.0.0 (MAJOR)

- 담당자 재확인 결과 방 리스트 탭의 **진입 기본값이 `Peek`가 아니라 `Half`**로 확정되었다(v1.2.2에서 참고용으로 남겼던 구분이 실제로는 진입 상태 자체를 가리키는 것으로 정정됨). FR-001 요구사항 문장을 재정의하고, 유저 플로우 1의 단계 순서(진입→`Half`, 아래로 드래그→`Peek`)를 뒤집었으며, TS-001을 "진입 시 Half 기본값"으로 교체하고 TS-015(Half→Peek 드래그)를 신규 추가, §4 가정과 §5 TBD 기록의 `Peek` 언급을 `Half`로 정정했다. 요구사항의 실질 의미가 바뀌는 변경이라 MAJOR로 처리. 재검증 결과 16개 항목 모두 통과(FR-001 대응 테스트 시나리오는 TS-001·TS-015로 커버리지 유지).
