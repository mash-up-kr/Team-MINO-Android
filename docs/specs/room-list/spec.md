## 1. 유저 시나리오 (User Scenarios)

### 유저 플로우 1 - 지도 & 3단 바텀시트 탐색
방 리스트 탭에 진입한 사용자가 지도 위 마커로 자신이 속한 모든 방의 장소를 훑어보고, 바텀시트를 드래그해 방 목록의 밀도를 조절한다.

**진입 조건**: 사용자가 바텀 네비게이션에서 방 리스트 탭을 선택했다.

1. 탭 진입 → [SYS-004]로 지도 초기화(위치 권한이 아직 없을 때만 이 시점에 팝업 표출 — [SCR-003]·[SCR-008]에서 이미 허용했다면 다시 묻지 않음) → 내가 속한 모든 방의 장소 마커 표시 → 하단에 `방 리스트` 시트가 보유한 공동방 개수에 따라 정해진 고정 높이의 `Half` 상태로 표출(진입 기본값)
2. 사용자가 시트를 아래로 드래그 → `Peek`(88dp, 헤더만)로 축소
3. `Peek`/`Half` 상태에서 사용자가 지도 상단 정렬 드롭다운·카테고리 칩(전체/카페/음식점)을 조작 → 지도 위 마커가 해당 조건으로 필터링

5. 사용자가 `Full` 상태에서 시트를 아래로 드래그 → 직전 `Half` 고정 높이로 복귀

**완료 조건**: 사용자가 지도 위 마커 또는 방 카드 목록으로 자신이 속한 방과 장소를 확인했다.

### 유저 플로우 4 - 공동방 생성 유도 (Nudge & Ghost Card)

**진입 조건**: 사용자의 공동방 개수가 0개다.

1. 방 리스트 탭 진입 → [SYS-009] Nudge 바텀시트가 자동으로 표출(`공동방을 생성해보세요!` / `"저번에 말한 거기가 어디였지?" 더 이상 묻지 마세요.`)

4. Nudge를 닫은 이후에도 방 리스트 하단에 `공동방 만들기` Ghost Card가 상시 노출 → 클릭 시 [SYS-001] 호출

## 2. 요구사항 (Requirements)
### 2.1 기능적 요구사항 (Functional Requirements)

- **FR-001**: 시스템은 반드시 방 리스트 탭 진입 시 [SYS-004]로 지도를 초기화하고(위치 권한이 아직 없을 때만 이 시점에 요청한다 — [SCR-003] 홈 탭 `가까운순` 전환 또는 [SCR-008] 마이페이지 위치 스위치에서 이미 허용됐다면 다시 묻지 않는다) 내가 속한 모든 방의 장소 마커를 표시하며, 바텀시트를 보유한 공동방 개수에 따른 고정 높이의 `Half` 상태로 표출해야 한다(진입 기본값, 높이 값은 FR-002 참고). 단, [SCR-005] 방 상세에서 [X]로 복귀한 경우는 이 진입 기본값 대신 `room-detail` spec FR-004의 상태 유지 규칙(방 상세 `Half`→방 리스트 `Half`, `Full`→`Full`)을 따른다. 사용자는 시트를 위/아래로 드래그해 `Peek`(88dp, 바텀 네비게이션 높이 제외)·`Full` 상태로 전환할 수 있다. ### 2.2 핵심 UX 규칙 (Core UX Rules)

- **UX-001**: 바텀시트의 높이는 화면 비율이 아니라 화면·상태별 고정 dp 값을 사용한다 — 기기 화면 크기와 무관하게 동일한 dp 값을 유지한다. (근거: PRD 「3단 바텀시트」 정의)
- **UX-002**: 시트는 바텀 네비게이션 위로 드래그해 승격하며, `Full` 상태에서는 [SYS-004] 현재 위치 버튼도 함께 숨긴다. (근거: PRD [SYS-004] Flow D)
- **UX-003**: 공동방 카드가 2개 이상일 때 `Half` 상태의 3번째 카드는 의도적으로 잘려 보이게 표시해 스크롤 가능함을 암시한다. (근거: PRD 「3단 바텀시트」[SCR-004] 정의)

### 2.3 주요 도메인 (Core Domain)

- **방 리스트 시트 (Room List Sheet)**: 방 리스트 탭의 지도 위에 떠 있는 3단(`Peek`/`Half`/`Full`) 바텀시트. 담기는 콘텐츠가 보유 공동방 개수에 따라 달라지며, 그에 맞춰 `Half` 고정 높이도 달라진다. ## 3. 범위 (Scope)
### 3.1 측정 가능한 성과 (Measurable Performance)

- **SC-001**: 방 리스트 탭 진입 후 3초 이내에 지도와 `Peek` 시트가 렌더링된다.
- **SC-002**: 사용자가 드래그 한 번으로 `Peek`↔`Half`↔`Full` 각 인접 단계를 전환할 수 있다.
- **SC-003**: 공동방 개수(0/1/2개 이상) 각 케이스에서 `Half` 시트가 PRD에 정의된 고정 dp 값과 어긋나지 않게 렌더링된다.
- **SC-004**: 공동방이 0개인 사용자의 90% 이상이 Nudge 또는 Ghost Card를 통해 공동방 생성 폼에 도달한다.

### 3.2 비목표 항목 (Out of Scope)

- 공동방 생성/편집 폼 자체의 입력 필드·검증 규칙은 [SYS-001] 관련 spec이 정의한다.
- 지도 카메라 초기화, 마커 색상 판별 규칙 자체는 [SYS-004]가 정의한다.
- 바텀 네비게이션([SYS-005]) 자체의 탭 전환·상태 보존 동작은 이 spec의 범위가 아니다.
- [SCR-005] 방 상세 화면 자체의 구성(정렬·필터·뷰 전환·장소 액션 등)은 이 spec의 범위가 아니다 — `room-detail` spec이 정의한다.
- [SCR-005]에서 [X]로 복귀할 때의 시트 상태 유지 규칙 자체는 `room-detail` spec(FR-004)이 소유한다 — 이 spec(FR-001, EC-007)은 그 규칙이 방 리스트 진입 기본값의 예외임을 참조할 뿐이다.
- 3단 바텀시트의 드래그 제스처 인식·높이 전환 애니메이션 메커니즘 자체는 디자인 시스템 공용 컴포넌트(이슈 #144)가 정의한다.

## 4. 가정 (Assumptions)

- 대표 색상·캐릭터 표시 규칙은 [SYS-004] 정의를 그대로 따른다.
- 카테고리 칩(전체/카페/음식점)의 옵션 값은 저장된 장소 카테고리 기반으로 동적 생성되며, [SCR-005] 방 상세와 동일한 원칙을 따른다.
- `Peek`(88dp)/`Half`(256dp·360dp·380dp) 고정 높이 값은 PRD 「3단 바텀시트」[SCR-004] 정의를 그대로 사용한다. 이슈 #142의 초안 수치는 PRD 3.1.0에서 디자인 정책 보드 확정값으로 대체되었으므로 참조하지 않는다.
- 방 리스트 탭 진입 시 기본 시트 상태는 항상 `Half`다(보유 공동방 개수에 따라 고정 높이는 다르다) — [SCR-005] 방 상세의 진입 기본값도 `Half`라 이 점은 동일하다. 단 [SCR-005]에서 [X]로 복귀한 경우는 예외이며 EC-007을 따른다.
- 위치 권한 허용 여부는 앱 전역에서 공유되는 상태로 본다 — [SCR-003] 홈 탭 `가까운순` 전환이나 [SCR-008] 마이페이지 위치 스위치에서 이미 허용한 이력이 있으면, 방 리스트 탭에 처음 진입하더라도 권한 팝업을 다시 띄우지 않는다(PRD 「지연 권한 요청」 정의).

## 5. TBD 확인 기록

- Q: Nudge를 닫은 뒤 같은 세션에서 방 리스트 탭을 다시 방문하면 Nudge 바텀시트가 재노출되는가?
  -> A: 재노출된다. 별도의 "닫힘을 기억하는" 상태 저장 없이, 탭에 재진입할 때마다 FR-001에 따라 시트가 항상 `Half` 상태로 새로 표출되고, 그 시점에 공동방이 여전히 0개면 FR-008에 따라 Nudge가 다시 뜬다(세션당 1회로 제한하지 않음). 즉 Nudge만의 특수한 재노출 로직이 아니라, "탭 재진입 시 항상 `Half`로 시작"하는 일반 동작(FR-001)과 "공동방 0개면 Nudge 표출"하는 조건(FR-008·FR-010)이 겹쳐서 나오는 결과다. (담당자 확인 2026-08-17, 진입 기본값이 `Peek`가 아니라 `Half`임을 재확인 — FR-001·§4 가정 갱신)
