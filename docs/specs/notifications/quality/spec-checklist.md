## 검증 결과

**16개 중 16개 통과, 실패 0개. `[TBD]` 잔여 0건.** 3.0.0은 2.1.0에서 확정했던 두 항목을 디자이너 답변으로 뒤집은 개정이며, 미확정이 새로 생기지는 않았다.

### 판정 근거가 갈릴 수 있었던 항목

- **`요구사항이 검증 가능하고 모호하지 않다`** — FR-022의 "현재 표시 기준으로 삼고 있는 방"은 그 자체로는 외부 값이지만, 그 값이 무엇인지(사용자가 [SYS-004] 중복 마커에서 마지막으로 고른 방)와 값이 없을 때의 기본값(가장 최근 저장한 방)을 문장 안에 함께 적어 판정 가능하게 만들었다. TS-047·TS-049가 두 갈래를 각각 검증한다. 통과.
- **`엣지 케이스가 식별되어 있다`** — 도착지 규칙이 외부 상태에 의존하게 되면서 새로 생기는 구멍을 EC-023(기준 방에서 이미 나감)·EC-024(기준 방이 정해진 적 없음)·EC-025(중복이 난 방과 기준 방이 다름)로 메웠다. EC-025는 이번 개정에서만 성립하는 조합(묶인 행 + 표시 기준 방)이라 새로 만들었다. 통과.
- **`의존성과 가정이 식별되어 있다`** — 이번 확정은 알림함 밖의 두 전제 위에 서 있어 §4에 명시했다. ① 묶는 일은 서버가 한다(20건 페이징과 클라이언트 묶기가 양립하지 않는다) ② 표시 기준 방은 장소마다 하나씩 영속 유지되며 [SYS-004]가 관리한다. 둘 중 하나라도 다르게 구현되면 FR-021·FR-022가 성립하지 않는다. 통과.
- **`구현 세부사항이 명세로 새어 들어오지 않았다`** — "현재 표시 기준 방"은 저장 위치나 상태 관리 방식이 아니라 사용자에게 보이는 개념(마지막으로 보던 방)으로 서술했고, 값의 보관 책임은 §3.2에서 [SYS-004]로 넘겼다. 통과.
- **`기능이 성공 기준에 정의된 측정 가능한 결과를 충족한다`** — SC-004에 붙어 있던 모달 관련 단서를 걷어내고, SC-013(행 수 = 저장 시도 수)·SC-014(방 고르는 단계 0회)를 이번 결정에 맞는 지표로 재정의했다. 통과.

## 비고

- **이번 개정은 PRD가 아니라 디자이너 확정에서 촉발되었다.** 기준 PRD 버전은 5.0.0 그대로이며, PRD와 어긋나는 항목은 없다. [SCR-007] Flow B는 클릭 시 이동 대상을 "[SCR-006] 장소 상세"로만 규정하고 어느 방 기준인지는 말하지 않으므로, FR-022는 PRD가 비워 둔 자리를 채우는 규칙이다.
- **ID를 유지한 채 의미를 재정의했다.** FR-021·FR-022, UX-015·UX-016, SC-013·SC-014, TS-045~TS-051, EC-019·EC-020·EC-023·EC-024가 모두 2.1.0과 다른 내용을 담는다. 2.0.0의 TS-027 재정의와 같은 방식이며, 뒤집힌 경위는 §5 「확정된 항목」의 (2.1.0 답 철회) 줄에 남겼다. **2.1.0을 읽고 작성된 산출물이 있다면 이 ID들부터 다시 봐야 한다.**
- **2.1.0이 남긴 디자인 숙제가 사라졌다.** 2.1.0 체크리스트가 지적한 "FR-021이 Figma 시안과 어긋나 시안 반영이 필요하다"는 병기안이 철회되면서 소멸했다. 3.0.0의 행 구성은 `007-1-2`(3037-90987) 시안과 100% 일치한다.
- **서버 API에 걸리는 요구가 하나 늘었다.** 중복 저장 알림을 저장 시도 단위로 묶어 내려주어야 한다(§4 가정). 방 단위로 N건을 그대로 내려주면 FR-021을 화면에서 만족시킬 수 없다 — 페이징 경계에서 묶음이 갈라지기 때문이다. Plan 단계에서 서버와 맞춰야 할 항목이다.
- **[SYS-004]에 걸리는 의존이 하나 늘었다.** 장소마다 유지되는 "현재 표시 기준 방"이 앱을 껐다 켜도 남는 값이어야 FR-022가 성립한다. PRD [SYS-004] Flow B는 방 전환 시 색이 바뀐다고만 적혀 있고 그 선택의 영속 여부를 말하지 않으므로, **PRD 쪽에 이 값을 명시하는 개정을 제안할 필요가 있다.**
- **결번 ID는 이번에도 재사용하지 않았다.** 1.1.0에서 삭제한 FR-007·008·009·013, UX-003·004, TS-013~019·TS-026, EC-006·007·008, SC-006은 비어 있는 채로 두었고, 신규는 TS-052·EC-025만 이어 붙였다.
