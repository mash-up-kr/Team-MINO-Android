## 비고

### 2.2.0 검증 (2026-08-20) — 16/16 통과, `[TBD]` 0건 → **PASS**

**`[TBD]` 마커가 남아 있지 않다 — 통과 (2.1.0 미통과에서 회복)**

2.1.0에 하나 남아 있던 `EC-019`의 `[TBD]`("고를 수 있는 방이 하나도 없을 때")가 이번 개정에서 확정되었다. `spec.md` §5 「미확정 항목」은 비었고, 본문 전체에 `[TBD]` 마커가 0건이다.

**기계 검증 결과**

- 요구사항 22건(`FR-001`~`FR-022`)이 모두 하나 이상의 테스트 시나리오에서 참조된다(TS 미참조 FR 0건). 신설된 `FR-022`는 `TS-034`·`TS-035`가 덮는다.
- 테스트 시나리오 35건, 엣지 케이스 21건, 핵심 UX 규칙 10건, 성과 지표 7건.
- 여지 어휘("~수도 있다", "가능하면", "되도록", "가급적", "필요시", "적절히") 사용 0건.
- 치환되지 않은 템플릿 플레이스홀더 0건.

**요구사항이 검증 가능하고 모호하지 않다 — 통과**

`FR-022`는 세 가지가 각각 판정 가능하다 — [다른방에 공유]가 항상 활성인가, 시트에서 모든 카드가 체크·비활성이고 [공유하기]가 비활성인가, 안내 문구·토스트가 없는가. `UX-010`은 "문구가 아니라 상태로 알린다"를 카드·CTA의 관측 가능한 상태로 환원해 서술하므로 측정 가능하다.

### 2.2.0 개정 내용

- **`EC-019` 확정** — 모든 방에 이미 저장된 경우 [다른방에 공유]는 활성을 유지하고, 시트 안에서 모든 방 카드가 체크(✓)·비활성 · [공유하기]도 비활성인 상태로 드러난다.
- **`FR-022` 신설** — 위 상태와 두 갈래 탈출 경로([새 방 만들기] / 시트 닫기), 안내 문구를 두지 않는다는 규정.
- **`UX-010` 신설** — "이미 모든 방에 있다"를 문구가 아니라 카드·CTA의 상태로 알린다.
- **`TS-034`·`TS-035` 추가** — 전부 비활성 시 CTA 비활성 / 새 방 생성 후 CTA 활성.
- **`EC-020` 보강, `EC-021` 신설** — 새 방이 유일한 선택지가 되는 경우, 확인 후 시트를 닫고 장소 상세로 복귀하는 경우.
- **`SC-007` 신설** — 고를 수 있는 방이 없는 사용자가 막힌 채로 남지 않는다.
- **유저 플로우 6에 「갈래」 추가**, §3.2 비목표에서 [SYS-003]과의 소유 경계 재정리(시각 표현은 [SYS-003], 0개일 때의 경로는 이 문서), §4에 가정 2건 추가(진입 전 중복 미조회 / 개인방 하나뿐인 사용자도 같은 경로).
