### 3.0.0 검증 (2026-08-28) — 16/16 통과, `[TBD]` 0건 → **PASS**

**기계 검증 결과**

- 요구사항 27건(`FR-001`~`FR-027`)이 모두 하나 이상의 테스트 시나리오에서 참조된다(TS 미참조 FR 0건). 신설 5건은 `FR-023`←`TS-040`·`TS-041`, `FR-024`←`TS-042`·`TS-043`·`TS-048`, `FR-025`←`TS-043`~`TS-047`, `FR-026`←`TS-038`·`TS-039`·`TS-049`, `FR-027`←`TS-002`·`TS-007`·`TS-036`·`TS-037`이 덮는다.
- 테스트 시나리오 49건(`TS-001`~`TS-049`), 엣지 케이스 27건(`EC-001`~`EC-027`), 핵심 UX 규칙 13건, 성과 지표 10건. ID 중복 0건.
- 여지 어휘("~수도 있다", "가능하면", "되도록", "가급적", "필요시", "적절히") 사용 0건.
- 치환되지 않은 템플릿 플레이스홀더 0건. `[TBD]` 마커 0건이며 §5 「미확정 항목」은 비어 있다.

**요구사항이 검증 가능하고 모호하지 않다 — 통과**

새로 들어온 「지금 보고 있는 방」이 관측 가능한 세 결과로 환원되어 있어 판정 가능하다 — 마커 색상·외형(`FR-002`), 코멘트 목록(`FR-019`), [나가기] 목적지(`FR-009`). 값이 정해지는 시점(`FR-027`)과 바뀌는 유일한 경로(`FR-025`)가 각각 하나씩만 규정되어, 같은 상황에서 두 가지 결론이 나오지 않는다. `FR-026`은 발생 시점(진입 시 1회 + 방 전환 갱신 시 1회)과 실패 시 처리를 모두 적어 통과·실패를 가릴 수 있다.

**핵심 UX 규칙이 측정 가능하다 — 통과**

`UX-011`은 버튼의 활성/비활성이라는 관측 상태로, `UX-012`는 "목록에 현재 방이 없다"는 셀 수 있는 조건으로, `UX-013`은 "`Full`에서 버튼이 보이지 않는다"로 각각 확인 가능하다.

**범위가 명확히 한정되어 있다 — 통과**

「저장된 방 시트」의 소유권이 이 문서로 넘어오면서 §3.2에서 [SYS-004]와의 경계를 다시 그었다 — 마커를 그리는 판별 로직은 [SYS-004], 어느 방을 기준으로 그릴지는 이 문서. 폐기된 겹침 모달 동선은 "어느 스펙도 정의하지 않는다"로 명시해 공백이 아니라 폐기임을 남겼다. 「경과일 초기화 확인」은 발생 시점만 이 문서가, 순위 재산정은 서버·[SCR-003]이 소유한다고 갈랐다.

### 3.0.0 개정 내용 (기준 PRD 5.0.0 → 9.0.0)

- **유저 플로우 7 「저장된 방 전환」 신설** — 지도 위 [저장된 방] 버튼 → 「저장된 방 시트」 → 방 카드 클릭으로 보는 방을 바꾸는 동선. `TS-042`~`TS-049`, `EC-024`~`EC-027`.
- **`FR-023`·`FR-024`·`FR-025` 신설** — 버튼 배치와 활성 조건(중복 저장 장소만), 시트 구성(442dp / 스크롤 312dp / 현재 방 제외 / 체크박스·CTA 없음), 전환 시 갱신 범위와 상태 초기화.
- **`FR-026` 신설** — 「경과일 초기화 확인」(Access)을 진입 시와 방 전환 갱신 시마다 기록. `EC-022`·`EC-023`.
- **`FR-027` 신설** — 「지금 보고 있는 방」의 초기값 결정 규칙(진입 경로가 특정한 방, 알림만 최초 저장 방).
- **`FR-002` 의미 변경** — 마커 양식 기준이 "장소가 속한 방" → "지금 보고 있는 방"(기본값은 최초 저장 방).
- **`FR-009` 의미 변경** — [나가기] 목적지가 "그 장소가 속한 방" → "지금 보고 있는 방". 홈 카드 진입도 예외 없이 방 상세로 나간다.
- **`EC-002` 폐기·재작성** — 중복 마커 클릭 시 방 선택 모달을 겹쳐 띄우던 동선(PRD 5.1.0 폐기)을 걷어내고, 단일 방 장소와 동일하게 곧바로 `Half`를 띄우는 것으로 바꿨다.
- **진입점 확대** — [SCR-003] 홈 카드 클릭이 네 번째 진입점으로 추가(`TS-036`·`TS-037`).
- **`UX-011`~`UX-013`, `SC-008`~`SC-010` 신설**, §2.3에 도메인 「지금 보고 있는 방」 추가, §3.2 [SYS-004] 경계 재정리와 비목표 3건 추가, §4 가정 5건 추가.
- **근거 링크 갱신** — 코멘트 삭제 근거의 PRD Flow F → Flow G(5.1.0에서 Flow C가 끼어들며 밀림).
