**PRD 5.0.0 → 6.0.0 대조 결과**

이 spec이 근거로 삼는 PRD 구간을 5.0.0 커밋과 섹션 단위로 대조한 결과 **차이가 없다.**

- `[SYS-002] 외부 공유 수신` 전 구간(Flow A·B, URL 추출 규칙, 토스트 배치, 전면 선택 가능) — 동일
- `「방 선택 시트」` 정의(방 카드 구성, 복수 선택, CTA 문구 진입점별 분리, '이미 저장된 방' 진입점별 처리, 높이 2단 436/612/644dp) — 동일
- `[SCR-001]` 스플래시 Flow A~E, `[SCR-007]` 알림 6종·Flow D 저장 오류 안내, 「비회원 익명 세션」 — 동일

5.1.0·6.0.0의 실제 변경은 `[SCR-003]` 홈 카드 덱([장소 더 보기] 스펙아웃·「덱 소진 예고 툴팁」 신설), `[SCR-006]` 장소 상세(「저장된 방 시트」 신설로 Flow C 삽입·종전 C~F가 D~G로 밀림), `[SYS-004]` Flow B 마커 색상 기준(가장 최근 저장 방 → 최초 저장 방)에 몰려 있으며, 모두 이 spec의 §3.2 비목표 바깥이다.

**갱신됨**

- **헤더** — 기준 PRD 버전 5.0.0 → **6.0.0**, 버전 2.3.0 → **2.3.1**(PATCH), 최종 수정일 2026-08-26. 개정 입력을 **입력** 항목에 덧붙였다.
- **근거 표기** — §2·§3·§4에서 `PRD 5.0.0`으로 적힌 근거 표기를 **`PRD 6.0.0`으로 갱신**했다(FR-001·002·004·005·006·008·010·011·012·013·014·015·016·017·019, UX-006·007·010, §3.2 세션 항목, §4 가정 5건). 인용한 내용은 6.0.0에서도 그대로이므로 **요구사항 문장은 한 건도 바뀌지 않았다.**
- **§5 TBD는 손대지 않았다.** Q1~Q7의 `PRD 4.1.0`·`PRD 5.0.0` 표기는 "그 결정이 어느 버전에서 내려졌는가"를 남기는 기록이므로 6.0.0으로 고치면 이력이 왜곡된다.

**추가됨**

- **§3.2 비목표 1건** — `[SCR-006]` 장소 상세의 [저장된 방]이 여는 「저장된 방 시트」(442dp)를 이 문서 밖으로 명시했다. PRD 6.0.0에서 방을 다루는 시트가 네 종(「방 선택 시트」·「홈 방 시트」·「저장된 방 시트」·[SYS-003])으로 늘어, 이미 「홈 방 시트」·[SYS-003]을 갈라 두던 비목표 목록의 구분을 완결시킨 것이다. **범위의 축소·확대가 아니라 이미 암묵적이던 경계의 문장화**여서 PATCH로 다뤘다.

- **PRD 내부 불일치**: `business-context.md`의 「장소」 중복 규칙(§1 데이터 및 도메인 용어)에 *"「방 선택 시트」는 미정이다"* 가 남아 있으나, 같은 문서의 「방 선택 시트」 정의와 §5 확정 항목은 [SYS-002] 전면 선택 가능 / [SYS-003]·[SCR-003] 체크·비활성으로 **이미 확정**했다. 5.0.0부터 이어진 잔존 문장이며, 이 spec은 상세 정의 쪽을 근거로 삼는다(FR-016). PRD 개정 시 정리가 필요하다.
