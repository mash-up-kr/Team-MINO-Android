## 발견된 문제

### 검증 (2026-08-20, spec 2.3.0 — PRD 5.0.0·Figma 개정 반영)

미통과 항목 없음. `[TBD]` 잔여 0건이다.

**갱신됨**

- **헤더** — 기준 PRD 버전 4.2.0 → **5.0.0**, 버전 2.2.0 → **2.3.0**(MINOR), 최종 수정일 2026-08-20. 개정 입력을 **입력** 항목에 덧붙였다.
- **FR-016 근거 교체** — "PRD 4.2.0 「미확정 항목」의 (b)안"이라는 미확정 근거를, PRD 5.0.0 「방 선택 시트」 '이미 저장된 방'의 진입점별 확정([SYS-002] 전면 선택 가능)과 [SYS-002] Flow A의 명시 문장, 그리고 Figma `013-1` 주석 ②에서 체크·비활성 문장이 삭제된 사실로 교체했다. **요구사항 문장 자체는 2.2.0과 동일하다.**
- **FR-019 근거 보강** — PRD 5.0.0 [SCR-001] Flow E가 신설한 "세션 확보 전 화면 진입 차단"이 **스플래시를 거치는 앱 실행 경로의 규칙**이며 이 진입점에는 적용되지 않는다는 점을 근거에 명시했다. 요구사항 문장은 그대로다.
- **§2.3 도메인 「익명 세션」** — "설치가 살아 있는 동안 만료되지 않는다", "무효 세션을 재발급하지도 않는다"를 반영했다.
- **§3.2 비목표** — 세션 항목을 재서술했다. [SCR-001] Flow B~E(로딩 스피너·네트워크 오류·일시적 오류 토스트·확보 전 진입 차단)가 스플래시 스펙 소관임을 적고, "세션 무효화·재발급 규칙은 PRD 「미확정 항목」" 이라는 낡은 서술을 "만료되지 않아 규칙 자체가 없다"로 바꿨다.
- **§5 Q5 후속** — "후속 필요"를 **"후속 해소(2.3.0)"** 로 전환했다. PRD·디자인 양쪽에서 어긋나던 근거가 모두 사라진 것을 확인한 기록이다.
- **§5 Q6 후속** — "5.0.0 재확인(2.3.0)" 문단을 덧붙여, 외부 공유 수신이 [SCR-001] Flow E의 앱 전체 전제가 성립하지 않는 유일한 진입점이라는 사실과 ①안을 유지한 근거(②·③안의 대가)를 남겼다.

**철회됨**

- **EC-012**(세션은 복원됐으나 저장 실행 시점에 서버가 무효로 판정) — PRD 5.0.0이 "설치가 살아 있는 동안 세션은 만료되지 않으며 앱에 무효 세션 감지·재발급 경로를 두지 않는다"를 확정해, 이 엣지 케이스가 성립할 조건이 사라졌다. 대응하는 §4 가정도 함께 걷어냈다.
- 엣지 케이스가 하나 줄었으나 **"엣지 케이스가 식별되어 있다"는 계속 통과**한다. 남은 EC-001~006·EC-011이 이탈·URL 부재·URL 복수·방 0개·재설치·카드 부족·중복 방을 덮고, 저장이 성립하지 않는 나머지 사유는 EC-007~009와 FR-014의 오류 알림 경로가 받는다.

**추가됨**

- **§4 가정 2건** — ①한 번 복원된 세션이 저장 시점에 무효가 되는 경우는 다루지 않으며 그 밖의 실패는 FR-014로 흡수한다, ②외부 공유 수신은 "익명 세션은 항상 확보되어 있다"는 PRD 전제가 성립하지 않을 수 있는 유일한 진입점이며 그때는 FR-013의 방 0개 처리로 수렴한다.
- **§5 Q7** — EC-012 철회 판단과 근거를 「해소된 항목」에 기록했다.

**FR ↔ TS 커버리지 재확인**

- FR-001~FR-017·FR-019 전 항목이 하나 이상의 TS로 연결된다. EC-012 철회로 끊긴 검증 경로는 없다 — FR-014는 TS-017·TS-019, FR-019는 TS-022·TS-023이 계속 받는다.

**디자인 대조 (Figma [013] 섹션, 2026-08-20 재확인)**

- 프레임 구성(`013-1-1 peek` / `013-1-2 full_4개` / `013-1-3 full_4개 이상` / `013-2 저장 피드백`)은 2.2.0 시점과 같다. 신규·삭제 프레임 없음.
- 높이 실측이 FR-008과 일치한다 — peek 436(카드 영역 240 + 헤더 94 + 액션 102), full_4개 612(카드 영역 416), full_4개 이상 644. 카드 높이 104 고정.
- 헤더 문구(`게시물 저장` / `장소를 저장할 방을 선택해주세요.`)와 카드 구성(썸네일·방 이름·방 설명·`장소 N개`·체크박스, 멤버 아바타 없음)이 FR-004·FR-006과 일치한다.
- 주석 ②에서 체크·비활성 문장이 삭제되어 FR-016과 일치한다. 시안의 카드도 전부 선택 가능한 빈 체크박스로 그려져 있다.

### 후속 확인 필요 (spec 외부)

- **디자인**: Figma `013-1` 주석 ③의 제목이 여전히 `'공유하기' 버튼 클릭`이다. 시안의 실제 버튼과 PRD 5.0.0 「방 선택 시트」 CTA 문구는 [SYS-002]에 대해 `저장하기`로 확정되어 있으므로(spec §5 Q1) 주석 제목 갱신이 필요하다. 본문("장소 카드를 하나라도 선택 시 활성화된다")은 FR-009와 일치한다.
- **디자인**: 방 0개 상태(FR-013)의 시트 화면이 Figma `013-1`에 없다. 안내 문구와 시각 표현이 디자인 확정 대상으로 남아 있으며, spec은 §4 가정으로 그 경계를 표시해 두었다.
- **[SCR-001] 스플래시 spec**: PRD 5.0.0이 Flow B~E로 세션 확보 실패 처리를 확정했다. 스플래시 spec 작성 시, Flow E의 "세션 확보 전에는 어느 화면으로도 들여보내지 않는다"가 **외부 공유 수신에는 적용되지 않는다**는 이 spec의 FR-019·§5 Q6 결정과 대조해 양쪽 서술이 어긋나지 않는지 확인해야 한다.
- **해소 확인** — 2.2.0의 후속 확인 2건은 이번 실행에서 닫혔다. PRD는 5.0.0에서 (b)안을 「확정된 항목」으로 올렸고, Figma `013-1` 주석 ②의 어긋나던 문장은 삭제되었다.
