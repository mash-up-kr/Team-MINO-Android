## 검증 근거

- **요구사항 커버리지**: 기능 요구사항 `FR-001`~`FR-024` 24건이 모두 하나 이상의 테스트 시나리오(`TS-001`~`TS-039`, 39건)에 참조된다. 미참조 FR은 0건이다.
- **UX 규칙 커버리지**: `UX-002`·`UX-003`·`UX-004`·`UX-006`은 테스트 시나리오로, `UX-001`(`EC-005`·`EC-019`)과 `UX-005`(`EC-003`·`EC-009`)는 엣지 케이스로 검증된다. 엣지 케이스는 `EC-001`~`EC-022` 22건이며 모두 관련 FR이 명시돼 있다.
- **유저 시나리오 포괄성**: 완주(플로우 1) / 건너뛰기 최단 경로(플로우 2) / 친구 초대(플로우 3) / 튜토리얼(플로우 4) / 재실행(플로우 5)로 [SCR-002] Flow A~D와 재진입 경로를 모두 덮는다.
- **범위 한정**: §3.2가 프로필 폼·공동방 폼·익명 세션·스플래시·홈·방 상세·초대 링크 수신·바텀 네비게이션·디자인 에셋·분석 이벤트를 각각 어느 스펙이 소유하는지 지목한다.
- **TBD**: `[TBD]` 마커 0건. §5의 7개 항목은 모두 답이 확정된 기록이다.

## 문제 기록

이번 검증에서 spec 본문의 결함으로 판정된 항목은 없다. 다만 **이 spec 밖에서 개정이 필요한 사항 3건**을 §4 가정에 기록해 두었으므로, `/mino-plan` 진행과 별개로 처리 대상이다.

| # | 대상 문서 | 개정이 필요한 서술 | 이 spec의 판단 |
|---|---|---|---|
| 1 | `docs/prd/business-context.md` [SYS-006] Flow A · [SCR-002] Flow C | `[초대 링크 복사]` 후 `1.5초 뒤 자동 이동`, 이탈 컨트롤 `[건너뛰기]` | spec 1.1.0에서 폐기됨. PRD 9.0.0까지 미반영 (`FR-012`·`FR-013`, §5) |
| 2 | `docs/prd/business-context.md` [SYS-006] Flow A | 이탈 경로 `[뒤로가기]: [SYS-001] 공동방 생성 화면으로 복귀` | 같은 PRD [SYS-001] Flow E·[SYS-011] Flow D의 5.0.0 재정의와 충돌하는 잔존 서술로 본다 (`FR-006`·`FR-007`) |
