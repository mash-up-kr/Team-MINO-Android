## 비고

- 2026-08-20 개정 2건(자동 화면 전환 제거 · 백프레스 정책 변경)에 대해 체크 표시를 전부 초기화한 뒤 재검증했다. 전 16개 항목 통과, `[TBD]` 잔여 0건. 두 개정은 작성 시점에 버전을 동결했다가 사용자 결정으로 `1.1.0`에 함께 반영했다.
- 추적성 재확인: FR-001~FR-024·UX-001~UX-006 전 항목이 테스트 시나리오(TS 39건) 또는 엣지 케이스(EC 22건)에서 최소 1회 참조된다. 미참조·미정의 참조 모두 0건.
- **`1.0.0` → `1.1.0` 사이에서 `FR-007`(백프레스)·`FR-012`(링크 복사 후 전환) 두 요구사항의 의미가 바뀌었다.** 늘어난 변경이 아니라 뒤집힌 변경이므로, 하위 문서(`plan.md`·`tasks.md`)를 만들 때 `1.0.0` 기준으로 읽은 내용이 남아 있지 않은지 확인해야 한다.
- **PRD 5.0.0과 어긋나는 항목 2건.** 둘 다 spec에만 반영돼 있고 PRD는 옛 규칙을 담고 있다.
  - 자동 화면 전환 제거 → PRD [SYS-006] Flow A(`1.5초 뒤 다음 온보딩 스텝으로 자동 이동`)·[SCR-002] Flow C(`링크 복사 토스트 후 1.5초 뒤 Flow D로 이동`) 개정 필요.
  - 백프레스 정책 → PRD는 온보딩의 시스템 뒤로가기 처리를 아예 서술하지 않는다(`뒤로가기 컨트롤 비표출`만 있다). 백그라운드 전환 정책을 명문화할지 확인 필요.
- 앞선 검증에서 확인한 문서 간 불일치 3건은 그대로 유효하며 §4 가정에 판정 근거와 함께 남아 있다.
  - `009-1 친구 초대` 이탈 컨트롤: Figma 우상단 [X] vs PRD [SYS-006] Flow A [건너뛰기]·[뒤로가기] → Figma 채택. 자동 전환 제거로 [X]가 이 스텝의 유일한 전진 수단이 되어 비중이 더 커졌다.
