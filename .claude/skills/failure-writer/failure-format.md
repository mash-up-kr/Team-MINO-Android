# 실패 기록 출력 포맷 (SSOT)

실패 기록 문서의 **파일명·통제 어휘·템플릿** 형식을 정의하는 단일 출처다. 실패 기록 작성은 [`failure-writer` 스킬](SKILL.md)이 전담하며 이 형식을 따른다(작성 시점 판단·증거 수집·인덱스 갱신 같은 정책은 그쪽에 있다). 실패 기록을 읽는 사람에게는 상태 값의 의미 참조처다. 규칙을 다른 곳에서 다시 풀어쓰지 않고 이 파일을 참조한다.

## 파일명

- `NNN-kebab-제목.md` (3자리 일련번호)
- 번호는 **한 번 부여하면 재사용하지 않는다**

## 통제 어휘 — 상태 값

| 상태 | 의미 |
|---|---|
| `Open` | 원인은 기록됐지만 재발 방지책이 아직 정리되지 않음 |
| `Resolved` | 대체 방법까지 적용되어 마무리됨 |

## 문서 템플릿

언어는 한국어. 아래 헤더·순서를 그대로 따르되, 서술 내용은 매 사례마다 다르므로 예시 문장은 넣지 않는다.

```markdown
# NNN. {제목}

- **상태**: Open | Resolved
- **발생일자**: YYYY-MM-DD
- **작성자**:
- **관련 ADR**: (있으면 ADR 링크, 없으면 "없음 — 문서화되지 않은 결정")
- **관련 커밋/PR**:

## 무엇을 시도했는가

## 무엇이 잘못됐는가

## 어떻게 발견했는가

## 무엇으로 대체했는가
```
