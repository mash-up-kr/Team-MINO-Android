# 실패 기록 작성 규약 (SSOT)

실패 기록의 **파일명 규칙·통제 어휘·문서 템플릿**의 단일 출처다. `failure-writer` 스킬과 사람이 직접 작성할 때 모두 이 문서를 따르며, 규칙을 다른 곳(docs/failures/README.md 등)에서 다시 풀어쓰지 않고 이 파일을 참조한다.

## 파일명 규칙

- `NNN-kebab-제목.md` (3자리 일련번호, 예: `001-celery.md`)
- 번호는 **한 번 부여하면 재사용하지 않는다**

## 통제 어휘 — 상태 값

| 상태 | 의미 |
|---|---|
| `Open` | 원인은 기록됐지만 재발 방지책이 아직 정리되지 않음 |
| `Resolved` | 대체 방법까지 적용되어 마무리됨 |

## 작성 규칙

- 필수 항목: **상태 · 발생일자 · 작성자 · 관련 ADR/커밋 · 무엇을 시도했는가 · 무엇이 잘못됐는가 · 어떻게 발견했는가 · 무엇으로 대체했는가**
- **작성자**는 [ADR](../../../docs/adr/README.md)과 동일하게, 문서를 쓴 사람이 아니라 **이 기록이 누구의 작업과 관련되면 좋을지**를 남기는 필드다
- 언어는 한국어
- 작성 후 [`docs/failures/README.md`](../../../docs/failures/README.md) 인덱스에 줄을 추가한다

## 문서 템플릿

내용은 채우지 않은 뼈대만 남긴다. 실제 작성 시 아래 헤더·순서를 그대로 따르되, 서술 내용은 매 사례마다 다르므로 예시 문장은 넣지 않는다.

```markdown
# NNN. {제목}

- **상태**: Open | Resolved
- **발생일자**: YYYY-MM-DD
- **작성자**:
- **관련 ADR**: (있으면 ADR 링크, 없으면 "없음 — 문서화되지 않은 결정")
- **관련 커밋/PR**:

## 무엇을 시도했는가

## 무엇이 잘못됐는가

## 어떻게 발견했는가

## 무엇으로 대체했는가
```
